The Descent Procedure & Heights

"Finitely many kinds of remainder (weak MW)" + "multiplying by m always makes points bigger (height)" = "finitely generated". We carry out a modern version of Fermat's infinite descent completely, following AEC VIII §3–§4. In the second half we survey §5–§11 (general number fields, canonical height, torsion, rank).

Section 01

Why weak MW alone isn't enough AEC start of VIII §3

First, let's fix the intuition with counterexamples. "A/mA finite ⇒ A finitely generated" is false.

  • A = ℝ: for any m ≥ 1, ℝ/mℝ = 0 (finite!). But ℝ is not finitely generated.
  • A = E(ℚp): E(ℚp) contains a subgroup of finite index ≅ ℤpAEC VII.6.3. ℤp/mℤp is finite (0 if p ∤ m), so E(ℚp)/mE(ℚp) is finite. But E(ℚp) is not finitely generated (ℤp is uncountable).

The pathology common to both counterexamples is that "there are lots of elements divisible by m infinitely many times" (in both ℝ and ℤp, any element can be divided by m again and again). To show this pathology doesn't occur for elliptic curves over number fields, we introduce "the size of a point" = the height, and show that "the multiplication-by-m map multiplies heights by about m²". There are only finitely many points of bounded size, so dividing forever becomes impossible ── that's the heart of descent.

Section 02

The descent theorem Descent Theorem

Theorem (descent theorem) AEC VIII.3.1

Let A be an abelian group, and suppose a function h : A → ℝ (a height function) has the following three properties.

(i) For each Q ∈ A there is a constant C₁ = C₁(Q) with: h(P + Q) ≤ 2h(P) + C₁ (∀P)
(ii) There are an integer m ≥ 2 and a constant C₂ with: h(mP) ≥ m²h(P) − C₂ (∀P)
(iii) For any constant C₃, { P ∈ A : h(P) ≤ C₃ } is a finite set

If moreover A/mA is finite for the m in (ii), then A is finitely generated.

Proof (main line)

Take representatives Q₁, …, Qr of the cosets of A/mA (the finiteness assumption). Starting from any P ∈ A, repeat the operation "divide by m and subtract the remainder":

P = mP₁ + Qi₁, P₁ = mP₂ + Qi₂, …, Pn−1 = mPn + Qiₙ

Estimate how the height changes at each step. For any j:

h(Pj) ≤ (1/m²)( h(mPj) + C₂ ) (by (ii))
　　　 = (1/m²)( h(Pj−1 − Qij) + C₂ )
　　　 ≤ (1/m²)( 2h(Pj−1) + C₁′ + C₂ ) (applying (i) to Q = −Qi)
C₁′ = max{ C₁(−Qi) : i = 1,…,r }. Both C₁′ and C₂ are constants independent of P

So at each step the height becomes "about 2/m² times + a constant". If m ≥ 2, then 2/m² ≤ 1/2, so this is a contraction. Using it repeatedly:

h(Pn) ≤ (2/m²)ⁿ h(P) + ( 1/m² + 2/m⁴ + ⋯ + 2ⁿ⁻¹/m²ⁿ )(C₁′ + C₂)
　　　 < (2/m²)ⁿ h(P) + (C₁′ + C₂)/(m² − 2)
　　　 ≤ 2⁻ⁿ h(P) + (C₁′ + C₂)/2 (when m ≥ 2)

Taking n large enough, h(Pn) ≤ 1 + (C₁′ + C₂)/2. On the other hand, tracing the chain of divisions backward,

P = mⁿPn + Σj=1n mj−1 Qij

so P is a linear combination of elements of the following set:

{ Q₁, …, Qr } ∪ { Q ∈ A : h(Q) ≤ 1 + (C₁′ + C₂)/2 }

By (iii) this is a finite set. So A is finitely generated.

∎

? Relation to Fermat's infinite descent

Fermat used it in the form "if there's a solution, you can make a smaller one → you can't get smaller forever, contradiction" (a proof of non-existence). Mordell–Weil repurposes the same shrinking structure as a proof of generation: "any point falls to the floor in finitely many steps → the floor points and the remainders Qi generate everything". "Infinite descent" producing not non-existence but finite generation ── historically, too, an interesting turning point.

A remark on effectivity AEC VIII.3.2

To turn the descent theorem into an "algorithm", it's enough that three things can be computed: (1) each C₁(Qi), (2) C₂, (3) a list of the points below the floor. For the heights on elliptic curves (next section), all of these can be computed effectively. In other words, as long as you get generators of E(K)/mE(K), you can always compute generators of E(K). The ineffectivity of the Mordell–Weil theorem really is concentrated at the single point seen in Part 2, Remark 2 (determining E(K)/mE(K)).

Section 03

The height function over ℚ ─ definition and property (a)

All that's left is to build a function on E(ℚ) satisfying (i)(ii)(iii); together with weak MW for m = 2 (Part 2), finite generation of E(ℚ) follows. Fix E : y² = x³ + Ax + B (A, B ∈ ℤ).

Definition (naive height) AEC VIII §4

For t = p/q ∈ ℚ (in lowest terms), H(t) = max{ |p|, |q| }. And

hx : E(ℚ) → ℝ, hx(P) = log H(x(P)) (P ≠ O), hx(O) = 0

A naive definition: the size of a point is "the number of digits of the larger of the numerator and denominator of its x-coordinate". Note hx ≥ 0.

Property (iii) is clear: a rational number with H(t) ≤ C has numerator and denominator integers in [−C, C], so there are at most (2C+1)² of them, and for each x there are at most two yAEC VIII.4.2(c). The problem is (i)(ii), that is, reading off "how addition and doubling change the height" from the addition formula.

🔬 Between-the-lines note N1 ─ foundations of height: a complete proof via p-adic valuations that "coordinates are always (a/d², b/d³)", basic properties of H, an exact count for (c), and a check of the example 2P = (−23/16, −11/64) →
Lemma (properties of height) AEC VIII.4.2
(a) hx(P + P₀) ≤ 2hx(P) + C₁(P₀, A, B)
(b) hx([2]P) ≥ 4hx(P) − C₂(A, B)
(c) { P : hx(P) ≤ C₃ } is finite
Proof of (a) (main line)

The cases P₀ = O and P ∈ {O, ±P₀} are handled by taking C₁ large, so exclude them. In lowest terms we can write P = (a/d², b/d³), P₀ = (a₀/d₀², b₀/d₀³) (the denominators of a Weierstrass equation always take this form: if x = u/v is in lowest terms, v = d² follows from the denominator of y²). Rearranging the addition formulaAEC III.2.3(d) using the curve's equation:

x(P + P₀) = ( (xx₀ + A)(x + x₀) + 2B − 2yy₀ ) / (x − x₀)²
　　　　 = ( (aa₀ + Ad²d₀²)(ad₀² + a₀d²) + 2Bd⁴d₀⁴ − 2bd·b₀d₀ ) / (ad₀² − a₀d²)²

The numerator and denominator are expressions "of degree at most 2" in a, d², bd. Cancelling only lowers the height, so

H(x(P+P₀)) ≤ C′ · max{ |a|², |d|⁴, |bd| }

(C′ is a constant depending only on A, B, a₀, b₀, d₀). Since H(x(P)) = max{|a|, |d|²}, |a|² and |d|⁴ have exactly the form H(x(P))². The only troublemaker is |bd|. Here we use "P lies on the curve": from b² = a³ + Aad⁴ + Bd⁶,

|b| ≤ C″ max{ |a|³ᐟ², |d|³ } ⇒ |bd| ≤ C″ max{ |a|³ᐟ²|d|, |d|⁴ } ≤ C″ max{ |a|², |d|⁴ }
The last inequality: if |a|¹ᐟ² ≥ |d| then |a|³ᐟ²|d| ≤ |a|², otherwise |a|³ᐟ²|d| < |d|⁴

So H(x(P+P₀)) ≤ C₁ max{|a|,|d|²}² = C₁ H(x(P))². Taking logarithms gives (a).

∎
🔬 Between-the-lines note N2 ─ property (a) with zero leaps: handling the 3 exceptional points, every line of deriving the symmetric form, a term-by-term check of multiplying by d⁴d₀⁴, a complete proof of |bd| ≤ √(1+|A|+|B|)·M², and an explicit form of C₁ →
? The lesson of (a)

The addition formula is a rational function of degree 2 in x, so "twice the height + a constant" is almost obvious ── except that where the y-term (|bd|) mixes in, you need the curve's equation itself to bound y by x. The moment the information "the point lies on the curve" turns into a quantitative estimate.

Section 04

The crux: doubling quadruples the height ─ property (b)

(b) is harder than (a). The reason is the direction of the inequality. (a) only says "it doesn't get too big" (an upper bound), so we could ignore cancellation, but (b) says "it doesn't get too small" (a lower bound), so we have to control how much the fraction can cancel.

Homogenize the duplication formula. With x = x(P) = p/q (in lowest terms):

x([2]P) = F(p, q) / G(p, q)
F(X, Z) = X⁴ − 2AX²Z² − 8BXZ³ + A²Z⁴
G(X, Z) = 4X³Z + 4AXZ³ + 4BZ⁴ (corresponding to 4y²·Z⁴)

F(X,1) and G(X,1) are coprime polynomials (when Δ ≠ 0), so by the theory of resultants there is an identity serving as "a certificate of coprimality". AEC writes it out explicitly:

Sublemma (explicit identities) AEC VIII.4.3

Setting Δ' = 4A³ + 27B² (the discriminant without the factor −16), as identities in ℤ[A,B,X,Z]

f₁(X,Z)·F(X,Z) − g₁(X,Z)·G(X,Z) = 4Δ'·Z⁷
f₂(X,Z)·F(X,Z) − g₂(X,Z)·G(X,Z) = 4Δ'·X⁷
f₁ = 12X²Z + 16AZ³, g₁ = 3X³ − 5AXZ² − 27BZ³ (f₂, g₂ are also explicit polynomials of degree 3)
Proof of (b) (main line)

If we take C₂ ≥ 4·max{ hx(T) : T ∈ E(ℚ)[2] }, the case [2]P = O is trivial, so assume [2]P ≠ O. Let δ = gcd( F(p,q), G(p,q) ) be the amount of cancellation. Substituting (X,Z) = (p,q) into the identities:

f₁(p,q)F(p,q) − g₁(p,q)G(p,q) = 4Δ'q⁷, f₂(p,q)F(p,q) − g₂(p,q)G(p,q) = 4Δ'p⁷

δ divides both left sides, so it divides both 4Δ'q⁷ and 4Δ'p⁷. Since gcd(p,q) = 1, δ | 4Δ'. That is, at most |4Δ'| (a constant independent of P!) can cancel. Hence:

H(x([2]P)) ≥ max{ |F(p,q)|, |G(p,q)| } / |4Δ'|

All that remains is to bound max{|F|, |G|} from below by max{|p|,|q|}⁴. Again from the identities:

|4Δ'q⁷| ≤ 2 max{|f₁|, |g₁|} · max{|F|, |G|}, |4Δ'p⁷| ≤ 2 max{|f₂|, |g₂|} · max{|F|, |G|}

f₁, g₁, f₂, g₂ are polynomials of degree 3, so max{|f₁|,…,|g₂|} ≤ C·max{|p|,|q|}³. Putting it together,

max{ |4Δ'p⁷|, |4Δ'q⁷| } ≤ 2C·max{|p|,|q|}³ · max{|F|, |G|}
⇒ max{|F|, |G|} / |4Δ'| ≥ (2C)⁻¹ max{|p|,|q|}⁴ = (2C)⁻¹ H(x(P))⁴

Taking logarithms gives hx([2]P) ≥ 4hx(P) − C₂.

∎
🔬 Between-the-lines note N3 ─ property (b) with zero leaps: explicit forms of f₂ and g₂ (omitted in the main part) with a monomial-by-monomial verification table, every line of δ | 4Δ′, an explicit form C₂ = max{log 2κ, …}, and a numerical check on y² = x³+3 →
? Why "four times" doesn't break ── the essence of the argument

The duplication formula is a rational map of degree 4, so it's no surprise the height is "at most four times". What's nontrivial is that "almost exactly four times" is also guaranteed from below, and the reason is that F and G have no common zero (= the curve is nonsingular, Δ ≠ 0). The quantitative version of having no common zero is the identity in the sublemma, and in the form "the cancellation δ divides 4Δ'" geometric nondegeneracy is translated into an arithmetic estimate. This phenomenon, "a morphism of projective space multiplies heights by its degree", is promoted to general theory in AEC VIII.5.6.

Section 05

Assembly: the Mordell–Weil theorem over ℚ

Theorem AEC VIII.4.1

If E/ℚ is an elliptic curve, then E(ℚ) is finitely generated.

Proof

By the weak Mordell–Weil theorem (Part 2, m = 2), E(ℚ)/2E(ℚ) is finite. By (a)(b)(c) of VIII.4.2, hx satisfies the assumptions (i)(ii)(iii) (m = 2) of the descent theorem. So by the descent theorem (VIII.3.1), E(ℚ) is finitely generated.

∎

Note: the weak MW used here is only the case m = 2, and moreover we don't assume E[2] ⊂ E(ℚ) (the reduction lemma in Part 2 takes care of the field extension). Savor how the two parts mesh.

Section 06 ─ Survey (summary)

Walking VIII §5–§11 with a map

§5–§6: extending to general number fields, and the "height machine"

Over a general number field K, height is defined by combining all the places (absolute values): for P = [x₀ : … : xN] ∈ ℙᴺ(K), HK(P) = Πv maxi|xi|vnv. Thanks to the product formula it doesn't depend on the choice of coordinates. There are two key results:

  • Northcott's finitenessAEC VIII.5.11: there are finitely many points of bounded height and degree. The general version of property (iii).
  • The height machine: for an even function f ∈ K(E), hf is "almost a quadratic form" (hf(P+Q) + hf(P−Q) = 2hf(P) + 2hf(Q) + O(1), the parallelogram law)AEC VIII.6.2. All the inequalities of type (i)(ii) follow from this, and the Mordell–Weil theorem over general number fields AEC VIII.6.7 is proved with the same skeleton as §4.
⏩ Don't stop here

§5–§6 are the chapter that "reforges what we computed by hand in §4 into a form that works for any number field and any projective embedding". If you understand the skeleton in the case of ℚ (today's content), you can skim §5–§6 with confidence as "a generalization of the same argument". It's enough to go deep when you need the canonical height (§9).

§7: the torsion subgroup ─ Lutz–Nagell and Mazur

Theorem (Lutz–Nagell) AEC VIII.7.1–7.2

Let E : y² = x³ + Ax + B (A,B ∈ ℤ) and P = (x,y) a torsion point (≠ O). Then x, y ∈ ℤ, and either y = 0 or y² | 4A³ + 27B².

With this, E(ℚ)tors can be determined by finitely many divisibility checks (Exercise 5). As a deeper fact, Mazur's theoremAEC VIII.7.5: E(ℚ)tors is one of 15 kinds, ℤ/Nℤ (N ≤ 10 or 12) or ℤ/2ℤ × ℤ/2Nℤ (N ≤ 4). (The proof is beyond AEC. Knowing the statement is enough.)

§8: minimal discriminants, global minimal models

Over K = ℚ you can take a Weierstrass equation that is minimal at all primes simultaneously (a global minimal model)AEC VIII.8.2–8.3 (over general number fields you can if the class number is 1). It backs up the "minimal equation" used when choosing S in Part 2. A summary is fine.

§9: the canonical height (Néron–Tate height)

The "+O(1)" wobble in hx can be completely eliminated by a limit:

ĥ(P) = (1/2)·limn→∞ 4⁻ⁿ hx([2ⁿ]P)
(normalizations differ by a factor of 1/2 depending on convention. AEC VIII §9 defines it as the limit of h_f/deg f)
  • ĥ becomes an exact quadratic form, and ĥ(P) = 0 ⟺ P is a torsion pointAEC VIII.9.3.
  • It is positive definite on E(K) ⊗ ℝAEC VIII.9.6. The determinant of the bilinear form ⟨P,Q⟩ = ĥ(P+Q) − ĥ(P) − ĥ(Q) is the elliptic regulatorAEC VIII.9.7, which appears in the formula of the BSD conjecture.
  • The proof that the limit exists is an elementary argument called "Tate's telescoping trick" (we actually do it in Exercise 6).

§10–§11: the mystery of rank, Szpiro's conjecture (as reading)

For the rank r, basic open problems are still lined up: is the rank unboundedAEC VIII.10.1 (conjecture), what is the "average" rank, and so on. §11 is a reading section on the equivalence of Szpiro's conjecture (an inequality between discriminant and conductor) and the ABC conjecture, not needed for understanding Mordell–WeilAEC VIII §11.

Exercises

Exercises

Problem 1★ Basic

In the proof of the descent theorem we said "taking n large enough, h(Pn) ≤ 1 + (C₁′+C₂)/2". Given h(P) and C₁′+C₂, give one explicit n that guarantees this (take m = 2).

Open the solution

The estimate is h(Pn) ≤ 2⁻ⁿ h(P) + (C₁′+C₂)/2, so 2⁻ⁿ h(P) ≤ 1 is enough. That is, any integer n ≥ log₂ h(P) works, for example n = max{0, ⌈log₂ h(P)⌉}. You reach the floor in a number of steps equal to the log of the height (≈ the log of the number of digits) ── you can also read off that descent is "fast".

Problem 2★ Basic

Using only height property (iii) (finiteness of bounded sets), show directly, without going through the descent theorem, that the torsion subgroup of E(ℚ) is finite. (Hint: derive from (a)(b) that torsion points have bounded height.)

Open the solution

Let P be a torsion point of order k. Repeating (b) gives hx(2ⁿP) ≥ 4ⁿ hx(P) − C₂(1 + 4 + … + 4ⁿ⁻¹) ≥ 4ⁿ( hx(P) − C₂/3 ). If hx(P) > C₂/3 the left side diverges with n, but {2ⁿP} is a finite set (contained in the cyclic group generated by P), so the heights are bounded, a contradiction. So every torsion point satisfies hx ≤ C₂/3, and by (iii) there are finitely many torsion points. ── This is a naive version of "ĥ(torsion point) = 0" (VIII.9.3).

Problem 3★★ Standard

For E : y² = x³ + 3, P = (1,2), check the 4P row of the table in the text. That is, compute F(−23,16) = 2540833 and G(−23,16) = 7744, confirm gcd(2540833, 7744) = 1 using "δ | 4Δ' = 972", and conclude hx(4P) = log 2540833.

Open the solution

F(X,Z) = X⁴ − 24XZ³ (since A=0, B=3, the terms −2AX²Z² and A²Z⁴ vanish): F(−23,16) = 279841 + 24·23·4096 = 279841 + 2260992 = 2540833. G(X,Z) = 4X³Z + 12Z⁴: G(−23,16) = −778688 + 786432 = 7744 = 2⁶·11². δ | 4Δ' = 972 = 2²·3⁵ and δ | 7744 = 2⁶·11², so δ | 4. F(−23,16) is odd (even + odd), so δ = 1. So in lowest terms x(4P) = 2540833/7744; the numerator is larger, so hx(4P) = log 2540833 ≈ 14.75.

Problem 4★★ Standard

For A = 0, B = 3, actually expand and verify the first identity of the sublemma (VIII.4.3), f₁F − g₁G = 4Δ'Z⁷. (f₁ = 12X²Z, g₁ = 3X³ − 81Z³, F = X⁴ − 24XZ³, G = 4X³Z + 12Z⁴, 4Δ' = 972.)

Open the solution

f₁F = 12X²Z(X⁴ − 24XZ³) = 12X⁶Z − 288X³Z⁴.
g₁G = (3X³ − 81Z³)(4X³Z + 12Z⁴) = 12X⁶Z + 36X³Z⁴ − 324X³Z⁴ − 972Z⁷ = 12X⁶Z − 288X³Z⁴ − 972Z⁷.
Taking the difference, f₁F − g₁G = 972Z⁷ = 4·243·Z⁷ = 4Δ'Z⁷ (Δ' = 27·9 = 243). ✓ Verifying it for general A, B is "a boring but sure computation" (in AEC's words, a tedious calculation). Deriving f₁, g₁ yourself with Euclid's algorithm is also good practice.

Problem 5★★ Standard

Use Lutz–Nagell (VIII.7.1–7.2) to show that the torsion subgroup of E : y² = x³ + 3 is trivial (= {O}), and conclude from P = (1,2) and the Mordell–Weil theorem that rank E(ℚ) ≥ 1.

Open the solution

4A³ + 27B² = 0 + 243 = 243 = 3⁵. A torsion point (x,y) ≠ O has x,y ∈ ℤ, and if y = 0 then x³ = −3 (no integer solution). If y ≠ 0, y² | 243 gives y² ∈ {1, 9, 81}, i.e. y ∈ {±1, ±3, ±9}. These give x³ = y² − 3 ∈ {−2, 6, 78}, none of which is a perfect cube. So the only torsion point is O. P = (1,2) ∈ E(ℚ) is not O, so it has infinite order. E(ℚ) ≅ ℤʳ (no torsion) with r ≥ 1. (In fact r = 1 and P is a generator, but proving that needs the descent computations of Part 5.)

Problem 6★★★ Advanced

(Tate's telescoping trick = existence of the canonical heightthe core of AEC VIII.9.1) Let h = hx. First, (a): you may accept that there is a constant C with |h(2P) − 4h(P)| ≤ C (∀P), from VIII.4.2(b) and "the upper bound h(2P) ≤ 4h(P) + C" (which comes from a crude estimate like (a)). Then (b): show that the sequence aₙ = 4⁻ⁿ h(2ⁿP) is a Cauchy sequence, and prove that the limit ĥ'(P) = lim aₙ exists and satisfies |ĥ'(P) − h(P)| ≤ C/3.

Open the outline of the solution

Estimate the difference of adjacent terms: |an+1 − an| = 4⁻⁽ⁿ⁺¹⁾|h(2·2ⁿP) − 4h(2ⁿP)| ≤ C·4⁻⁽ⁿ⁺¹⁾. So for n < m, |am − an| ≤ C Σk>n 4⁻ᵏ = C·4⁻ⁿ/3 → 0, a Cauchy sequence. Calling the limit ĥ'(P), |ĥ'(P) − a₀| ≤ Σk≥1 C·4⁻ᵏ = C/3, and a₀ = h(P), so the claim follows.

Supplement: the same telescoping estimate immediately gives ĥ'(2P) = 4ĥ'(P) with no error (just shift the limit in the definition). The design idea of §9, "kill the +O(1) by a limit to get an exact quadratic form", is condensed into this computation. Using the parallelogram law, a similar argument even shows ĥ' is a quadratic form (the proof of AEC VIII.9.3).
