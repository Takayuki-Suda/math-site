Between-the-lines notes ─ Weak Mordell–Weil N0/N3

A complete proof of the reduction lemma
Reduction Lemma, with every step justified

"We may assume E[m] ⊂ E(K)" ── we rebuild this one line of STEP 0 in the main part with zero leaps. We first fix the premises we use with numbers, and make the "claim" and "reason" explicit for every step of the proof. If the main part is a map, this note is a survey chart drawn down to the contour lines.

TEXT: Silverman, AEC 2nd ed. ─ VIII.1.1.1 (fully expanded)

Main II Weak MW N0 Reduction lemma N1 Kummer pairing N2 Unramifiedness N3 Finiteness from field theory
Section 01

The gaps this note fills

The proof of STEP 0 in the main part is a correct blueprint, but in the following six places it relied on the reader filling things in mentally. This note puts all of them on paper.

  • ① Why "the natural map E(K)/mE(K) → E(L)/mE(L)" is well defined
  • ② The set-theoretically precise form of the phrase "finite because it's squeezed between finite groups" (the first isomorphism theorem)
  • ③ Making explicit the double choice needed to construct λP (a coset representative, and its m-division point)
  • ④ "A Galois-invariant point is K-rational" ── a precise proof going back to the relation between equality of points and equality of coordinates
  • ⑤ The reason [m] commutes with the Galois action (used implicitly three times in the proof)
  • ⑥ A complete proof that "K(E[m])/K is a finite Galois extension", used in the corollary

Plan: first, in Section 02, we fix the premises as P1–P5. In the proof that follows, we proceed while checking that every step follows only from "P1–P5, steps already shown, or pure computation".

Section 02

Fixing the premises (P1–P5)

Only the things listed here are imported from outside. Each one's source is stated. Put the other way, the proof that follows uses no "magic" beyond these.

Premise P1 ─ group structure of the point set AEC III.2.2 / III.3.6

E(K) is an abelian group with identity O = [0:1:0], and addition and inverses are given by morphisms with coefficients in K. For an intermediate field K ⊂ F ⊂ K, E(F) is a subgroup. [m] : E(K) → E(K) is repeated addition, so it's a group homomorphism.

Premise P2 ─ commutativity of the Galois action with addition

σ ∈ GK/K acts on E(K) by P = (x, y) ↦ Pσ = (xσ, yσ), Oσ = O, and

(P + Q)σ = Pσ + Qσ, (−P)σ = −Pσ, hence ([m]P)σ = [m](Pσ)

hold. Also, if P ∈ E(K) then Pσ = P (its coordinates are in K, and σ fixes K).

Why they commute (open the proof)

The coordinates of the sum P + Q can be written as rational functions with coefficients in K of the coordinates of P and Q (the chord-and-tangent formulas: AEC III.2.3). σ is a field homomorphism fixing K, so for a rational function f with coefficients in K, f(x₁,…)σ = f(x₁σ,…). So the coordinates of (P+Q)σ = the addition formula passed through σ = the coordinates of Pσ + Qσ. The special cases (P = ±Q, cases involving O) work the same way since O = [0:1:0] is K-rational. ([m]P)σ = [m](Pσ) is just applying (P+Q)σ = Pσ+Qσ m−1 times.

Premise P3 ─ Galois-invariant points are points over the lower field

If M/F is a (finite or infinite) Galois extension, then E(M)GM/F = E(F).

Open the proof (gap ④)

⊇ is the last claim of P2. We show ⊆. Suppose P ∈ E(M) satisfies Pσ = P for all σ. If P = O, then O ∈ E(F) and we're done. If P ≠ O, P has affine coordinates (x, y), and affine coordinates represent a point uniquely, so from "Pσ = P as points" follows "xσ = x and yσ = y as coordinates" (this is gap ④: with projective coordinates we could only say the ratios agree, but the pair of affine coordinates is unique). So x, y ∈ MGM/F = F. The last equality is the fundamental theorem of Galois theory (even in the infinite case, "the fixed field of a Galois extension is the base field" holds: field theory). Hence P ∈ E(F).

Premise P4 ─ the number of m-torsion points AEC III.6.2(d)

When char K = 0, E[m] := ker( [m] : E(K) → E(K) ) ≅ (ℤ/mℤ)². In particular #E[m] = m², and E[m] is a finite subgroup of E(K).

Premise P5 ─ a standard fact of group theory (the first isomorphism theorem)

If φ : A → B is a group homomorphism with N = ker φ, then A/N ≅ im φ. So A splits into |im φ| cosets of N, and if N and im φ are both finite, |A| = |N|·|im φ| and A is finite too.

Section 03

The statement and the design of the proof

Lemma (the reduction lemma) AEC VIII.1.1.1

Let L/K be a finite Galois extension. If E(L)/mE(L) is finite, then E(K)/mE(K) is finite too.

Design: send the kernel Φ of the restriction map E(K)/mE(K) → E(L)/mE(L) injectively into the finite set Map(GL/K, E[m]) (the set of all maps from GL/K to E[m]). If the kernel and image are both finite, the whole thing is finite (P5) ── a two-stage approach.

Section 04 ─ Part 1

Identifying the kernel Φ, and the precise form of the "squeeze"

1

mE(K) ⊆ mE(L). Hence the composite map E(K) ↪ E(L) ↠ E(L)/mE(L) sends the subgroup mE(K) to 0.

▸ Reason An element of mE(K) has the form [m]R (R ∈ E(K)), and E(K) ⊆ E(L) (P1) gives R ∈ E(L), so [m]R ∈ mE(L).

2

A group homomorphism φ : E(K)/mE(K) → E(L)/mE(L), φ(P mod mE(K)) = P mod mE(L), is induced and well defined.

▸ Reason The universal property of quotient groups: a homomorphism whose kernel contains mE(K) (Step 1) factors through the quotient E(K)/mE(K). This is what gap ① contains.

3

Φ := ker φ = ( E(K) ∩ mE(L) ) / mE(K).

▸ Reason P mod mE(K) ∈ ker φ ⟺ P ∈ mE(L) (definition of φ) ⟺ P ∈ E(K) ∩ mE(L) (P was an element of E(K) to begin with).

4

When E(L)/mE(L) is finite, if Φ is finite then E(K)/mE(K) is finite, and |E(K)/mE(K)| = |Φ|·|im φ| ≤ |Φ|·|E(L)/mE(L)|.

▸ Reason Apply P5 with A = E(K)/mE(K), N = Φ. im φ is a subset of the finite group E(L)/mE(L), so it's finite. This is the precise form of gap ②. From now on, the only goal is "Φ is finite".

Section 05 ─ Part 2

Constructing the map λ ─ making the double choice explicit

5

For each coset c ∈ Φ, choose one representative Pc ∈ E(K) ∩ mE(L). Then choose one Qc ∈ E(L) with [m]Qc = Pc. Fix these two choices from now on.

▸ Reason A representative exists by the definition of cosets. Qc exists by the very definition of Pc ∈ mE(L). This is gap ③: the argument from here on concerns the map c ↦ λc, which depends on "the chosen Pc, Qc", and the logic is complete with that (injectivity alone is enough for comparing cardinalities).

6

Define λc : GL/K → E(K) by λc(σ) := Qcσ − Qc.

▸ Reason Qc ∈ E(L), and GL/K acts on E(L) (P2 applied to L/K), so the right side makes sense.

7

The values of λc actually lie in E[m]. That is, λc ∈ Map(GL/K, E[m]).

▸ Reason The following three-line computation. The reason for each equality is given on the right.

[m](Qcσ − Qc) = [m](Qcσ) − [m]Qc ← [m] is a homomorphism (P1)
　= ([m]Qc)σ − [m]Qc ← the action commutes with [m] (P2) = gap ⑤
　= Pcσ − Pc = O ← Pc ∈ E(K) and the last claim of P2
Section 06 ─ Part 3

Injectivity and finiteness

8

Injectivity: if λc = λc′, then c = c′. Below we break it into 8a–8d.

8a

By assumption, Qcσ − Qc = Qc′σ − Qc′ for all σ ∈ GL/K.

▸ Reason λc = λc′ is equality as maps, i.e. agreement of values at every argument.

8b

Moving terms, (Qc − Qc′)σ = Qc − Qc′ (∀σ ∈ GL/K).

▸ Reason E(K) is an abelian group (P1), so terms can be moved freely. (A − B)σ = Aσ − Bσ is P2.

8c

Setting R := Qc − Qc′, R ∈ E(L) and it is GL/K-invariant. So R ∈ E(K).

▸ Reason E(L) is a subgroup (P1), so the difference is also a point of E(L). Invariance is 8b. The conclusion is P3 applied with M = L, F = K (the assumption that L/K is Galois is used here).

8d

[m]R = Pc − Pc′. Since R ∈ E(K), Pc − Pc′ ∈ mE(K), i.e. c = c′.

▸ Reason [m]R = [m]Qc − [m]Qc′ (P1: [m] is a homomorphism) = Pc − Pc′ (the choice in Step 5). "c = c′" is the definition of equality in the quotient group E(K)/mE(K) (the difference lies in mE(K)).

9

Map(GL/K, E[m]) is a finite set, of cardinality exactly (m²)[L:K].

▸ Reason |GL/K| = [L:K] < ∞ (a finite Galois extension: field theory), #E[m] = m² (P4). There are |Y||X| maps from a finite set X to a finite set Y.

10

c ↦ λc is an injection from Φ into Map(GL/K, E[m]) (Step 8). So |Φ| ≤ (m²)[L:K] < ∞. Together with Step 4 this completes the proof of the lemma.

▸ Reason With an injection, the cardinality is at most that of the codomain (set theory).

∎
By-product: an explicit upper bound
|E(K)/mE(K)| ≤ m2[L:K] · |E(L)/mE(L)|

Note that we get not only "it's finite" but a quantitative estimate too. Explicit upper bounds for the Mordell–Weil rank (the supplement to STEP 3 of the main part) are built by stacking estimates of this kind.

What we didn't use (knowing the outline of the proof)

Abelianness of GL/K is not needed (any finite Galois extension works). Finiteness of L/K is used only in Step 9. The assumption E[m] ⊂ E(K) is not used at all ── which is exactly why this lemma lets us safely climb up to "the extension that makes E[m] rational".

Section 07

Corollary ─ we may assume E[m] ⊂ E(K)

Corollary

Let L := K(E[m]) (the field obtained by adjoining to K the affine coordinates of all points of E[m]). Then L/K is a finite Galois extension. Therefore, by the reduction lemma, it is enough to prove the weak Mordell–Weil theorem in the case E[m] ⊂ E(K).

1

L/K is a finite extension.

▸ Reason E[m] is a finite set (P4: m² points), and the coordinates of each point are elements of K, i.e. algebraic over K by definition. An extension generated by finitely many algebraic elements is finite (a standard fact of field theory). "Are they algebraic?" isn't even a question ── the coordinates of points of E(K) live inside the algebraic closure from the start. This is the first half of gap ⑥.

2

GK/K preserves the set E[m]: T ∈ E[m] ⇒ Tσ ∈ E[m].

▸ Reason [m](Tσ) = ([m]T)σ (P2) = Oσ = O (P2: O is K-rational).

3

L/K is normal, and hence (being separable too, since char 0) Galois.

▸ Reason Any K-embedding τ : L → K extends to an automorphism σ of K (the isomorphism extension theorem: field theory). By Step 2, σ permutes E[m], so it preserves the set of generators {x(T), y(T) : T ∈ E[m]} as a set. So τ(L) = K(σ(generators)) = K(generators) = L. "The image under every embedding is L" is the definition of normality.

4

If we show E(L)/mE(L) is finite (E/L is an elliptic curve satisfying E[m] ⊂ E(L)), then by the reduction lemma E(K)/mE(K) is finite too.

▸ Reason By Steps 1–3, L/K is a finite Galois extension. E[m] ⊂ E(L) is just how L was made. E[m] doesn't change when the coefficient field is extended (it's a set defined inside K).

∎
? What is λ? ─ a bridge to Part 3

λc(σ) = Qcσ − Qc is, in the language of Part 3, a 1-cocycle of GL/K with values in E[m] (the action on E[m] need not be trivial, so in general it's not a homomorphism). This time we could get by with the naive argument "it injects into the set of maps Map" because all we needed was a cardinality estimate. When you want structure too (which λ actually occur?), you need the cohomology group H¹.
