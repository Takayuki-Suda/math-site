行間ノート ─ 降下法と高さ N0/N3

降下定理の完全証明
The Descent Theorem, with every step justified

「A/mA 有限 ＋ 高さ関数 ⇒ 有限生成」──本編Ⅳ Section 02 の証明を、飛躍ゼロで組み立て直します。 降下列の構成に隠れた「選択」、縮小評価の帰納法、逆望遠鏡和、そして「生成する」の正確な意味まで、 すべてのステップに「主張」と「根拠」を明示します。ここは楕円曲線がまだ登場しない、純粋な群論＋実数の章です。

TEXT: Silverman, AEC 2nd ed. ─ VIII.3.1（完全展開）

Section 01

このノートで埋める行間

本編 Section 02 の証明は正しい設計図ですが、次の6箇所で読者の頭の中の補完に頼っていました。 このノートはそれを全部、紙の上に出します。

  • ① 降下列 P₁, P₂, … の構成に含まれる2重の選択（剰余類の番号 ij と商 Pj）の明示
  • ② 性質 (i) を「Q = −Qi」に適用する符号処理と、定数 C₁′ が P に依らず取れる理由
  • ③ 反復評価 h(Pn) ≤ (2/m²)ⁿh(P) + …（幾何級数）の帰納法による厳密証明
  • ④ h は ℝ 値で非負とは仮定していない──h(P) < 0 でも議論が回ることの確認
  • ⑤ 逆望遠鏡和 P = mⁿPn + Σ mj−1Qij の帰納法による証明
  • ⑥ 「有限集合で生成される」の集合論的に正確な形（生成部分群 = 全体）の書き下し

方針：まず Section 02 で前提を H1–H3 として固定します。以後の証明では、 すべてのステップが「H1–H3・既に示したステップ・純粋な計算」のいずれかだけから従うことを確認しながら進みます。

Section 02

前提の固定（H1–H3）

このノートが外部から輸入するのは次の3つだけです。楕円曲線論も体論も一切使いません （それらは N1–N3 で「高さ関数の存在」を証明するときに初めて登場します）。

前提 H1 ─ アーベル群と生成 群論の定義

A はアーベル群（加法的に書く）。部分集合 Z ⊆ A に対し、Z の生成する部分群とは

⟨Z⟩ = { n₁z₁ + ⋯ + nkzk : k ≥ 0, ni ∈ ℤ, zi ∈ Z }　（空和 = 0）

である。「A は有限生成」とは、有限集合 Z で A = ⟨Z⟩ となるものが存在すること。 整数倍 mP は加法の反復であり、任意の P, Q ∈ A と n ∈ ℤ で n(P+Q) = nP + nQ が成り立つ。

前提 H2 ─ 商群と剰余類代表 群論の定義

mA = { mP : P ∈ A } は部分群で、商群 A/mA が定義される。 「A/mA が有限（位数 r）」とは、代表元 Q₁, …, Qr ∈ A が存在して、 任意の a ∈ A に対しある i で a − Qi ∈ mA となること。

前提 H3 ─ 実数の初等事実 解析の基礎

0 < α < 1 と実数 β ≥ 0 に対し：

幾何級数：β(1 + α + α² + ⋯ + αn−1) = β·(1−αⁿ)/(1−α) < β/(1−α)
アルキメデス性：任意の x ≥ 0 に対し、2⁻ⁿx ≤ 1 なる整数 n ≥ 0 が存在する

また、実数の不等式は正数で割っても向きが変わらない。使う解析はこれだけである。

Section 03

主張と証明の設計

定理（降下定理） AEC VIII.3.1

A をアーベル群、h : A → ℝ を次を満たす関数とする。

(i)　各 Q ∈ A に対し定数 C₁ = C₁(Q) があり：h(P + Q) ≤ 2h(P) + C₁　（∀P ∈ A）
(ii)　ある整数 m ≥ 2 と定数 C₂ があり：h(mP) ≥ m²h(P) − C₂　（∀P ∈ A）
(iii)　任意の定数 C₃ に対し { P ∈ A : h(P) ≤ C₃ } は有限集合

さらに (ii) の m について A/mA が有限ならば、A は有限生成である。

設計は3部構成です。Part 1（構成）：任意の点 P から「m で割って余りを引く」降下列を作る。 Part 2（評価）：降下列の高さが幾何級数的に「床」まで落ちることを示す。 Part 3（生成）：降下列を逆にたどって、P が「床の点＋余りの代表」の整数結合であることを確かめる。 有限性の供給源は最後に (iii) が一手に引き受けます。

? h に「意味」は要らない

この定理の h は「E(ℚ) の点の桁数」のつもりで作られていますが、証明中では (i)(ii)(iii) 以外の性質を一切使いません。h ≥ 0 すら仮定していないことに注意 （行間④で確認します）。公理的に切り出したからこそ、この定理は E(ℚ) 以外にも── たとえば一般の数体上の E(K) にも、そのまま再利用できますAEC VIII.6.7。

Section 04 ─ Part 1

降下列の構成 ─ 選択を明示する

1

A/mA の代表元 Q₁, …, Qr ∈ A を1組選んで固定する。あわせて定数 C₁′ := max{ C₁(−Q₁), …, C₁(−Qr) } を定める。

▸ 根拠　代表元の存在は H2（A/mA 有限の定義）。C₁′ は有限個の実数の最大値なので確かに存在し、P には依らない。各 −Qi に対する定数 C₁(−Qi) の存在は (i)。これが行間②の後半。

2

P ∈ A を任意に取り、P₀ := P とおく。j ≥ 1 について帰納的に：Pj−1 まで構成できたら、Pj−1 − Qij ∈ mA なる番号 ij ∈ {1,…,r} を1つ選び、さらに mPj = Pj−1 − Qij なる Pj ∈ A を1つ選ぶ。

▸ 根拠　ij の存在は H2（Pj−1 はどれかの剰余類に入る）。Pj の存在は「mA の元 = ある元の m 倍」という mA の定義そのもの。これが行間①：構成には毎ステップ2つの選択が入るが、各ステップの選択肢は空でなく、必要なのは有限列を1本作ることだけなので、任意に選んで固定すればよい（選択公理は不要）。

3

こうして任意の長さ n の「降下データ」(P₀, P₁, …, Pn; i₁, …, in) が得られる：

P₀ = P,　Pj−1 = mPj + Qij　(j = 1, …, n)

▸ 根拠　Step 2 の式 mPj = Pj−1 − Qij の移項（A はアーベル群、H1）。

Section 05 ─ Part 2

縮小評価 ─ 高さは幾何級数的に床へ落ちる

4

1ステップ評価：各 j = 1, …, n で　h(Pj) ≤ ( 2h(Pj−1) + C₁′ + C₂ ) / m²。以下 4a–4d に分解する。

4a

m²h(Pj) ≤ h(mPj) + C₂。

▸ 根拠　(ii) を P = Pj に適用して移項しただけ。

4b

h(mPj) = h(Pj−1 − Qij) = h(Pj−1 + (−Qij))。

▸ 根拠　mPj と Pj−1 − Qij は A の同じ元（Step 2 の構成）なので h の値も等しい。引き算は「逆元を足すこと」（H1）。

4c

h(Pj−1 + (−Qij)) ≤ 2h(Pj−1) + C₁(−Qij) ≤ 2h(Pj−1) + C₁′。

▸ 根拠　最初の不等号は (i) を「Q = −Qij、P = Pj−1」に適用したもの。(i) は任意の Q ∈ A に対して定数を与えるので、−Qi に使ってよい──これが行間②の前半（符号処理）。2つ目の不等号は C₁′ の定義（Step 1：max を取ってある）。

4d

4a–4c を繋いで m² ( > 0 ) で割ると、主張の1ステップ評価を得る。

▸ 根拠　m²h(Pj) ≤ h(mPj) + C₂ ≤ 2h(Pj−1) + C₁′ + C₂。正数で割っても不等号の向きは不変（H3）。

5

反復（帰納法）：α := 2/m²、β := (C₁′ + C₂)/m² とおくと、任意の n ≥ 0 で

h(Pn) ≤ αⁿ h(P) + β ( 1 + α + α² + ⋯ + αn−1 )

▸ 根拠　n についての帰納法（行間③）。n = 0 は「h(P) ≤ h(P)」で真（右辺の和は空和 = 0）。n で成立するとき、Step 4 の1ステップ評価 h(Pn+1) ≤ αh(Pn) + β に帰納法の仮定を代入：h(Pn+1) ≤ α( αⁿh(P) + β(1+⋯+αn−1) ) + β = αn+1h(P) + β(1+α+⋯+αⁿ)。α > 0 なので不等式に α を掛けてよい。

6

床の導出：m ≥ 2 より α ≤ 1/2 だから、h⁺ := max{ h(P), 0 } とおくと

h(Pn) < αⁿ h(P) + β/(1−α) ≤ 2⁻ⁿ h⁺ + (C₁′ + C₂)/(m² − 2) ≤ 2⁻ⁿ h⁺ + (C₁′ + C₂)/2

▸ 根拠　幾何級数の和は H3。β/(1−α) = [(C₁′+C₂)/m²] / [(m²−2)/m²] = (C₁′+C₂)/(m²−2) は分母分子に m² を掛けるだけの計算。m ≥ 2 ⇒ m²−2 ≥ 2。α ≤ 1/2 とはいえ αⁿh(P) ≤ 2⁻ⁿh(P) と書けるのは h(P) ≥ 0 のときだけ──h(P) < 0 なら αⁿh(P) < 0 ≤ 2⁻ⁿh⁺ なので、どちらの場合も αⁿh(P) ≤ 2⁻ⁿh⁺。これが行間④：h の非負性は不要で、max{h(P), 0} を使えば統一的に処理できる。なお C₁′+C₂ ≥ 0 も仮定していないが、負ならば床が下がるだけで以後の議論はそのまま通る。

7

停止時刻の選択：2⁻ⁿ h⁺ ≤ 1 なる n ≥ 0 を1つ選ぶ。この n について

h(Pn) ≤ 1 + (C₁′ + C₂)/2 =: C₃*　（P に依らない定数！）

▸ 根拠　存在は H3 のアルキメデス性（h⁺ ≥ 0）。明示的には n = max{ 0, ⌈log₂ h⁺⌉ } が取れる（本編・練習問題1）。n は P ごとに変わるが、床 C₃* は変わらない──ここがこの証明の急所である。

Section 06 ─ Part 3

逆望遠鏡と生成

8

逆望遠鏡和：任意の n ≥ 0 で

P = mⁿ Pn + Σj=1n mj−1 Qij　（n = 0 のときは P = P₀、和は空和）

▸ 根拠　n についての帰納法（行間⑤）。n = 0 は P = P₀（Step 2 の定義）。n = k で成立するとき、Pk = mPk+1 + Qik+1（Step 3）を代入：P = mk( mPk+1 + Qik+1 ) + Σj≤k mj−1Qij = mk+1Pk+1 + Σj≤k+1 mj−1Qij。分配則 mk(X+Y) = mkX + mkY は H1。

9

生成集合の確定：Z := { Q₁, …, Qr } ∪ { R ∈ A : h(R) ≤ C₃* } とおくと、Z は有限集合で A = ⟨Z⟩。

▸ 根拠　有限性：第1の集合は r 個、第2の集合は (iii) を C₃ = C₃* に適用して有限──証明全体で (iii) を使うのはこの一度だけ。生成：任意の P に対し Step 7 の n を取れば、Step 8 の式は P を「Pn（∈ 第2の集合、Step 7）の mⁿ 倍」と「各 Qij の mj−1 倍」の和として表す。これは H1 の意味での Z の整数結合そのもの。これが行間⑥：「生成する」とは任意の元が整数結合で書けること、それを文字通り書き下した。

10

よって A は有限集合 Z で生成され、定理の証明が完了する。

▸ 根拠　Step 9 がまさに「有限生成」の定義（H1）。

∎
副産物：明示的な生成集合と停止時刻
A = ⟨ {Q₁,…,Qr} ∪ { R : h(R) ≤ 1 + (C₁′+C₂)/2 } ⟩,　停止時刻 n ≈ log₂ h⁺(P)

「有限生成である」だけでなく、生成集合の候補と、そこへ到達するステップ数まで証明が教えてくれる。 C₁′, C₂ が計算できて（N2・N3 が実際に計算します）、床以下の点が列挙できるなら（N1 の数え上げ）、 生成元はアルゴリズムで見つかる──本編の「効果性の注意」AEC VIII.3.2の中身はこれです。

何を使わなかったか（証明の輪郭を知る）

h の非負性は不要（Step 6）。(i) の係数 2 は本質でない── 2 の代わりに任意の c < m² でも縮小率 c/m² < 1 が保たれ、床の分母が m²−c に変わるだけ。 A の可算性・ねじれの有無も不要。有限性を供給したのは (iii) の一度きりの適用（Step 9）と A/mA の有限性（Step 1）の2箇所だけである。

? 縮小写像として見る ─ シミュレータの「床」の正体

1ステップ評価（Step 4）は、実数の漸化式 x ↦ (2x + C)/m² を高さに強制する。 この一次写像は傾き 2/m² < 1 の縮小写像で、不動点は x* = C/(m²−2)── 本編のシミュレータに引いた金色の点線がこれです。Banach の不動点定理の初等版が、 「どんなに高い点も対数回のステップで床に落ちる」ことを保証している、と読めます。 Fermat の無限降下が「矛盾」を出すのに使った同じ縮小構造を、ここでは「生成」を出すのに使う── 本編 Section 02 の why ボックスとあわせて味わってください。
