The weak Mordell–Weil theorem
Why E(K)/mE(K) Is Finite

E(K)/mE(K) is finite ── this single claim packs in reduction (local theory), the Galois action, and both great finiteness theorems of algebraic number theory. In this Part 2 we read the proof of AEC VIII §1 step by step, filling in the gaps between the lines.

TEXT: Silverman, AEC 2nd ed. ─ Ch. VIII §1 (close reading)

Section 01

The claim, and where it fits

Theorem (weak Mordell–Weil) AEC VIII.1.1

Let K be a number field, E/K an elliptic curve, and m ≥ 2 an integer. Then

E(K)/mE(K) is a finite group

First, let's be clear about what this theorem does not say. "E(K)/mE(K) is finite" alone does not give "E(K) is finitely generated". For example, ℝ/mℝ = 0 is the trivial group for every m, yet ℝ is not finitely generated. Likewise, for an elliptic curve E(ℚp) over a p-adic field, E(ℚp)/mE(ℚp) is finite, but E(ℚp) is not finitely generatedAEC VIII §3 opening / VII.6.3. What is missing is a mechanism that rules out "points divisible by m again and again", and that is supplied by height functions and descent (Part 4).

In other words, the Mordell–Weil theorem is a two-stage rocket, "weak MW (this part) + descent (Part 4)", and this time we launch the first stage.

? Why the quotient group E(K)/mE(K)?

Because the input that descent (Theorem VIII.3.1 in Part 4) requires is exactly "A/mA is finite". Descent is an argument that "shrinks an arbitrary point P by repeatedly subtracting its remainder mod m (= a coset representative)", so it cannot even start unless there are finitely many kinds of remainders. Weak MW guarantees that "finiteness of remainders".

Section 02

Blueprint of the proof

The proof has 4 steps. We first look at the whole, then dive into each step.

Figure 1: Structure of the proof of the weak Mordell–Weil theorem. The dotted boxes are "deep theorems brought in from outside". The originality of the proof lies in the "translation" of STEPS 1–2; the source of finiteness is the classical number theory of STEP 3.

In one sentence: translate the finiteness problem for rational points into a finiteness problem for a field extension (Kummer pairing), show with reduction theory that this extension is "well-behaved" (unramified), and use classical number theory to guarantee that there are only finitely many well-behaved extensions (class number and units) ── that is the whole route.

Section 03 ─ Step 0

Reduction lemma ─ we may assume E[m] ⊂ E(K)

The Kummer pairing we are about to use is far easier to handle when "the points of E[m] are K-rational". But for a general E/K, E[m] ⊄ E(K). So first we show that replacing the field by a finite Galois extension does not change whether the theorem holds.

Lemma (the reduction lemma) AEC VIII.1.1.1

Let L/K be a finite Galois extension. If E(L)/mE(L) is finite, then E(K)/mE(K) is also finite.

Proof (main line)

The inclusion E(K) ⊂ E(L) induces a natural map E(K)/mE(K) → E(L)/mE(L). Call its kernel Φ:

Φ = ( E(K) ∩ mE(L) ) / mE(K)

(the "K-rational points that become divisible by m once we go up to L"). It suffices to show that Φ is finite. Indeed, then by the exact sequence 0 → Φ → E(K)/mE(K) → E(L)/mE(L), E(K)/mE(K) is sandwiched between the finite group Φ and the finite group E(L)/mE(L), so it is finite.

For each element P of Φ (mod mE(K)), choose one point QP ∈ E(L) with [m]QP = P, and define the map

λP : GL/K → E[m], λP(σ) = QPσ − QP

First, check that the values really land in E[m]: [m](QPσ − QP) = ([m]QP)σ − [m]QP = Pσ − P = O. The last equality holds because P is K-rational and σ fixes K.

Key claim: P ↦ λP is injective (as a map from Φ). Suppose λP = λP′. Then for every σ ∈ GL/K, (QP − QP′)σ = QP − QP′. So QP − QP′ is GL/K-invariant, and by Galois theory QP − QP′ ∈ E(K). Multiplying by m, P − P′ = [m](QP − QP′) ∈ mE(K), that is, P ≡ P′ (mod mE(K)). Injectivity is shown.

But GL/K and E[m] are both finite sets, so the set of maps Map(GL/K, E[m]) is finite. Φ injects into it, so Φ is finite.

∎
🔬 Between-the-lines note N0 ─ this proof with zero gaps: fixing prerequisites P1–P5, all 10 steps + reasons, and a full proof of the corollary "we may assume E[m] ⊂ E(K)" →
? Where is the "variable" in this proof?

The key is a single point: "the Galois-orbit displacement QPσ − QP of an m-th division point QP of P remembers the information of P (mod mE(K))". In the language of Part 3, this λP is exactly a 1-cocycle. AEC also remarks, "λP is an example of a 1-cocycle; see (VIII §2)". The argument we just did by hand will be organized in Part 3 into the general theory of the inflation–restriction exact sequence.

Now, E[m] is a finite set of order m², and the coordinates of each point are algebraic numbers in KAEC III.6.4. So L = K(E[m]) (the field obtained by adjoining the coordinates of all m-torsion points) is a finite extension, and since GK/K preserves E[m] as a set ([m]P = O is a Galois-invariant condition), L/K is Galois. By the reduction lemma, from now on it suffices to prove the theorem assuming E[m] ⊂ E(K). This assumption is in force for the rest of §1.

Section 04 ─ Step 1

Kummer pairing ─ translating rational points into field extensions

Definition (the Kummer pairing) AEC VIII §1

Assume E[m] ⊂ E(K). For P ∈ E(K) and σ ∈ GK/K, choose any point Q ∈ E(K) with [m]Q = P, and

κ(P, σ) = Qσ − Q

define it as above. (The existence of Q follows from the surjectivity of [m] : E(K) → E(K)AEC III.6.2 + II.2.3.)

Intuitively, κ(P, σ) measures "the Galois twist that appears when you try to divide P by m". If P is divisible inside K (P ∈ mE(K)), Q can be chosen K-rational, so there is no twist. If not, Q lives in a genuine extension field, and the difference by which σ moves Q shows up in E[m] ── that is the picture.

Proposition (basic properties of the Kummer pairing) AEC VIII.1.2

(a) κ is well-defined. (b) κ is bilinear. (c) The left kernel is mE(K). (d) The right kernel is GK/L, where

L = K([m]−1E(K)) = "the field obtained by adjoining all Q ∈ E(K) with [m]Q ∈ E(K)"

Hence κ induces a perfect pairing

E(K)/mE(K) × GL/K → E[m]

.

Proof (main line, with comments)

(a) Well-definedness. First, κ(P,σ) ∈ E[m]: [m](Qσ − Q) = Pσ − P = O (P is K-rational). Next, independence of the choice of Q: any other choice has the form Q + T (T ∈ E[m]) (since the difference vanishes when multiplied by m). Then

(Q+T)σ − (Q+T) = Qσ − Q + (Tσ − T) = Qσ − Q

In the last equality we used E[m] ⊂ E(K): T is K-rational, so Tσ = T. The assumption we arranged with the reduction lemma is already paying off here.

(b) Bilinearity. Linearity in P is clear from the definition (choose the Q's additively). In σ: for σ, τ ∈ GK/K,

κ(P, στ) = Qστ − Q = (Qσ − Q)τ + (Qτ − Q) = κ(P,σ)τ + κ(P,τ)

Here κ(P,σ) ∈ E[m] ⊂ E(K), so it is fixed by τ; hence κ(P,στ) = κ(P,σ) + κ(P,τ). Once again E[m] ⊂ E(K) is doing the work. This computation shows that "κ(P,·) is in general not a homomorphism but a 1-cocycle, and it becomes a homomorphism only when E[m] is rational" ── foreshadowing the viewpoint of Part 3 (cohomology).

(c) Left kernel = mE(K). If P = [m]Q with Q ∈ E(K), then Qσ = Q, so κ(P,·) ≡ O. Conversely, if κ(P,σ) = O for every σ, then Qσ = Q (∀σ ∈ GK/K), so Q ∈ E(K), and therefore P = [m]Q ∈ mE(K).

(d) Right kernel = GK/L. If σ fixes L, then every Q (with [m]Q ∈ E(K)) is a point over L, so Qσ = Q, i.e. κ(·,σ) ≡ O. Conversely, if κ(P,σ) = O for every P, then Qσ = Q for every Q with [m]Q ∈ E(K). Since L is generated by the coordinates of such Q, σ fixes L.

Finally, L/K is Galois: GK/K preserves the set [m]−1E(K) ([m]Q ∈ E(K) ⇒ [m]Qσ = ([m]Q)σ ∈ E(K)), so L is closed under conjugation. And by (d), σ ↦ κ(·,σ) gives an injective homomorphism

GL/K ↪ Hom( E(K), E[m] )

and the perfect-pairing claim follows.

∎
🔬 Between-the-lines note N1 ─ all 20 steps of (a)–(d) expanded: the convention for composing actions, descending to the quotient, the two injections, and a table of every place E[m] ⊂ E(K) is used →
The "translation" obtained at this point

By the general theory of perfect pairings, E(K)/mE(K) injects into Hom(GL/K, E[m]). Since E[m] is finite:

E(K)/mE(K) is finite ⟺ the extension L/K is finite

All that remains is to show that "L = K([m]−1E(K)) is a finite extension of K". The problem about rational points has become a problem about fields ── that is what STEP 1 achieves.

Section 05 ─ Step 2

Properties of the extension L/K ─ ramification is forbidden outside S

First, we fix the set of primes that can cause trouble.

S = { v : E has bad reduction at v } ∪ { v : v(m) ≠ 0 } ∪ MK∞
MK∞ = the set of infinite primes (archimedean absolute values)

It is essential that S is a finite set: once we fix a Weierstrass equation, for all but finitely many v the coefficients are v-integral and v(Δ) = 0, and E has good reduction thereAEC VIII.1.3. There are finitely many primes dividing m, and finitely many infinite primes.

Let us restate, in the form we will use, the weapon brought over from Ch. VII.

Proposition (reduction of m-torsion is injective) AEC VIII.1.4 = VII.3.1(b)

Let v be a finite prime with v(m) = 0, and suppose E has good reduction at v. Then the reduction map

E(Kv)[m] → Ẽv(kv)

is injective. (Its kernel E₁ is controlled by the formal group, which has no torsion prime to m〔AEC IV §6, VII.2.2〕.)

Proposition (properties of L) AEC VIII.1.5

Let L = K([m]−1E(K)).

(a) L/K is an abelian extension, and the exponent of its Galois group divides m.

(b) L/K is unramified outside S. That is, if v ∉ S, then L/K is unramified at v.

Proof (main line, with comments)

(a) follows immediately from the injection GL/K ↪ Hom(E(K), E[m]) of STEP 1. The right-hand side is an abelian group in which m times every element vanishes (because the values lie in E[m]), so GL/K is also abelian of exponent m.

(b) This is the crux. Take v ∉ S, choose one Q with [m]Q ∈ E(K), and set K′ = K(Q). L is the compositum of such fields K′, so it suffices to show that each K′/K is unramified at v (a compositum of unramified extensions is unramified).

Let v′ be a prime of K′ above v, and take any element σ of the inertia group Iv′/v ⊂ GK/K. "K′/K is unramified at v′" means "the inertia group acts trivially on K′", so we only need to show that σ does not move Q.

Since v ∉ S, E has good reduction at v (the same Weierstrass equation is minimal and nonsingular at v′ too), and there is a reduction map E(K′v′) → Ẽ(k′v′). By the very definition of the inertia group, σ acts trivially on the residue field k′v′. Therefore

(Qσ − Q)˜ = Q̃σ − Q̃ = Q̃ − Q̃ = Õ (after reduction the displacement is invisible)

On the other hand, [m](Qσ − Q) = ([m]Q)σ − [m]Q = O ([m]Q is K-rational), so Qσ − Q ∈ E[m]. So Qσ − Q is "an m-torsion point that also lies in the kernel of reduction". Since v(m) = 0, VIII.1.4 applies, and the only such point is O:

Qσ − Q = O, that is, Qσ = Q

Hence the inertia group fixes Q, and K′ = K(Q) is unramified at v. Since this holds for every v ∉ S and every v′ above v, (b) follows.

∎
🔬 Between-the-lines note N2 ─ fully expanded: construction of the reduction map (primitive coordinates) and proof of Galois compatibility, the unramifiedness criterion via inertia groups, and the finiteness of S →
? What is so remarkable about this argument?

"Ramification of L/K" is purely global, field-theoretic information. It is forbidden by the geometric fact that "on the reduced curve, the inertia group cannot move anything" ── the local (reduction at each prime) constrains the global (the shape of the field extension), a typical pattern of arithmetic geometry. Note that the proof of (b) does not use the assumption E[m] ⊂ E(K) (AEC also points this out). This fact will be reused as is in Part 5 when we prove the finiteness of the Selmer group.

Section 06 ─ Step 3

Finiteness from field theory ─ the heart of number theory

Proposition AEC VIII.1.6

Let K be a number field, S ⊂ MK a finite set containing MK∞, and m ≥ 2. Let L/K be "the largest abelian extension of exponent m unramified outside S". Then L/K is a finite extension.

The proof has 5 stages. Pay attention to which classical theorem is at work in each stage.

Proof (main line, with comments)

(i) We may assume μm ⊂ K. Let K′ = K(μm) and let S′ be the set of primes above S. If the proposition holds for K′, then LK′/K′ is abelian of exponent m and unramified outside S′, hence finite, so L/K is finite too. From now on assume μm ⊂ K.

(ii) We may enlarge S. Enlarging S only makes L bigger, so it suffices to prove it for a larger S. So, using the finiteness of the ideal class group, we add to S the primes dividing representative ideals a₁, …, ah of the class group, so that the ring of S-integers

RS = { a ∈ K : v(a) ≥ 0 (∀v ∉ S) }

becomes a principal ideal domain (PID). We also add the primes dividing m, so that v(m) = 0 (∀v ∉ S).

(iii) Kummer theory. In a field of characteristic 0 containing μm, the maximal abelian extension of exponent m is obtained by "adjoining m-th roots of all elements" (see a field theory textbook, or AEC Exercise 8.4). So L is "the largest subfield unramified outside S" of K(m√a : a ∈ K×). We determine which m√a give unramified extensions. For v ∉ S we have v(m) = 0, and the discriminant of the polynomial Xm − a is ±mmam−1, so:

Kv(m√a)/Kv is unramified ⟺ ordv(a) ≡ 0 (mod m)

Hence L is generated only by m-th roots of elements of the following set:

TS = { a ∈ K×/(K×)m : ordv(a) ≡ 0 (mod m) (∀v ∉ S) }
L = K(m√a : a ∈ TS)

It remains to show that TS is a finite set; then by Kummer theory [L : K] is also finite.

(iv) S-units surject onto TS. Consider the natural map RS× → TS. Let a ∈ K× represent an element of TS. The condition ordv(a) ≡ 0 (mod m) (∀v∉S) means "the ideal aRS is the m-th power of an ideal of RS" (prime ideals of RS ⟷ v ∉ S). Since RS is a PID, there is b ∈ K× with aRS = bmRS; setting u = a/bm, we get u ∈ RS×, and a and u are in the same class in K×/(K×)m. Hence we get a surjection

RS×/(RS×)m ↠ TS

(it is in fact an isomorphism, but surjectivity is enough).

(v) Dirichlet's S-unit theorem. RS× is finitely generated (concretely μ(K) × ℤ#S−1), so RS×/(RS×)m is finite, and hence TS is finite. This completes the proof.

∎
🔬 Between-the-lines note N3 ─ fully expanded: both directions of the local unramifiedness criterion "ordv(a) ≡ 0 (mod m)", every line of the PID reduction, and the derivation of the equality [LK,S:K] = m#S →
A quantitative supplement (a sense of efficiency)

From the structure theorem in (v), |RS×/(RS×)m| = m#S (when μm ⊂ K), so for the enlarged S we get the explicit upper bound [L : K] ≤ m#S. In other words, the weak MW theorem even gives an explicit upper bound of the form "the order of E(K)/mE(K) is at most m2·(some computable number)".

? Why do we need both the "class number" and the "units"?

Elements of TS are subject only to the condition "all valuations are multiples of m". To rewrite them in the form "m-th power × unit", we need both the ability to take m-th roots at the level of ideals (being a PID = having killed the class group) and the remaining unit part being of finite type (the S-unit theorem). Finiteness of the class number controls "the gap between ideals and elements", and the unit theorem controls "the invertible part of elements" ── the two great finiteness theorems of algebraic number theory are each used exactly once, in different roles. A beautiful division of labor.

Section 07

Completing the proof, and two noteworthy remarks

Proof of the weak Mordell–Weil theorem (assembly)

By the reduction lemma (STEP 0), assume E[m] ⊂ E(K). Let L = K([m]−1E(K)). By the perfect pairing (STEP 1), E(K)/mE(K) is finite if and only if GL/K is finite. By STEP 2, L/K is abelian of exponent m and unramified outside the finite set S. By STEP 3, such an extension is of finite degree. Hence E(K)/mE(K) is finite.

∎ (AEC VIII.1.1)
🔬 Between-the-lines note N3 §09 ─ the "zero-gap" assembly joining N0–N3, and a complete list of the external theorems the proof cites →

Remark 1: an alternative proof via Minkowski AEC VIII.1.7

Instead of STEP 3, one can use the Minkowski–Hermite theorem, "there are only finitely many extensions of K of bounded degree unramified outside S". Indeed, the Galois conjugates of Q ∈ [m]−1E(K) all have the form Q + T (T ∈ E[m]), so the degree is uniformly bounded by [K(Q) : K] ≤ m², and finitely many candidates for K(Q) ⇒ the compositum L is finite. This viewpoint gives another intuition for "why it is finite" (boundedness of discriminants).

Remark 2: what exactly is "not computable"? AEC VIII.1.8

In fact GL/K is completely computable (if you trace the proof above explicitly). Then all elements of the right-hand side of the injection E(K)/mE(K) ↪ Hom(GL/K, E[m]) can be written down as well. The only thing that cannot be computed is deciding "which elements of the right-hand side actually come from rational points". All of the ineffectivity of the Mordell–Weil theorem is concentrated here, and the Selmer group was invented to attack exactly this point (Part 5). Be sure to keep this remark in mind before moving on to Part 5.

Section 08

Checking everything on an example ─ E : y² = x³ − x, m = 2

We carry the abstract theory all the way through on one curve. K = ℚ, m = 2. This curve has Δ = 64, and E[2] = {O, (0,0), (1,0), (−1,0)} is entirely ℚ-rational, so the theory runs right away without the reduction lemma. Moreover, E(ℚ) consists of exactly these 4 points (rank 0; this can be proved by the methods of Part 5, so we accept it here).

S = {2, ∞} (Δ = 64, so the only bad reduction is at 2; m = 2 also divides only 2)

Actually computing L = ℚ([2]⁻¹E(ℚ))

For each P ∈ E(ℚ), we find a solution Q of [2]Q = P. The duplication formulaAEC III.2.3(d), with A = −1, B = 0, gives:

x([2]Q) = (x² + 1)² / ( 4(x³ − x) ) (x = x(Q))

For example, take P = (1, 0). Rearranging x([2]Q) = 1 gives x⁴ − 4x³ + 2x² + 4x + 1 = 0. This folds beautifully into a square:

x⁴ − 4x³ + 2x² + 4x + 1 = (x² − 2x − 1)² ⇒ x = 1 ± √2
y² = x³ − x = 2(1+√2)² ⇒ y = ±√2(1+√2) (when x = 1+√2)

So the halves of (1,0) live in ℚ(√2). Computing the other points the same way:

P ∈ E(ℚ)Q (one solution of [2]Q = P)K(Q)
OQ ∈ E[2] ⊂ E(ℚ)ℚ
(0, 0)(i, 1−i), etc.ℚ(i)
(1, 0)(1+√2, √2(1+√2)), etc.ℚ(√2)
(−1, 0)(−1+√2, i√2(√2−1)), etc.ℚ(i, √2)
L = ℚ(i, √2), GL/ℚ ≅ (ℤ/2ℤ)²

Comparing with the theory's predictions

  • Abelian of exponent 2? Gal ≅ (ℤ/2)². ✓
  • Unramified outside S = {2,∞}? ℚ(i,√2) = ℚ(ζ₈) (the field of 8th roots of unity), whose discriminant is a power of 2. The only ramified finite prime is 2. ✓ Exactly as the theory (VIII.1.5b) says.
  • Is it a perfect pairing? |E(ℚ)/2E(ℚ)| = 4, |GL/ℚ| = 4, E[2] ≅ (ℤ/2)². A 4×4 pairing with values in (ℤ/2)², with both kernels vanishing ── the sizes match too. ✓

The abstract L = K([m]−1E(K)) turns out in practice to be such a small, concrete field (the cyclotomic field ℚ(ζ₈)!). With this feeling in hand, you won't be surprised in Part 5 when finite sets like K(S,2) = {±1, ±2} appear.

Exercises

Exercises

★ = basic (checking definitions and proofs), ★★ = standard (work it out by hand), ★★★ = advanced (build the argument yourself). Every problem has a solution or an outline. Aim to try on your own for 15 minutes first.

Problem 1★ Basic

In the proof that the Kummer pairing is well-defined (VIII.1.2a), the assumption E[m] ⊂ E(K) was used essentially in exactly one place. Identify that place. Also, if this assumption is dropped, as what kind of object does κ(P,σ) survive? (Hint: how does the value change depending on the choice of Q?)

Open the solution

It was used in the part "for another choice Q + T (T ∈ E[m]), Tσ = T". Because E[m] ⊂ E(K), σ fixes T. If the assumption is dropped, replacing Q by Q + T changes the value of κ to (Q+T)σ − (Q+T) = (Qσ − Q) + (Tσ − T), a shift by Tσ − T. Since σ ↦ Tσ − T is a coboundary (a trivial 1-cocycle), κ(P,·) is no longer well-defined as a "map", but it survives as a well-defined cohomology class of 1-cocycles. This is why δ : E(K)/mE(K) → H¹(G, E[m]) can be defined in the general situation in Part 3.

Problem 2★ Basic

Without looking at the text, reconstruct on your own the argument λP = λP′ ⇒ P ≡ P′ (mod mE(K)) from the proof of the reduction lemma. In particular, state explicitly where you use the fact that "a Galois-invariant K-point is a K-point".

Open the solution

λP(σ) = λP′(σ) ⟺ QPσ − QP = QP′σ − QP′ ⟺ (QP − QP′)σ = QP − QP′. This holds for all σ ∈ GL/K. Since QP, QP′ ∈ E(L), their difference is also a point of E(L), and a GL/K-invariant L-point is a K-point (by Galois theory its coordinates descend to K). So R := QP − QP′ ∈ E(K). Since [m]R = P − P′, we get P − P′ ∈ mE(K).

Problem 3★★ Standard

The proof of unramifiedness (VIII.1.5b) needed the condition v(m) = 0 (v does not divide m). If this condition fails (p = char kv divides m), which step of the proof breaks down? Explain in the language of formal groups (AEC IV §6).

Open the solution

The step that breaks is "Qσ − Q ∈ E[m] ∩ (kernel of reduction) ⇒ Qσ − Q = O" (the application of VIII.1.4). The kernel of reduction E₁ is isomorphic to the formal group Ê(M), and Ê(M) has no torsion of order prime to p, but it can have torsion of p-power order (e.g. over a ramified extension of ℚp). If p | m, E[m] has a p-part, so there can be points other than O that are "m-torsion and in the kernel of reduction", and injectivity is no longer guaranteed. In fact, when m = p, K([p]⁻¹E(K))/K can ramify even above a prime p of good reduction. This is why we put "the primes dividing m" into S.

Problem 4★★ Standard

Let E : y² = x³ − x and P = (−1, 0). Derive the quartic equation satisfied by the x-coordinate of Q with [2]Q = P, check that it is (x² + 2x − 1)², and determine the coordinates of Q and the field ℚ(Q) (that is, fill in the last row of the table in the text yourself).

Open the solution

By the duplication formula, (x²+1)² / (4(x³−x)) = −1, which rearranges to x⁴ + 4x³ + 2x² − 4x + 1 = 0. Comparing expansions confirms (x² + 2x − 1)² = x⁴ + 4x³ + 2x² − 4x + 1 (expanding (x²+2x−1)²: x⁴+4x³+4x²−2x²−4x+1). So x = −1 ± √2. For x = −1+√2, y² = x³ − x = x(x−1)(x+1) = (−1+√2)(−2+√2)(√2) = −2(√2−1)² < 0 (negative over the reals), so y = ± i√2(√2−1). Hence Q = (−1+√2, i√2(√2−1)) and ℚ(Q) = ℚ(i, √2) (a degree-4 extension). For this P alone, the half point lies in neither ℚ(i) nor ℚ(√2), and the compositum is needed.

Problem 5★★ Standard

In the proof of VIII.1.6 we built a surjection RS×/(RS×)m ↠ TS, and AEC remarks that "it is in fact an isomorphism". Prove injectivity. That is, show that if u ∈ RS× is an m-th power in K× (u = bm, b ∈ K×), then b ∈ RS×.

Open the solution

For every v ∉ S, m·ordv(b) = ordv(bm) = ordv(u) = 0 (since u is an S-unit). So ordv(b) = 0 for all v ∉ S, and b ∈ RS×. In other words, if u lies in (K×)m, it already lies in (RS×)m, so the kernel is trivial. Together with surjectivity, RS×/(RS×)m ≅ TS.

Problem 6★★★ Advanced

(Complete the alternative proof via MinkowskiAEC VIII.1.7.) Assume E[m] ⊂ E(K). For Q ∈ [m]−1E(K), prove the degree bound [K(Q) : K] ≤ m². Then, granting the Hermite–Minkowski theorem "there are only finitely many extensions of bounded degree unramified outside S", deduce that L = K([m]−1E(K)) is of finite degree.

Open the outline of the solution

Degree bound: for σ ∈ GK/K, [m](Qσ − Q) = ([m]Q)σ − [m]Q = O, so Qσ ∈ { Q + T : T ∈ E[m] }. So Q has at most #E[m] = m² Galois conjugates, and the minimal polynomial of (the coordinates of) Q has degree at most m². Hence [K(Q) : K] ≤ m².

Finiteness: each K(Q) is unramified outside S by the same argument as VIII.1.5b (that argument does not use E[m] ⊂ E(K)). By Hermite–Minkowski there are only finitely many extensions of degree ≤ m² unramified outside S, so the candidate fields K(Q₁), …, K(Qt) are finite in number. L is their compositum, so [L : K] ≤ Π [K(Qi) : K] < ∞.

Comparison: the proof in the text (Kummer theory) derives finiteness from the structure "abelian of exponent m", whereas this one pushes through using only "uniform boundedness of the degree". Note that both need "unramifiedness" (STEP 2) in common.
