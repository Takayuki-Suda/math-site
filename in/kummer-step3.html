Section 02

前提の固定（J1–J4）

前提 J1 ─ 部分群と商の設定

G を射有限群、M を離散 G-加群（N0 §04）とする。inf–res 定理では N ⊴ G を開正規部分群とする（このシリーズの応用はすべてこの場合。 N0 Step 9 で検証済みの事実：MN は mσN := mσ により G/N-加群になる──代表の取り替えと well-defined 性にN の正規性が効く）。 res は正規性のいらない操作なので、任意の閉部分群 H ≤ G に対して定める （惰性群 Iv̄ がこの場合）。 応用では N = GK/L（L/K 有限次 Galois）で G/N ≅ GL/Kweakmw N1 前提Q4 / ANT IV.1.2。

前提 J2 ─ 分解群・惰性群と延長の共役性 weakmw N2 前提R2 / ANT I §9・II §9

v を K の有限素点、v̄ をその K への延長とする。 分解群 Dv̄/v = { σ : v̄∘σ = v̄ } と惰性群 Iv̄/v ⊂ Dv̄/v （剰余体に恒等を誘導するもの）は G の閉部分群である。 v の延長全体には G が推移的に作用しANT II.8.1（の K への極限）、 v̄′ = v̄∘σ のとき定義から直ちに

Iv̄′/v = σ−1 Iv̄/v σ　（分解群も同様）

すなわち延長の取り替えは惰性群の共役である。

前提 J3 ─ weakmw N2 の部品（還元と惰性） weakmw N2 §04–§05 / AEC VIII.1.5(b)

S := {悪い還元の素点} ∪ { v : v(m) ≠ 0 } ∪ MK∞ とする。 weakmw N2 は次を飛躍ゼロで証明済み：v ∉ S、延長 v̄、σ ∈ Iv̄/v、 [m]Q = P ∈ E(K) ならば Qσ = Q（§05 Step 3–9。 道具は原始座標による還元写像とその Galois 両立性（§04）、 E[m] が良い還元・v ∤ m の下で還元で単射に移ること）。 しかもこの議論は E[m] ⊂ E(K) を使っていない。

Section 03

inf と res の構成（行間①）

1

res の構成：閉部分群 H ≤ G に対し、制限 res : H¹(G, M) → H¹(H, M), [c] ↦ [c|H] は well-defined な群準同型。

▸ 根拠　M は作用の制限で離散 H-加群（固定化群は H の中でも開：開集合との共通部分）。c|H がコサイクル：条件 cστ = cστ + cτ は特に σ, τ ∈ H の組で成立。連続性：連続写像の制限は連続。コバウンダリの制限はコバウンダリ（同じ m が効く）ので類の写像として well-defined。準同型性：制限は点ごとの和と可換。正規性はどこにも使っていないことに注意（§06 で惰性群に使うための確認）。

2

inf の構成：開正規部分群 N ⊴ G に対し、引き戻し inf : H¹(G/N, MN) → H¹(G, M), (inf c̄)σ := c̄σN は well-defined な群準同型。

▸ 根拠　MN が G/N-加群であることは N0 Step 9 で検証済み（正規性）。コサイクル条件：(inf c̄)στ = c̄(σN)(τN) = (c̄σN)τN + c̄τN = ((inf c̄)σ)τ + (inf c̄)τ（MN への G/N の作用の定義 mσN = mσ を戻しただけ）。連続性：inf c̄ は各剰余類 σN（開集合）上で定数、つまり局所定数。コバウンダリを保つ：c̄σN = mσN − m（m ∈ MN）の引き戻しは σ ↦ mσ − m、同じ m の G-コバウンダリ。準同型性は点ごと。

3

res ∘ inf = 0（合成が消えること──完全列の「⊇ 側」の半分）。

▸ 根拠　η ∈ N に対し (inf c̄)η = c̄ηN = c̄eN = 0。最後の等号は「コサイクルは単位元で消える」（N0 Step 3 を商群 G/N に適用）。つまり制限はコバウンダリどころかゼロ写像そのもの。

Section 04 ─ Main

inf–res 完全列（行間②）

定理（inflation–restriction） AEC B.2.4

G 射有限群、N ⊴ G 開正規部分群、M 離散 G-加群とすると、次は完全：

0 → H¹(G/N, MN) →inf H¹(G, M) →res H¹(N, M)

（Galois の言葉では N = GK/L：0 → H¹(GL/K, MGK/L) → H¹(GK/K, M) → H¹(GK/L, M)。）

4

inf の単射性（左端で完全）。

▸ 根拠　inf c̄ が G のコバウンダリ、つまり c̄σN = mσ − m（∀σ、ある m ∈ M）とする。η ∈ N を入れると左辺は c̄eN = 0（Step 3）なので mη = m（∀η ∈ N）、つまり m ∈ MN。すると σN ↦ mσN − m は MN の元 m が定める G/N-コバウンダリで、c̄ に一致する。よって [c̄] = 0。

5

ker res ⊆ im inf（中央で完全。逆向きは Step 3）。

▸ 根拠　res[c] = 0 とする：ある m ∈ M で cη = mη − m（∀η ∈ N）。c′ := c − (m のコバウンダリ) とおくと [c′] = [c] かつ c′|N = 0。以下 c′ を調べる。（イ）左剰余類上で定数：η ∈ N, σ ∈ G でコサイクル条件を (η, σ) の順に使うと c′ησ = (c′η)σ + c′σ = c′σ。（ロ）値が MN に入る：(σ, η) の順に使うと c′ση = (c′σ)η + c′η = (c′σ)η。一方 N の正規性で ση ∈ σN = Nσ なので（イ）より c′ση = c′σ。等置して (c′σ)η = c′σ（∀η ∈ N）。（ハ）c̄σN := c′σ は（イ）（ロ）より well-defined な写像 G/N → MN で、コサイクル条件は c′ の条件から降下（N0 Step 9 と同じ検証）。連続性：c′ は連続（連続コサイクルと連続コバウンダリの差）、G/N は有限離散（N が開）なので c̄ は自動的に連続。（ニ）定義から inf c̄ = c′。よって [c] = [c′] = inf[c̄]。∎

6

N0 §04 への返礼：これで「H¹cont(G, M) = ⋃U inf(H¹(G/U, MU)) の和集合は重なりなく増大する」が証明済みになった。

▸ 根拠　N0 §04 の why 枠が「inf が類のレベルで単射であることは N3 の帰結」と予告していた宿題。Step 4 の単射性がその中身。U ⊆ U′ の2段の inf の整合（inf の推移性）は定義の合成 c̄σU = c̄̄σU′ を並べるだけで、途中の商を経由しても値が変わらないことも定義から従う。

? この完全列は「何と何を比較する装置」か

inf–res は「有限段階 G/N の情報」と「無限段階 G の情報」の橋です。 左端の単射性は「有限段階で違う類は無限段階でも違う」、中央の完全性は 「無限段階の類が N 上で消えるなら、実は有限段階から来ている」。 第2部（有限群 GL/K の手計算）と第3部（絶対 Galois 群の一般論）が 往復できる根拠が、この2つの主張に凝縮されています。

Section 05

帰着補題の正体 ─ 可換図式の検証（行間③）

本編 §05 の設定を固定します：L/K を有限次 Galois 拡大、E[m] ⊂ E(L)、 N := GK/L（開正規）、G/N ≅ GL/K。 M = E[m] に対し MN = E[m] ∩ E(L) = E[m] なので、inf–res は

0 → H¹(GL/K, E[m]) →inf H¹(GK/K, E[m]) →res H¹(GK/L, E[m])

となります（本編 §05 の図式の下段）。上段は Φ := ( E(K) ∩ mE(L) )/mE(K) を核とする 0 → Φ → E(K)/mE(K) → E(L)/mE(L)。検証すべきは2つの四角の可換性です。

7

右の四角：res ∘ δK = δL ∘（自然写像 E(K)/mE(K) → E(L)/mE(L)）。

▸ 根拠　P ∈ E(K) を取り、[m]Q = P なる Q を1つ選ぶ。δK(P) の代表は σ ↦ Qσ − Q（σ ∈ GK/K）、その GK/L への制限は同じ式を σ ∈ GK/L で読んだもの。一方 P を E(L) の元と見た δL(P) も、同じ Q を持ち上げに選べば同じ式（N0 Step 13 の選択自由）。コサイクルが文字通り一致するので類も一致。

8

左の縦矢印の構成：P ∈ E(K) ∩ mE(L) なら δK(P) ∈ ker res = im inf であり、inf の逆像の明示形は第2部の λP そのもの：

λP ∈ Z¹(GL/K, E[m]),　λP(σ|L) = Qσ − Q　（Q ∈ E(L), [m]Q = P）

▸ 根拠　P ∈ mE(L) だから持ち上げ Q を E(L) の中で選べる。すると σ ∈ GK/L では Qσ = Q なので res δK(P) = 0、完全性（Step 5）より δK(P) ∈ im inf。しかもこの代表コサイクルは：値 Qσ − Q が E[m] に入り（[m] を当てると Pσ − P = O）、Q の座標が L の元なので σ の作用は制限 σ|L だけで決まる（L/K Galois なので Qσ ∈ E(L)）。つまり GL/K 上の写像として well-defined で、これは Step 5 の構成（c′ を剰余類ごとに読む）を今の c に適用した結果と一致する。weakmw N0 で手作りした λP の式と文字まで同じweakmw N0 §04 / AEC VIII.1.1.1。

9

帰着補題の3行証明の検証：λ : Φ → H¹(GL/K, E[m]), P mod mE(K) ↦ [λP] は well-defined な単射。右辺は有限集合。よって Φ は有限。

▸ 根拠　well-defined 性と単射性は図式追跡：inf[λP] = δK(P)（Step 8）で、δK は E(K)/mE(K) 上単射（N1 Step 10）、inf も単射（Step 4）。よって [λP] = [λP′] ⟺ δK(P) = δK(P′) ⟺ P ≡ P′ (mod mE(K))。有限性：GL/K も E[m] も有限集合なので、コサイクルは有限集合から有限集合への写像の一部、Z¹ ⊆ Map(GL/K, E[m]) は有限、その商 H¹ も有限。第2部・帰着補題（VIII.1.1.1）で「E(L)/mE(L) 有限 ⇒ E(K)/mE(K) 有限」と使った核 Φ の有限性が、コホモロジーの言葉で再証明された。

? 第2部の「手計算」は何をしていたのか

第2部 STEP 0 の λP の単射性証明は、いま見た「図式の可換性＋inf の単射性＋δ の単射性」を すべて素手で同時に実行していたことになります。一般論の利益は分業です： 単射性は3つの部品に分かれ、各部品（Step 4・N1 Step 10・Step 7–8）は他の場面でも再利用できます。 §06 以降の「不分岐」がまさにその再利用の現場です。

Section 06

共役補題 ─「不分岐」は延長の取り方に依らない（行間④）

定義（不分岐なコホモロジー類・再掲） AEC VIII §2

v を K の有限素点、v̄ を延長、Iv̄/v ⊂ G をその惰性群（J2。閉部分群なので Step 1 の res が使える）とする。 ξ ∈ H¹(G, M) が v で不分岐とは resIv̄/v(ξ) = 0 ∈ H¹(Iv̄/v, M) となること。

この定義が v̄ に依っては困ります。J2 より別の延長の惰性群は共役 σ−1 Iv̄/v σ なので、次の補題が「依らない」ことのすべてです。

補題（共役補題） AEC X.4.1.1 / 演習B.6 の中身

c ∈ Z¹(G, M)、H ≤ G を閉部分群、σ ∈ G とする。 c|H が H のコバウンダリならば、c|σ⁻¹Hσ も σ−1Hσ のコバウンダリである。 しかも「証人」は明示的に書ける：cη = mη − m（∀η ∈ H）ならば

n := mσ − cσ　に対し　cτ = nτ − n　（∀τ ∈ σ−1Hσ）
10

証明：στ = ησ の2通り展開。

▸ 根拠　τ ∈ σ−1Hσ を取り、η := στσ−1 ∈ H とおくと στ = ησ。コサイクル条件で cστ を2通りに書く：(1) cστ = (cσ)τ + cτ。(2) cησ = (cη)σ + cσ = (mη − m)σ + cσ = mησ − mσ + cσ（仮定と R1(i)(ii)）。等置して整理すると cτ = mησ − mσ + cσ − (cσ)τ。一方 n := mσ − cσ に対し nτ − n = mστ − (cσ)τ − mσ + cσ。στ = ησ より mστ = mησ、2つの式は一致する。∎（なお N0 Step 4 の逆元公式 cσ⁻¹ = −(cσ)σ⁻¹ を経由する流儀もあるが、上の2通り展開の方が短い。）

系（不分岐性の well-defined 性）

ξ = [c] ∈ H¹(G, M) と v の2つの延長 v̄, v̄′ に対し、 resIv̄/v(ξ) = 0 ⟺ resIv̄′/v(ξ) = 0。 根拠：J2 で Iv̄′/v = σ−1 Iv̄/v σ となる σ があり、 「制限がコバウンダリ」という条件が共役補題で両方向に移送される （⟸ は σ を σ−1 に replace して同じ補題）。 よって「ξ は v で不分岐」は延長に依らない概念であり、本編 §06 の定義 box の 括弧書き（AEC X.4.1.1 / 演習B.6）が検証済みになった。

Section 07

命題 VIII.2.1 の再構成（行間⑤）

命題 AEC VIII.2.1

S = {悪い還元} ∪ { v : v(m) ≠ 0 } ∪ MK∞ とする。 δ : E(K)/mE(K) → H¹(G, E[m]) の像の各類は、S に入らないすべての有限素点 v で不分岐である。

11

主張のコサイクル化：示すべきは「v ∉ S、σ ∈ Iv̄/v に対し cσ = Qσ − Q = O」。これが言えれば制限はコバウンダリどころかゼロコサイクル。

▸ 根拠　δ(P) の代表は cσ = Qσ − Q（[m]Q = P、N1 Step 13）。§06 の系により延長 v̄ は1つ選べば十分。「コサイクルとして 0」⇒「類として 0」は自明の向き。なお定義（§06）はコバウンダリで消えることしか要求しないが、ここでは強い形（恒等的に O）が成り立つ。

12

weakmw N2 の部品の接続：v ∉ S、σ ∈ Iv̄/v ならば Qσ = Q。よって命題が従う。

▸ 根拠　これはまさに J3 で引用した weakmw N2 §05 Step 3–9 の主定理の中身：Qσ − Q ∈ E[m]（[m] を当てると Pσ − P = O）、還元写像の Galois 両立性（weakmw N2 §04）と「惰性の元は剰余体に恒等を誘導する」ことから還元 red(Qσ − Q) = Õ、そして v ∉ S（良い還元かつ v ∤ m）では E[m] は還元で単射に移るので Qσ − Q = O。この鎖のすべての環は weakmw N2 で飛躍ゼロで検証済みであり、E[m] ⊂ E(K) の仮定はどこにも使われていない（本編 §06 の証明の括弧書きの確認）。∎

これで本編 §06 の「圧縮形」が、すべての部品込みで検証済みになりました：

E(K)/mE(K) ↪ H¹(GK/K, E[m]; S) := { ξ : S の外のすべての有限素点で不分岐 }
単射性は N1 Step 10、像が右辺に入ることが本節、右辺が部分群であることは res が準同型（Step 1）だから核の共通部分として明らか。
このノートで証明しないこと（スコープ宣言）

右辺 H¹(G, E[m]; S) の有限性はここでは証明しない。 本編の言葉どおり「中身は第2部 STEP 3 の議論そのもの」で、正式には AEC X.4.3 として第5部（本編Ⅴ Selmer群とШ）で引用・証明されるAEC X.4.3。 weakmw 側の実体は weakmw N3（Kummer 対応・類数の有限性・S-単数）だった。 つまり有限性の証明はすでにこのシリーズの別の場所にある──ここで足すべき新しい行間はない。

Section 08

Selmer 群への布石 ─ 局所条件の言語（行間⑥）

振り返ると、このノートで組んだ道具は全部「大域の類を局所の部分群に制限して条件を課す」 という1つの型に奉仕しています：

道具役割このノートでの証明
res : H¹(G, M) → H¹(H, M)局所条件を「課す」装置（H = Iv̄, Dv̄, GK/L…）Step 1
共役補題条件が「場所 v」だけで決まる（延長の選択に依らない）保証Step 10
inf–res 完全列条件を満たす類の「出どころ」を有限段階に特定する装置Step 4–5

Selmer 群（本編Ⅴ）はこの型の精密化です。「不分岐」は惰性群 Iv への制限で課す条件でしたが、 Selmer 群は分解群 Gv 全体への制限で課します：

S(m)(E/K) = { ξ ∈ H¹(G, E[m]) : ∀v で resGv(ξ) が局所点 E(Kv)/mE(Kv) から来る }
「不分岐」＝惰性で消える　⊂　「局所可解」＝分解群レベルで δ の像に入る（正確な定義と比較は本編Ⅴ §03–§04）

2つの条件の関係（ほとんどの v で「局所可解 ⇒ 不分岐」、有限個の v の補正で Selmer 群が 有限の箱 H¹(G, E[m]; S) に入ること）が、本編Ⅴの有限性証明（AEC X.4.2–X.4.3）の骨格です。 res の準同型性・共役 well-defined 性・inf–res は、そこで断りなく使われます── その断りのなさを、このノートが正当化しました。
