Between-the-lines notes ─ Descent and heights N2/N3

A complete proof of property (a) ─ addition and height
Translation doubles the height, at most

hx(P + P₀) ≤ 2hx(P) + C₁(P₀) ── the proof that Main IV Section 03 gave as "key points + gaps", written out completely with zero leaps, from handling the exceptional cases to a fully explicit form of the constant C₁. There's only one crux: bounding the y-term |bd| with the curve's equation itself.

TEXT: Silverman, AEC 2nd ed. ─ VIII.4.2(a) (fully expanded)

Main IV Descent N0 Descent theorem N1 Foundations of height N2 Property (a) addition N3 Property (b) doubling
Section 01

The gaps this note fills

  • ① Making explicit how to choose C₁ in the exceptional cases (P₀ = O, P ∈ {O, P₀, −P₀})
  • ② Every line of the computation turning the addition formula into the symmetric form ((xx₀+A)(x+x₀)+2B−2yy₀)/(x−x₀)²
  • ③ A term-by-term check of multiplying by the denominator d⁴d₀⁴ to get a fraction of integers
  • ④ The precise statement and proof of "cancelling only lowers the height"
  • ⑤ The complete argument bounding the troublemaker |bd| by M² (where the curve's equation is used)
  • ⑥ A fully explicit form of the constant C₁(P₀, A, B)

There are three premises, A1–A3. In particular A1 (the coordinate lemma of N1) is the foundation of every computation.

Section 02

Fixing the premises (A1–A3)

Premise A1 ─ shape of coordinates and height fully proved in N1

Any P ∈ E(ℚ) other than O can be written uniquely as P = (a/d², b/d³) (a, b ∈ ℤ, d ≥ 1, gcd(a,d) = gcd(b,d) = 1), and

H(x(P)) = max{ |a|, d² } =: M, b² = a³ + Aad⁴ + Bd⁶ (an equation of integers)

Also hx ≥ 0 and hx(P) = hx(−P).

Premise A2 ─ the addition formula AEC III.2.3(d)

For P = (x, y), P₀ = (x₀, y₀) with x ≠ x₀, setting λ = (y − y₀)/(x − x₀), x(P + P₀) = λ² − x − x₀. Note that on E, x(P) = x(P₀) ⟺ P = ±P₀ (only the two points (x, ±y) share the same x).

Premise A3 ─ elementary bounds on absolute values, and cancelling elementary number theory

|s + t| ≤ |s| + |t|, |st| = |s||t|. Moreover (gap ④): if t = N/D (N, D ∈ ℤ, D ≠ 0), then H(t) ≤ max{ |N|, |D| }.

Open the proof of H(t) ≤ max{|N|,|D|}

Let g = gcd(N, D) ≥ 1, p = N/g, q = ±D/g (sign chosen so q ≥ 1). Then t = p/q is the reduced representation. So H(t) = max{|p|, |q|} = max{|N|, |D|}/g ≤ max{|N|, |D|}. Cancelling (dividing by g) only ever works to lower the height ── this is why we can completely ignore cancelling in upper bounds. (Not so for lower bounds. That's the theme of N3.)

Section 03

The statement and the exceptional cases (gap ①)

Lemma (height property (a)) AEC VIII.4.2(a)

Fix P₀ ∈ E(ℚ). Then there is a constant C₁ = C₁(P₀, A, B) such that hx(P + P₀) ≤ 2hx(P) + C₁ for all P ∈ E(ℚ).

1

Case P₀ = O: C₁ = 0 works. From now on let P₀ = (a₀/d₀², b₀/d₀³) ≠ O.

▸ Reason h(P + O) = h(P) ≤ 2h(P) + 0. We used h(P) ≥ 0 (A1). The coordinate representation of P₀ is A1.

2

Case P ∈ { O, P₀, −P₀ }: if we take C₁ ≥ max{ h(P₀), h(2P₀) }, the inequality holds. From now on exclude these three points. Then x(P) ≠ x(P₀), so the formula of A2 can be used, and P + P₀ ≠ O.

▸ Reason If P = O, P+P₀ = P₀ and h(P₀) ≤ C₁ ≤ 2h(P)+C₁. If P = P₀, h(2P₀) ≤ C₁. If P = −P₀, P+P₀ = O and h(O) = 0 ≤ 2h(P)+C₁ (C₁ ≥ 0: values of h are ≥ 0). We removed at most three points, but C₁ can "swallow whole" the values at those three points ── an inequality of type (i) has slack in its constant term, so exceptions are nothing to fear. This is gap ①. x(P) ≠ x(P₀) is the contrapositive of the last claim in A2. P+P₀ = O ⟺ P = −P₀ is also already excluded.

Section 04

The symmetric form of the addition formula (gap ②)

3

Combine λ² − x − x₀ into a single fraction:

x(P + P₀) = (y − y₀)²/(x − x₀)² − (x + x₀) = [ (y − y₀)² − (x + x₀)(x − x₀)² ] / (x − x₀)²

▸ Reason A2 and a common denominator. x ≠ x₀ (Step 2), so the denominator isn't 0.

4

Expand the two chunks of the numerator:

(y − y₀)² = y² + y₀² − 2yy₀ = x³ + x₀³ + A(x + x₀) + 2B − 2yy₀
(x + x₀)(x − x₀)² = x³ + x₀³ − x²x₀ − xx₀²

▸ Reason Line 1: we added y² = x³+Ax+B and y₀² = x₀³+Ax₀+B (that both points lie on the curve). Line 2: we expanded (x−x₀)² = x²−2xx₀+x₀², multiplied by (x+x₀), and combined among the six terms −2x²x₀+x²x₀ = −x²x₀ and xx₀²−2xx₀² = −xx₀².

5

Taking the difference, x³ and x₀³ cancel:

numerator = x²x₀ + xx₀² + A(x + x₀) + 2B − 2yy₀ = (xx₀ + A)(x + x₀) + 2B − 2yy₀
∴ x(P + P₀) = [ (xx₀ + A)(x + x₀) + 2B − 2yy₀ ] / (x − x₀)²

▸ Reason Only the factorization x²x₀ + xx₀² = xx₀(x + x₀). The cubic terms vanished, leaving degree at most 2 in each variable ── the "2" in "height at most doubles" is this degree. This is the finished form of gap ② (the formula in the main part).

Section 05

Making it integral ─ multiplying by d⁴d₀⁴ (gaps ③④)

6

Substitute x = a/d², y = b/d³, x₀ = a₀/d₀², y₀ = b₀/d₀³ and multiply numerator and denominator by d⁴d₀⁴ to get x(P+P₀) = N/D, where

N = (aa₀ + Ad²d₀²)(ad₀² + a₀d²) + 2Bd⁴d₀⁴ − 2(bd)(b₀d₀)
D = (ad₀² − a₀d²)² (≠ 0)

▸ Reason Checking denominators term by term (gap ③): xx₀+A = (aa₀+Ad²d₀²)/(d²d₀²), x+x₀ = (ad₀²+a₀d²)/(d²d₀²), the product has denominator d⁴d₀⁴. Multiplying 2yy₀ = 2bb₀/(d³d₀³) by d⁴d₀⁴ gives 2bb₀dd₀ = 2(bd)(b₀d₀) ── exactly one power of each left over. (x−x₀)² = (ad₀²−a₀d²)²/(d⁴d₀⁴). Every term is cleared by the same d⁴d₀⁴. N, D ∈ ℤ. D ≠ 0 is x ≠ x₀.

7

H(x(P + P₀)) ≤ max{ |N|, |D| }.

▸ Reason A3 (gap ④). N/D need not be in lowest terms, but for an upper bound we may ignore cancelling.

Section 06

Bounding ─ by M² (gaps ⑤⑥)

Set M := max{ |a|, d² } = H(x(P)). The only relations we use are |a| ≤ M and d² ≤ M (hence d ≤ M1/2 and d⁴ ≤ M²).

8

The three chunks not involving y are bounded by M straightforwardly:

|ad₀² + a₀d²| ≤ (d₀² + |a₀|)·M, |aa₀ + Ad²d₀²| ≤ (|a₀| + |A|d₀²)·M
|2Bd⁴d₀⁴| ≤ 2|B|d₀⁴·M², |D| = (ad₀² − a₀d²)² ≤ (d₀² + |a₀|)²·M²

▸ Reason The triangle inequality (A3) and |a| ≤ M, d² ≤ M. For example |ad₀²+a₀d²| ≤ d₀²|a| + |a₀|d² ≤ d₀²M + |a₀|M. For D we squared the first bound.

9

The crux (gap ⑤): |b| ≤ (1+|A|+|B|)1/2·M3/2, hence |bd| ≤ (1+|A|+|B|)1/2·M².

▸ Reason Apply the triangle inequality to the integer equation b² = a³ + Aad⁴ + Bd⁶ from A1: |b|² ≤ |a|³ + |A||a|d⁴ + |B|d⁶. All three terms are at most M³ (|a|³ ≤ M³, |a|d⁴ ≤ M·M², d⁶ = (d²)³ ≤ M³), so |b|² ≤ (1+|A|+|B|)M³. Take square roots and multiply by d ≤ M1/2. On its own b (≈ the y-coordinate) seems unrelated to M, but the equation "P lies on the curve" forces the upper bound |b| ~ M3/2 ── this is the only place in the whole proof (along with line 1 of Step 4) where the curve's equation acts quantitatively.

10

Combine and define κ:

|N| ≤ [ (|a₀| + |A|d₀²)(d₀² + |a₀|) + 2|B|d₀⁴ + 2|b₀|d₀·(1+|A|+|B|)1/2 ]·M²
κ := max{ the bracket above, (d₀² + |a₀|)² } ⇒ max{|N|, |D|} ≤ κ·M²

▸ Reason Substitute the bounds of Steps 8–9 into the three chunks of N and combine with the triangle inequality. |2(bd)(b₀d₀)| ≤ 2|b₀|d₀·|bd|. κ is a constant depending only on P₀ and A, B (independent of P).

11

Finish by taking logarithms:

H(x(P+P₀)) ≤ κ·M² = κ·H(x(P))² ⇒ h(P + P₀) ≤ 2h(P) + log κ
C₁(P₀, A, B) := max{ log κ, h(P₀), h(2P₀) }

▸ Reason Step 7 + Step 10, monotonicity of log and log(uv) = log u + log v. The final max merges in the exceptional cases of Step 2 (gaps ①⑥). Note also that κ ≥ (d₀²+|a₀|)² ≥ 1, so log κ ≥ 0.

∎
By-product: C₁(Q) = C₁(−Q)

−P₀ = (a₀/d₀², −b₀/d₀³), and the formula for κ only looks at b₀ through its absolute value. Moreover h(−P₀) = h(P₀) and h(−2P₀) = h(2P₀) (N1). So in the construction above C₁(P₀) = C₁(−P₀) holds automatically. The C₁′ = maxi C₁(−Qi) needed in the descent theorem (N0 Step 1) can be the same value as the representatives' own constant maxi C₁(Qi) ── so there was never any need to worry about signs.

? This proof has not a single lower bound

However small the denominator D gets, however much N/D cancels, it doesn't affect an upper bound (A3: cancelling only lowers the height). So the proof of (a) was a one-way street of just "bounding everything above by M²". In (b), on the other hand, we have to say that H(x(2P)) doesn't get too small, and we must control the amount of cancellation itself. The tool for that is two identities ── on to N3.
