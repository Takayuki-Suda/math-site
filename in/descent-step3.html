性質(b)の完全証明 ─ 倍加と高さ
Duplication quadruples the height, almost exactly

hx([2]P) ≥ 4hx(P) − C₂──下からの評価は、約分がどれだけ起きうるかの制御がすべてです。 本編が「f₂, g₂ も次数3の明示的な多項式」と書くにとどめた2本の恒等式を、 係数まで完全に書き下し、単項式ごとの検証表を付け、定数 C₂ の明示形と数値検算まで一気に仕上げます。

Section 02

前提の固定（B1–B3）

前提 B1 ─ 座標の形 N1 で完全証明済み

P ≠ O の x 座標は既約分数 x(P) = p/q（q = d² ≥ 1, gcd(p,q) = 1）で書け、 H(x(P)) = max{|p|, |q|} =: T ≥ 1。

前提 B2 ─ 倍加公式と2等分点 AEC III.2.3(d)

P = (x, y)、y ≠ 0 のとき x([2]P) = λ² − 2x、λ = (3x² + A)/(2y)。 また P ≠ O について [2]P = O ⟺ y = 0（接線が垂直になる点）。

前提 B3 ─ gcd の基本性質 初等整数論

δ | u かつ δ | v ⇒ δ | (su + tv)（∀s, t ∈ ℤ）。 gcd(p, q) = 1 ⇒ gcd(p⁷, q⁷) = 1（p⁷ と q⁷ を両方割る素数は p と q を両方割る）。 gcd(cu, cv) = |c|·gcd(u, v)。

Section 03

倍加公式の斉次化（行間①②）

補題（高さの性質 (b)） AEC VIII.4.2(b)

定数 C₂ = C₂(A, B) が存在して、すべての P ∈ E(ℚ) で hx([2]P) ≥ 4hx(P) − C₂。

1

例外の丸呑み（行間②）：E(ℚ)[2] := { P : [2]P = O } は高々4点。C₂ ≥ 4·max{ hx(P) : P ∈ E(ℚ)[2] } と取っておけば、[2]P = O の場合の不等式は自動的に成立。以後 [2]P ≠ O（特に P ≠ O, y ≠ 0）とする。

▸ 根拠　[2]P = O なる P ≠ O は y = 0（B2）、つまり x³ + Ax + B = 0 の有理根が x 座標。3次方程式の根は高々3個なので、O とあわせて高々4点──有限個だから max が取れる。この C₂ に対し h([2]P) = h(O) = 0 ≥ 4h(P) − C₂。P = O も 0 ≥ 0 − C₂ で成立。

2

倍加公式を x の有理式に直す：

x([2]P) = (3x² + A)²/(4y²) − 2x = [ (3x² + A)² − 8xy² ] / (4y²)
分子 = 9x⁴ + 6Ax² + A² − 8x(x³ + Ax + B) = x⁴ − 2Ax² − 8Bx + A²
分母 = 4y² = 4x³ + 4Ax + 4B

▸ 根拠　B2 と通分、y² = x³ + Ax + B の代入（分子で1回、分母で1回──ここで曲線の方程式を使い切り、以後は x だけの計算になる）。展開：9x⁴ − 8x⁴ = x⁴、6Ax² − 8Ax² = −2Ax²。

3

x = p/q を代入し、分子分母に q⁴ を掛けて斉次化する：

x([2]P) = F(p, q) / G(p, q)
F(X, Z) = X⁴ − 2AX²Z² − 8BXZ³ + A²Z⁴
G(X, Z) = 4X³Z + 4AXZ³ + 4BZ⁴

▸ 根拠　各項の次数を Z で埋めて4次斉次にしただけ（x⁴ → X⁴、−2Ax² → −2AX²Z² など）。F, G ∈ ℤ[X, Z]（A, B ∈ ℤ）なので F(p,q), G(p,q) ∈ ℤ。

4

G(p, q) = 4q⁴y² > 0。特に G(p, q) ≠ 0 で、Step 3 の分数は意味を持つ。

▸ 根拠　G(p,q) = 4q(p³ + Apq² + Bq³) = 4q·q³(x³ + Ax + B) = 4q⁴y²。y ≠ 0（Step 1）かつ q ≥ 1 なので正。「G の消滅 ⟺ 2等分点」という幾何が、分数の well-definedness という代数に翻訳されている。

Section 04

2本の恒等式 ─ f₂, g₂ まで明示する（行間③）

副補題（明示的な恒等式・完全版） AEC VIII.4.3

Δ′ = 4A³ + 27B² とおく。ℤ[A, B, X, Z] の恒等式として

f₁·F − g₁·G = 4Δ′·Z⁷,　　f₂·F − g₂·G = 4Δ′·X⁷

が成り立つ。ここで4本とも (X, Z) の3次斉次多項式で：

f₁ = 12X²Z + 16AZ³
g₁ = 3X³ − 5AXZ² − 27BZ³
f₂ = 4Δ′X³ − 4A²BX²Z + 4A(3A³ + 22B²)XZ² + 12B(A³ + 8B²)Z³
g₂ = −A²BX³ − A(5A³ + 32B²)X²Z − 2B(13A³ + 96B²)XZ² + 3A²(A³ + 8B²)Z³

「存在する」ではなく「これである」。検証は展開して比べるだけの有限計算です。 両辺とも (X, Z) の7次斉次式なので、第1恒等式は Z = 1 と置いた1変数の等式を確かめれば十分です （斉次式は非斉次化から一意に復元できる）。

第1恒等式の検証を開く（全行・手計算）

Z = 1 とおき、f₁F と g₁G を別々に展開する。

f₁F = (12X² + 16A)(X⁴ − 2AX² − 8BX + A²)
　= 12X⁶ − 24AX⁴ − 96BX³ + 12A²X² + 16AX⁴ − 32A²X² − 128ABX + 16A³
　= 12X⁶ − 8AX⁴ − 96BX³ − 20A²X² − 128ABX + 16A³

g₁G = (3X³ − 5AX − 27B)·4(X³ + AX + B)
　= 4[ 3X⁶ + 3AX⁴ + 3BX³ − 5AX⁴ − 5A²X² − 5ABX − 27BX³ − 27ABX − 27B² ]
　= 4[ 3X⁶ − 2AX⁴ − 24BX³ − 5A²X² − 32ABX − 27B² ]
　= 12X⁶ − 8AX⁴ − 96BX³ − 20A²X² − 128ABX − 108B²

X⁶, X⁴, X³, X², X の係数は完全に一致して差し引きで消え、定数項だけが残る：
f₁F − g₁G = 16A³ + 108B² = 4(4A³ + 27B²) = 4Δ′。✓

第2恒等式は項数が多いので、単項式 X7−kZk ごとに f₂F と g₂G の係数を並べた検証表を与えます：

単項式f₂F の係数g₂G の係数差
X⁷4Δ′04Δ′
X⁶Z−4A²B−4A²B0
X⁵Z²−4A(5A³+32B²)−4A(5A³+32B²)0
X⁴Z³−12B(9A³+64B²)−12B(9A³+64B²)0
X³Z⁴−4A²(2A³+9B²)−4A²(2A³+9B²)0
X²Z⁵−4AB(31A³+224B²)−4AB(31A³+224B²)0
XZ⁶4(3A⁶−2A³B²−192B⁴)4(3A⁶−2A³B²−192B⁴)0

8つの単項式のうち7つで係数がぴったり一致して消え、X⁷ の係数だけが 4Δ′ 残る── f₂F − g₂G = 4Δ′X⁷。✓（各係数の展開は「多項式の掛け算」だけの機械的計算です。 たとえば X⁶Z の係数：f₂F 側は f₂ の X²Z 係数 × F の X⁴ 係数 = −4A²B·1、 g₂G 側は g₂ の X³ 係数 × G の X³Z 係数 = (−A²B)·4。一致。他の行も同様に確かめられます。）

? 恒等式はどこから来るのか ─ 終結式と Δ²

F(X, 1) と G(X, 1) は Δ′ ≠ 0 のとき共通根を持ちません（共通根 x₀ は y = 0 かつ 倍加公式の分子分母の共通零点 ＝特異点の兆候）。互いに素な多項式には Euclid の互除法が「Bézout の証明書」 fF − gG = 定数 を返し、 分母を払うと上の恒等式になります。次数3のペアという制約の下で解は一意で、 現れる最小の定数が 4Δ′。ちなみに終結式を計算すると Res(F, G) = 256Δ′² = Δ²── 倍加写像の非退化性が判別式の言葉で二重に刻まれているわけです。 「射影空間の次数 d の射は高さをほぼ d 倍する」という一般定理AEC VIII.5.6の証明も、 この Nullstellensatz 証明書の高次元版です。

Section 05

約分の制御 ─ δ | 4Δ′（行間④⑤）

5

δ := gcd( F(p,q), G(p,q) ) ≥ 1 とおく（G(p,q) ≠ 0 なので定義される）。

▸ 根拠　Step 4。gcd(u, v)（v ≠ 0）は初等整数論の定義どおり。

6

恒等式に (X, Z) = (p, q) を代入する：

f₁(p,q)·F(p,q) − g₁(p,q)·G(p,q) = 4Δ′q⁷,　f₂(p,q)·F(p,q) − g₂(p,q)·G(p,q) = 4Δ′p⁷

▸ 根拠　ℤ[X, Z] の恒等式は任意の整数代入で ℤ の等式になる（A, B は最初から固定された整数）。

7

δ | 4Δ′q⁷ かつ δ | 4Δ′p⁷。

▸ 根拠　δ は F(p,q) と G(p,q) の両方を割るので、その整数結合（Step 6 の左辺）も割る（B3 第1性質、s = f₁(p,q), t = −g₁(p,q) など）。これが行間④の前半。

8

δ | 4Δ′。約分量は P に依らない定数で頭打ちである。

▸ 根拠　δ | gcd(4Δ′p⁷, 4Δ′q⁷) = |4Δ′|·gcd(p⁷, q⁷) = |4Δ′|（B3 第3性質と、gcd(p,q) = 1 ⇒ gcd(p⁷,q⁷) = 1：B3 第2性質）。Δ′ ≠ 0 は Δ = −16Δ′ ≠ 0（非特異性）から。これが行間④の後半──幾何の非退化性（Δ ≠ 0）が「約分の上限」という数論的定数に化ける瞬間。

9

高さの等式（行間⑤）：H(x([2]P)) = max{ |F(p,q)|, |G(p,q)| } / δ ≥ max{ |F(p,q)|, |G(p,q)| } / |4Δ′|。

▸ 根拠　F/δ と G/δ は整数で gcd = 1（δ で割り切ったから）、G/δ = 4q⁴y²/δ > 0（Step 4）。つまり (F/δ)/(G/δ) は分母が正の既約表示そのもので、既約表示の一意性（N1・V2）より H はその max に等しい。2つ目の不等号は Step 8（δ ≤ |4Δ′|）。N2 では「≤」で済んだ場所に、ここでは等号と δ の上界が要る──下からの評価だからである。

Section 06

下からの評価と C₂ の明示形（行間⑥）

10

κ := f₁, g₁, f₂, g₂ の「係数の絶対値の和」の最大値、とおくと、任意の3次斉次多項式の評価として

|f₁(p,q)|, |g₁(p,q)|, |f₂(p,q)|, |g₂(p,q)| ≤ κ·T³　（T = max{|p|, |q|}）

▸ 根拠　3次斉次式の各単項式は |p|i|q|3−i ≤ T³（三角不等式）。κ は A, B だけの定数。

11

Step 6 の2本の等式に三角不等式を使うと：

|4Δ′|·T⁷ = max{ |4Δ′p⁷|, |4Δ′q⁷| } ≤ 2κT³ · max{ |F(p,q)|, |G(p,q)| }

▸ 根拠　|f₁F − g₁G| ≤ |f₁||F| + |g₁||G| ≤ κT³|F| + κT³|G| ≤ 2κT³ max{|F|, |G|}、p⁷ 側も同様。max{|p⁷|, |q⁷|} = T⁷ は max の定義。

12

T³ ≥ 1 で割って整理すると max{ |F|, |G| } ≥ (|4Δ′| / 2κ)·T⁴、Step 9 と合わせて：

H(x([2]P)) ≥ T⁴ / (2κ) = H(x(P))⁴ / (2κ)

▸ 根拠　正数で割っても不等号は不変（T ≥ 1、κ ≥ 1）。Step 9 の分母 |4Δ′| がここで打ち消し合う──「約分でどれだけ失うか（≤ |4Δ′|）」と「恒等式がどれだけ保証するか（≥ |4Δ′|T⁴/2κ）」の比だけが残る。

13

対数を取って仕上げ：

hx([2]P) ≥ 4hx(P) − log(2κ)
C₂(A, B) := max{ log 2κ,　4·max{ hx(P) : P ∈ E(ℚ)[2] } }

▸ 根拠　log の単調性。最後の max で Step 1 の例外ケースを合流（行間②⑥）。これで補題の証明が完了する。

∎
上からも4倍：|h([2]P) − 4h(P)| ≤ C

同じ F, G に N2 と同型の「上からの」評価（約分無視・三角不等式）を使うと h([2]P) ≤ 4h(P) + log(κ′)（κ′ = F, G の係数絶対値和の最大値）も出ます。 あわせて |h([2]P) − 4h(P)| ≤ C：これが本編・練習問題6（Tate の望遠鏡トリック）の 仮定 (a) の正体で、標準高さ ĥ = lim 4⁻ⁿh([2ⁿ]P) の存在AEC VIII.9へ直結します。

Section 07

数値検算 ─ E : y² = x³ + 3, 2P = (−23/16, −11/64)（行間⑦）

A = 0, B = 3 では Δ′ = 27·9 = 243、4Δ′ = 972、そして

f₁ = 12X²Z,　g₁ = 3X³ − 81Z³,　f₂ = 972X³ + 2592Z³,　g₂ = −5184XZ²
f₂ = 4Δ′X³ + 12B·8B²·Z³ = 972X³ + 12·3·72·Z³、g₂ = −2B·96B²·XZ² = −2·3·864·XZ²（A = 0 で残る項だけ）

2P の座標 (p, q) = (−23, 16)、F(−23,16) = 2540833、G(−23,16) = 7744 に対して：

チェック左辺右辺結果

つまりこの曲線では h([2]P) ≥ 4h(P) − 9.25 が全点で成立。実測（本編の表）の h(4P) ≈ 4.7·h(2P) は余裕を持ってこの帯の中にいる
