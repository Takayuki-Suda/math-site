高さの土台 ─ 座標の形と有限性
Denominators are perfect squares & cubes

本編Ⅳが1行で流した「既約分数表示で P = (a/d², b/d³) と書けます」── 実はこれが高さ理論全体の土台です。p進付値による完全証明、高さ H の基本性質、 そして性質 (c)「高さ有界な点は有限個」の正確な数え上げまでを、このノートで固めます。

TEXT: Silverman, AEC 2nd ed. ─ VIII §4・VIII.4.2(c)（完全展開）

本編Ⅳ 降下法 N0 降下定理 N1 高さの土台 N2 性質(a) 加法 N3 性質(b) 倍加
Section 01

このノートで埋める行間

本編 Section 03 は高さの定義から性質 (a) の証明へ一気に進みましたが、その途中で次の5点が行間に沈んでいました。

  • ① H(t) と hx の基本性質（H ≥ 1、hx ≥ 0、hx(P) = hx(−P)）の証明
  • ② 「x = a/d², y = b/d³ と書ける」──分母が自動的に平方数・立方数のペアになることの完全証明
  • ③ gcd 条件（a ⊥ d、b ⊥ d）と、表示の一意性
  • ④ 性質 (c)「{ P : hx(P) ≤ C₃ } は有限」の正確な数え上げ（(2C+1)² と「各 x に y は高々2つ」の根拠）
  • ⑤ 実例での確認──P = (1,2) の倍加列に分母 16 = 4²、64 = 4³、7744 = 88² が現れる仕組み

②は N2・N3 の評価計算がすべて依存する土台です。方針：前提を V1–V3 に固定し、 素数 p を1つずつ見る「局所的な」議論で②を証明します。

Section 02

前提の固定（V1–V3）

前提 V1 ─ p進付値 素因数分解の一意性の言い換え

素数 p ごとに関数 vp : ℚ× → ℤ が定まり（t = pk·(u/w)、p ∤ uw と書いたときの k）、次を満たす：

(V1-1)　vp(st) = vp(s) + vp(t)
(V1-2)　vp(s + t) ≥ min{ vp(s), vp(t) }，等号は vp(s) ≠ vp(t) のとき必ず成立
(V1-3)　t ∈ ℤ ⟺ すべての p で vp(t) ≥ 0　（t ∈ ℚ×）
規約：vp(0) = +∞（どの p でも 0 は「無限回割れる」）。(V1-2) は 0 を含めても成立。
(V1-2) の等号の証明を開く

vp(s) < vp(t) とする。もし vp(s+t) > vp(s) なら、 s = (s+t) − t と書くと (V1-2) より vp(s) ≥ min{ vp(s+t), vp(−t) } > vp(s) （両方の項が vp(s) より真に大きい）となり矛盾。よって vp(s+t) = vp(s) = min。 「一番割れない項が和の割れ方を支配する」──超距離不等式の標準的な帰結である。

前提 V2 ─ 既約分数と高さ H AEC VIII §4

t ∈ ℚ は t = p/q（p, q ∈ ℤ, q ≥ 1, gcd(p,q) = 1）とただ一通りに書け、 H(t) := max{ |p|, |q| } と定める。付値との関係：q = Πℓ ℓmax{0, −vℓ(t)} （分母は「負の付値」の集まり）。

前提 V3 ─ 曲線の設定 本編Ⅳ Section 03

E : y² = x³ + Ax + B（A, B ∈ ℤ、Δ ≠ 0）を固定する。P = (x, y) ∈ E(ℚ) とは x, y ∈ ℚ がこの等式を満たすこと。hx(P) = log H(x(P))（P ≠ O）、hx(O) = 0。

Section 03

H と hx の基本性質（行間①）

1

すべての t ∈ ℚ で H(t) ≥ 1。したがって hx(P) = log H(x(P)) ≥ 0（∀P）。

▸ 根拠　V2 の表示で q ≥ 1 なので max{|p|, |q|} ≥ 1。log は [1, ∞) 上で ≥ 0。O では規約により hx(O) = 0 ≥ 0。降下定理では h ≥ 0 は不要だったが（N0）、あるおかげで評価が至る所で単純化する。

2

hx(−P) = hx(P)。

▸ 根拠　−(x, y) = (x, −y)AEC III.2.3(a)：逆元は x 座標を変えない。hx は x 座標しか見ないので値が一致。−O = O も規約と整合。この対称性のおかげで、降下定理の C₁′ = max C₁(−Qi) の計算は C₁(Qi) の計算と実質同じになる（N2 の副産物）。

3

H(t) ≤ C を満たす有理数 t は有限個で、その個数は (2⌊C⌋ + 1)² 以下。

▸ 根拠　t ↦ (p, q)（V2 の既約表示）は単射。H(t) ≤ C なら |p| ≤ C かつ |q| ≤ C、つまり (p, q) は整数格子の正方形 [−⌊C⌋, ⌊C⌋]² に入る。その格子点は (2⌊C⌋+1)² 個。単射があれば個数は像の候補数以下（集合論）。

Section 04

座標補題 ─ 分母は d² と d³（行間②③）

補題（座標の形） AEC VIII §4 で暗黙に使用

P = (x, y) ∈ E(ℚ)、P ≠ O とすると、整数 a, b と d ≥ 1 がただ一組存在して

x = a/d²,　y = b/d³,　gcd(a, d) = gcd(b, d) = 1

特に H(x(P)) = max{ |a|, d² }、そして b² = a³ + Aad⁴ + Bd⁶（整数の等式）。

証明は「素数 p を1つ固定して、x と y の分母の p 部分を比べる」だけです。急所は曲線の方程式が付値を2 : 3 に縛ること。

1

素数 p を固定し、v := vp(x) < 0 と仮定する。このとき vp(x³) = 3v であり、vp(Ax + B) ≥ v > 3v。

▸ 根拠　vp(x³) = 3v は (V1-1)。vp(Ax) = vp(A) + v ≥ v（A ∈ ℤ より vp(A) ≥ 0、(V1-3)）、vp(B) ≥ 0 > v。よって (V1-2) より vp(Ax+B) ≥ min{v, 0} = v。最後の v > 3v は v < 0 だから（2v < 0 を両辺に足す）。A = 0 や B = 0 で項が消えていても vp(0) = +∞ ≥ v なので議論はそのまま通る。

2

したがって vp(y²) = vp(x³ + (Ax+B)) = 3v。すなわち 2·vp(y) = 3v。

▸ 根拠　Step 1 で2つの項の付値が異なる（3v < v ≤ vp(Ax+B)）ので、(V1-2) の等号の場合が発動して和の付値は小さい方 3v に一致。vp(y²) = 2vp(y) は (V1-1)。なお y = 0 だと左辺が +∞ となり 3v < ∞ と矛盾するから、v < 0 なら自動的に y ≠ 0 である。

3

2vp(y) = 3v の左辺は偶数なので v も偶数。よって v = −2e（e ≥ 1 整数）、vp(y) = −3e。

▸ 根拠　3v が偶数 ⟺ v が偶数（3 は奇数）。v < 0 なので e = −v/2 ≥ 1。vp(y) = 3v/2 = −3e。分母の指数が (2e, 3e) のペアで現れることが、ここで確定する。

4

逆に vp(x) ≥ 0 の素数では vp(y) ≥ 0。

▸ 根拠　2vp(y) = vp(x³+Ax+B) ≥ min{3vp(x), vp(A)+vp(x), vp(B)} ≥ 0（(V1-2)、各項 ≥ 0）。y = 0 なら vp(0) = +∞ ≥ 0 で問題ない。

5

ep := max{ 0, −vp(x)/2 } とおくと各 ep は非負整数で、p が x の分母に現れる有限個の素数を除いて 0。d := Πp pep ≥ 1 と定める。

▸ 根拠　整数性は Step 3（vp(x) < 0 なら −vp(x)/2 = e ∈ ℤ）。有限個の p を除いて vp(x) ≥ 0 なのは、x の既約分数表示の分母の素因数が有限個だから（V2）。よって d は有限積で定義される。

6

a := x·d² と b := y·d³ は整数で、x = a/d²、y = b/d³。

▸ 根拠　(V1-3) で確かめる。vp(a) = vp(x) + 2ep は、vp(x) < 0 なら −2ep + 2ep = 0、vp(x) ≥ 0 なら vp(x) + 0 ≥ 0。vp(b) = vp(y) + 3ep は、vp(x) < 0 なら −3ep + 3ep = 0（Step 3）、vp(x) ≥ 0 なら vp(y) ≥ 0（Step 4）。全素数で付値 ≥ 0 なので整数。

7

gcd(a, d) = gcd(b, d) = 1。

▸ 根拠　p | d なる素数では ep ≥ 1、つまり vp(x) = −2ep < 0 で、Step 6 の計算により vp(a) = 0 かつ vp(b) = 0。すなわち d の素因数は a も b も割らない。これが行間③の前半。

8

一意性と残りの主張：表示は一意で、H(x(P)) = max{|a|, d²}、さらに b² = a³ + Aad⁴ + Bd⁶。

▸ 根拠　gcd(a, d) = 1 ⇒ gcd(a, d²) = 1 なので a/d²（d² ≥ 1）は既約表示そのもの。既約表示の一意性（V2）から a と d² が決まり、d ≥ 1 より d も一意、b = y·d³ も一意。同時に H(x(P)) = max{|a|, d²} が定義から直ちに出る。最後の等式は y² = x³+Ax+B に x = a/d², y = b/d³ を代入して d⁶ を掛けるだけ：b²/d⁶ = a³/d⁶ + Aa/d² + B。

∎
おまけ：y = 0 なら分母は消える（Lutz–Nagell の種）

y = 0（2等分点）だと Step 2 の矛盾によりすべての素数で vp(x) ≥ 0、 つまり x ∈ ℤ、d = 1 が強制されます。「捩れ点の座標は整数」という Lutz–Nagell 定理 AEC VIII.7.1–7.2（本編 Section 06）の最初の一歩が、 もうこの補題の中に入っているのです。

? なぜ 2 と 3 なのか ─ Weierstrass 方程式の重み

y² = x³ + ⋯ という式は「x に重み 2、y に重み 3」を与えると斉次になります（2·3 = 3·2 = 6）。 座標補題はこの重みが分母の指数にそのまま刻印されると言っています。 実は同じ現象を p進の内側から見たものが AEC VII 章の filtration E₁(ℚp) ⊃ E₂(ℚp) ⊃ ⋯（vp(x) = −2n, vp(y) = −3n の点たち）です AEC VII.2 周辺。大域的な高さ理論と局所理論が、 この「2 : 3」で最初に握手します。

Section 05

性質 (c) の完全証明（行間④）

補題（高さの性質 (c)） AEC VIII.4.2(c)

任意の定数 C₃ に対し { P ∈ E(ℚ) : hx(P) ≤ C₃ } は有限集合である。

1

C := eC₃ とおく。hx(P) ≤ C₃ かつ P ≠ O ならば H(x(P)) ≤ C。

▸ 根拠　log H(x(P)) ≤ C₃ で exp は単調増加。C₃ < 0 なら条件を満たす P ≠ O は存在しない（Step 1 of Section 03：hx ≥ 0）ので、以下 C ≥ 1 の場合だけが実質的。

2

x 座標の候補は有限個：#{ t ∈ ℚ : H(t) ≤ C } ≤ (2⌊C⌋+1)²。

▸ 根拠　Section 03 の Step 3。

3

x 座標を1つ固定すると、それを x 座標に持つ点 P ∈ E(ℚ) は高々 2 個。

▸ 根拠　P = (x, y) は y² = x³+Ax+B を満たす。体 ℚ の中で「2乗して c になる元」は高々2つ（y₁² = y₂² ⇒ (y₁−y₂)(y₁+y₂) = 0 ⇒ y₂ = ±y₁：整域に零因子なし）。よって y の候補は ±y₀ の高々2つ。

4

まとめ：#{ P : hx(P) ≤ C₃ } ≤ 2(2⌊C⌋+1)² + 1 < ∞。

▸ 根拠　P ≠ O は「x 座標の候補（Step 2）× 各候補の点数（Step 3）」で高々 2(2⌊C⌋+1)² 個、最後に O を1個足した。有限×有限＝有限。

∎
一般の数体では ─ Northcott の有限性

ℚ ではこの通り「格子点を数えるだけ」ですが、一般の数体 K では座標の候補が 「高さ有界の代数的数」になり、共役全体を抑える必要が生じます。 それでも「高さと次数が有界な代数的数は有限個」が成り立つ──これが Northcott の定理 AEC VIII.5.11で、本編 Section 06 の地図に出てきた性質 (iii) の一般版です。 証明の骨格は同じ「係数を数える」議論です。

Section 06

実例で検算 ─ E : y² = x³ + 3, P = (1, 2)（行間⑤）

本編 Section 05 の表の裏側を、座標補題の目で見直します。まず 2P を完全に計算：

λ = (3x² + A)/(2y) = 3/4
x(2P) = λ² − 2x = 9/16 − 2 = −23/16,
y(2P) = λ(x(P) − x(2P)) − y(P) = (3/4)(1 + 23/16) − 2 = 117/64 − 128/64 = −11/64
点座標d分母の検証
P(1, 2)11 = 1², 1 = 1³
2P(−23/16, −11/64)416 = 4², 64 = 4³ ✓
4Px = 2540833/7744887744 = 88² ✓（y の分母は 88³ = 681472）
✓

2P を p = 2 の付値で読む：v₂(x(2P)) = v₂(−23/16) = −4 = −2·2、v₂(y(2P)) = v₂(−11/64) = −6 = −3·2。

▸ 根拠　e₂ = 2 のペア (−2e, −3e) = (−4, −6) がぴったり現れている──Step 3 の「2 : 3 の縛り」の実物。gcd(−23, 4) = gcd(−11, 4) = 1 も確認できる（補題の gcd 条件）。

さらに、4P の分母 7744 が計算する前から平方数だと予言できることに注意してください。 倍加公式の分母 G(−23, 16) がどんな整数になろうと、座標補題は「既約化すれば必ず（何かの d）の2乗」と 保証しています。実際 7744 = 88²、88 = 2³·11。d が 4 から 88 へ約22倍になる── この分母の爆発こそ hx(2ⁿP) ≈ 4ⁿ 成長（性質 (b)、N3）の実体です。

⏩ 次へ

土台は固まりました。N2 では加法公式に (a/d², b/d³) を代入して性質 (a) を、 N3 では倍加公式と2本の恒等式で性質 (b) を、それぞれ飛躍ゼロで証明します。 どちらの計算でも「分母が d² と d³」であることが、式が整数の世界に収まる理由として効き続けます。
