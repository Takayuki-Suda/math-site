Between-the-lines notes ─ Descent and heights N0/N3

A complete proof of the descent theorem
The Descent Theorem, with every step justified

"A/mA finite + a height function ⇒ finitely generated" ── we rebuild the proof of Main Part IV, Section 02 with zero leaps. The "choices" hidden in constructing the descent sequence, the induction for the shrinking estimate, the reverse telescoping sum, and even the exact meaning of "generate": for every step we make the "claim" and the "reason" explicit. This is a chapter of pure group theory + real numbers, where elliptic curves haven't appeared yet.

TEXT: Silverman, AEC 2nd ed. ─ VIII.3.1 (fully expanded)

Section 01

The gaps this note fills

The proof in Section 02 of the main part is a correct blueprint, but in the following six places it relied on the reader filling things in mentally. This note puts all of them on paper.

  • ① Making explicit the double choice in constructing the descent sequence P₁, P₂, … (the coset index ij and the quotient Pj)
  • ② The sign handling when applying property (i) to "Q = −Qi", and why the constant C₁′ can be taken independent of P
  • ③ A rigorous proof by induction of the iterated estimate h(Pn) ≤ (2/m²)ⁿh(P) + … (a geometric series)
  • ④ h is real-valued and not assumed nonnegative ── checking that the argument works even when h(P) < 0
  • ⑤ A proof by induction of the reverse telescoping sum P = mⁿPn + Σ mj−1Qij
  • ⑥ Writing out the set-theoretically precise form of "generated by a finite set" (generated subgroup = the whole group)

Plan: first, in Section 02, we fix the premises as H1–H3. In the proof that follows, we proceed while checking that every step follows only from "H1–H3, steps already shown, or pure computation".

Section 02

Fixing the premises (H1–H3)

This note imports only the following three things from outside. It uses no elliptic curve theory and no field theory at all (those first appear in N1–N3, when we prove "the existence of a height function").

Premise H1 ─ abelian groups and generation group theory definitions

A is an abelian group (written additively). For a subset Z ⊆ A, the subgroup generated by Z is

⟨Z⟩ = { n₁z₁ + ⋯ + nkzk : k ≥ 0, ni ∈ ℤ, zi ∈ Z } (empty sum = 0)

"A is finitely generated" means there exists a finite set Z with A = ⟨Z⟩. An integer multiple mP is repeated addition, and n(P+Q) = nP + nQ holds for any P, Q ∈ A and n ∈ ℤ.

Premise H2 ─ quotient groups and coset representatives group theory definitions

mA = { mP : P ∈ A } is a subgroup, and the quotient group A/mA is defined. "A/mA is finite (of order r)" means there are representatives Q₁, …, Qr ∈ A such that for any a ∈ A, a − Qi ∈ mA for some i.

Premise H3 ─ elementary facts about real numbers basics of analysis

For 0 < α < 1 and a real number β ≥ 0:

Geometric series: β(1 + α + α² + ⋯ + αn−1) = β·(1−αⁿ)/(1−α) < β/(1−α)
Archimedean property: for any x ≥ 0 there is an integer n ≥ 0 with 2⁻ⁿx ≤ 1

Also, dividing a real inequality by a positive number doesn't change its direction. That's all the analysis we use.

Section 03

The statement and the design of the proof

Theorem (descent theorem) AEC VIII.3.1

Let A be an abelian group and h : A → ℝ a function satisfying the following.

(i) For each Q ∈ A there is a constant C₁ = C₁(Q) with: h(P + Q) ≤ 2h(P) + C₁ (∀P ∈ A)
(ii) There are an integer m ≥ 2 and a constant C₂ with: h(mP) ≥ m²h(P) − C₂ (∀P ∈ A)
(iii) For any constant C₃, { P ∈ A : h(P) ≤ C₃ } is a finite set

If moreover A/mA is finite for the m in (ii), then A is finitely generated.

The design has three parts. Part 1 (construction): from any point P, build a descent sequence by "dividing by m and subtracting the remainder". Part 2 (estimate): show that the heights in the descent sequence fall geometrically down to a "floor". Part 3 (generation): trace the descent sequence backward and check that P is an integer combination of "points on the floor + remainder representatives". At the very end, (iii) single-handedly supplies the finiteness.

? h doesn't need a "meaning"

The h in this theorem is built with "the number of digits of a point of E(ℚ)" in mind, but in the proof no properties other than (i)(ii)(iii) are used at all. Note that we don't even assume h ≥ 0 (checked in gap ④). Precisely because it was cut out axiomatically, this theorem can be reused as is beyond E(ℚ) ── for example for E(K) over a general number fieldAEC VIII.6.7.

Section 04 ─ Part 1

Constructing the descent sequence ─ making the choices explicit

1

Choose and fix one set of representatives Q₁, …, Qr ∈ A of A/mA. Also define the constant C₁′ := max{ C₁(−Q₁), …, C₁(−Qr) }.

▸ Reason Representatives exist by H2 (the definition of A/mA being finite). C₁′ is the maximum of finitely many real numbers, so it certainly exists, and it doesn't depend on P. The existence of the constant C₁(−Qi) for each −Qi is (i). This is the second half of gap ②.

2

Take any P ∈ A and set P₀ := P. Inductively for j ≥ 1: once Pj−1 has been constructed, choose one index ij ∈ {1,…,r} with Pj−1 − Qij ∈ mA, and then choose one Pj ∈ A with mPj = Pj−1 − Qij.

▸ Reason The existence of ij is H2 (Pj−1 lies in some coset). The existence of Pj is the very definition of mA, "an element of mA = m times some element". This is gap ①: every step of the construction involves two choices, but at each step the options are nonempty, and all we need is to build one finite sequence, so we may choose arbitrarily and fix (no axiom of choice needed).

3

In this way we get "descent data" (P₀, P₁, …, Pn; i₁, …, in) of any length n:

P₀ = P, Pj−1 = mPj + Qij (j = 1, …, n)

▸ Reason Just moving terms in the equation mPj = Pj−1 − Qij from Step 2 (A is an abelian group, H1).

Section 05 ─ Part 2

The shrinking estimate ─ heights fall geometrically to the floor

4

One-step estimate: for each j = 1, …, n, h(Pj) ≤ ( 2h(Pj−1) + C₁′ + C₂ ) / m². Below we break it into 4a–4d.

4a

m²h(Pj) ≤ h(mPj) + C₂.

▸ Reason Just (ii) applied to P = Pj, with terms moved.

4b

h(mPj) = h(Pj−1 − Qij) = h(Pj−1 + (−Qij)).

▸ Reason mPj and Pj−1 − Qij are the same element of A (by the construction in Step 2), so their values under h are equal too. Subtraction is "adding the inverse" (H1).

4c

h(Pj−1 + (−Qij)) ≤ 2h(Pj−1) + C₁(−Qij) ≤ 2h(Pj−1) + C₁′.

▸ Reason The first inequality is (i) applied with "Q = −Qij, P = Pj−1". (i) gives a constant for any Q ∈ A, so we may use it for −Qi ── this is the first half of gap ② (the sign handling). The second inequality is the definition of C₁′ (Step 1: we took the max).

4d

Chain 4a–4c together and divide by m² ( > 0 ) to get the claimed one-step estimate.

▸ Reason m²h(Pj) ≤ h(mPj) + C₂ ≤ 2h(Pj−1) + C₁′ + C₂. Dividing by a positive number doesn't change the direction of the inequality (H3).

5

Iteration (induction): setting α := 2/m², β := (C₁′ + C₂)/m², for any n ≥ 0

h(Pn) ≤ αⁿ h(P) + β ( 1 + α + α² + ⋯ + αn−1 )

▸ Reason Induction on n (gap ③). n = 0 is "h(P) ≤ h(P)", true (the sum on the right is the empty sum = 0). If it holds for n, substitute the induction hypothesis into the one-step estimate of Step 4, h(Pn+1) ≤ αh(Pn) + β: h(Pn+1) ≤ α( αⁿh(P) + β(1+⋯+αn−1) ) + β = αn+1h(P) + β(1+α+⋯+αⁿ). Since α > 0 we may multiply the inequality by α.

6

Deriving the floor: since m ≥ 2 gives α ≤ 1/2, setting h⁺ := max{ h(P), 0 },

h(Pn) < αⁿ h(P) + β/(1−α) ≤ 2⁻ⁿ h⁺ + (C₁′ + C₂)/(m² − 2) ≤ 2⁻ⁿ h⁺ + (C₁′ + C₂)/2

▸ Reason The sum of the geometric series is H3. β/(1−α) = [(C₁′+C₂)/m²] / [(m²−2)/m²] = (C₁′+C₂)/(m²−2) is just multiplying numerator and denominator by m². m ≥ 2 ⇒ m²−2 ≥ 2. Even though α ≤ 1/2, we can write αⁿh(P) ≤ 2⁻ⁿh(P) only when h(P) ≥ 0 ── if h(P) < 0 then αⁿh(P) < 0 ≤ 2⁻ⁿh⁺, so in either case αⁿh(P) ≤ 2⁻ⁿh⁺. This is gap ④: nonnegativity of h isn't needed; using max{h(P), 0} handles both cases uniformly. We also don't assume C₁′+C₂ ≥ 0, but if it's negative the floor just gets lower and the rest of the argument goes through unchanged.

7

Choosing the stopping time: choose one n ≥ 0 with 2⁻ⁿ h⁺ ≤ 1. For this n,

h(Pn) ≤ 1 + (C₁′ + C₂)/2 =: C₃* (a constant independent of P!)

▸ Reason Existence is the Archimedean property in H3 (h⁺ ≥ 0). Explicitly, n = max{ 0, ⌈log₂ h⁺⌉ } works (main part, Exercise 1). n changes with P, but the floor C₃* doesn't ── this is the crux of the proof.

Section 06 ─ Part 3

Reverse telescoping and generation

8

Reverse telescoping sum: for any n ≥ 0,

P = mⁿ Pn + Σj=1n mj−1 Qij (for n = 0, P = P₀ and the sum is empty)

▸ Reason Induction on n (gap ⑤). n = 0 is P = P₀ (the definition in Step 2). If it holds for n = k, substitute Pk = mPk+1 + Qik+1 (Step 3): P = mk( mPk+1 + Qik+1 ) + Σj≤k mj−1Qij = mk+1Pk+1 + Σj≤k+1 mj−1Qij. The distributive law mk(X+Y) = mkX + mkY is H1.

9

Pinning down the generating set: setting Z := { Q₁, …, Qr } ∪ { R ∈ A : h(R) ≤ C₃* }, Z is a finite set and A = ⟨Z⟩.

▸ Reason Finiteness: the first set has r elements, and the second set is finite by (iii) with C₃ = C₃* ── this is the only time (iii) is used in the whole proof. Generation: for any P, take the n from Step 7; then the formula in Step 8 expresses P as the sum of "mⁿ times Pn (in the second set, Step 7)" and "mj−1 times each Qij". This is literally an integer combination of Z in the sense of H1. This is gap ⑥: "generate" means every element can be written as an integer combination, and we wrote that out literally.

10

Therefore A is generated by the finite set Z, and the proof of the theorem is complete.

▸ Reason Step 9 is exactly the definition of "finitely generated" (H1).

∎
By-product: an explicit generating set and stopping time
A = ⟨ {Q₁,…,Qr} ∪ { R : h(R) ≤ 1 + (C₁′+C₂)/2 } ⟩, stopping time n ≈ log₂ h⁺(P)

The proof tells us not only "it's finitely generated" but even candidates for a generating set and the number of steps to reach it. If C₁′ and C₂ can be computed (N2 and N3 actually compute them) and the points below the floor can be listed (the count in N1), then generators can be found by an algorithm ── this is what the "remark on effectivity" in the main partAEC VIII.3.2 is about.

What we didn't use (knowing the outline of the proof)

Nonnegativity of h is not needed (Step 6). The coefficient 2 in (i) is not essential ── replacing 2 with any c < m² still keeps the shrink factor c/m² < 1; only the denominator of the floor changes to m²−c. Countability of A or whether it has torsion isn't needed either. Finiteness was supplied in only two places: the single application of (iii) (Step 9) and the finiteness of A/mA (Step 1).

? Seen as a contraction ─ what the simulator's "floor" really is

The one-step estimate (Step 4) forces the real recursion x ↦ (2x + C)/m² onto the heights. This linear map is a contraction with slope 2/m² < 1, and its fixed point is x* = C/(m²−2) ── that's the gold dotted line drawn in the main part's simulator. You can read it as an elementary version of Banach's fixed point theorem guaranteeing that "however high a point is, it falls to the floor in logarithmically many steps". The same shrinking structure Fermat's infinite descent used to produce a "contradiction" is used here to produce "generation" ── savor it together with the why box in Section 02 of the main part.
