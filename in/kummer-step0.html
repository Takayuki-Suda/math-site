行間ノート ─ Kummer対 N0/N3

群コホモロジーの土台
H⁰, H¹ and the Six-Term Sequence, fully assembled

本編が「短完全列から完全列が生える」と一行で述べた機械を、部品から完全に組み立てます。 Z¹・B¹ の群構造、連続コサイクルの有限段階への降下、連結準同型 δ の well-defined 性、 そして6項完全列の5箇所すべての完全性を、一行も飛ばさずに検証します。

TEXT: Silverman, AEC 2nd ed. ─ Appendix B §1–§2（完全展開）

本編Ⅲ Kummer対 N0 コホモロジーの土台 N1 Kummer完全列 N2 Hilbert 90 N3 inf–resと不分岐
Section 01

このノートで埋める行間

  • ① コサイクル全体 Z¹・コバウンダリ全体 B¹ が群をなすこと──これが確かめられて初めて商 H¹ = Z¹/B¹ が群として定義できる
  • ②「作用が自明なら H¹ = Hom(G, M)」の完全証明（本編は結果のみ）
  • ③ 射有限群での「連続コサイクル」の正確な意味と、「連続なら必ずある有限次Galois拡大を経由する」ことの証明──本編が「以後この規約は暗黙とします」と書いた一文の中身
  • ④ G-準同型 f : M → N が H¹ の写像 f* を誘導すること（完全列の後半2本の矢印の正体）
  • ⑤ 連結準同型 δ の well-defined 性（持ち上げの取り替えがコバウンダリの差しか生まないこと）と、δ が群準同型であること
  • ⑥ 6項完全列の完全性──5箇所の検証。本編は δ の構成だけ示して完全性は述べるにとどめた

このノートは楕円曲線を一切使いません。純粋に「機械の組み立て」です。 機械を楕円曲線に接続するのは N1、 乗法群に接続するのは N2 の仕事です。

Section 02

前提の固定（R1–R3）

前提 R1 ─ G-加群と右作用の規約

G を群、M をアーベル群（加法的に書く）とする。M が G-加群であるとは、 各 σ ∈ G に対し写像 m ↦ mσ が与えられ、次を満たすこと：

(i)　(m + n)σ = mσ + nσ　（各 σ は群準同型）
(ii)　mστ = (mσ)τ　（合成は右作用で読む）
(iii)　me = m

(ii) は弱MWノートの前提 Q3 と同じ規約weakmw N1 前提Q3。 AEC の指数表記に合わせてある。(i)(ii) から (−m)σ = −mσ、0σ = 0 も出る （準同型は逆元と単位元を保つ）。

前提 R2 ─ G-加群の短完全列

G-加群と G-同変準同型（f(mσ) = f(m)σ を満たす群準同型）の列

0 → A →φ B →ψ C → 0

が短完全列であるとは：φ が単射、ψ が全射、im φ = ker ψ。 以後 φ による像で A を B の部分 G-加群と同一視し、断りなく A ⊆ B と書く （その際 ψ の核がちょうど A である）。

前提 R3 ─ 記法

写像 c : G → M を cσ := c(σ) と添字で書く。 コサイクル条件 cστ = cστ + cτ を満たす c の全体を Z¹(G, M)、 ある m ∈ M により cσ = mσ − m と書けるものの全体を B¹(G, M) と書く。 H⁰(G, M) := MG（不変部分群──部分「群」であることは (i) から明らか）、 H¹(G, M) := Z¹/B¹（商が定義できることは §03 で検証する）。 G が射有限群のときの位相的な条件は §04 で正確に述べる。

Section 03

コサイクルの計算規則（行間①②）

1

Z¹(G, M) は、点ごとの和 (c + d)σ := cσ + dσ でアーベル群になる。

▸ 根拠　和がコサイクル条件を満たすこと：(c+d)στ = cστ + dστ = (cστ + cτ) + (dστ + dτ) = (cσ + dσ)τ + (c+d)τ。最後の等号が R1(i)。零写像はコサイクル（0 = 0τ + 0）。−c もコサイクル（両辺の符号反転と (−m)τ = −mτ）。結合則・可換則は M から点ごとに遺伝。

2

B¹(G, M) ⊆ Z¹(G, M) であり、B¹ は部分群。したがって商 H¹ = Z¹/B¹ が群として定義できる（行間①解消）。

▸ 根拠　m の定めるコバウンダリがコサイクル条件を満たすこと：(mσ − m)τ + (mτ − m) = mστ − mτ + mτ − m = mστ − m。ここで R1(i)(ii) を使った。部分群であること：m のコバウンダリと n のコバウンダリの差は m − n のコバウンダリ。

3

すべてのコサイクルは単位元で消える：ce = 0。

▸ 根拠　ce = ce·e = cee + ce = ce + ce（R1(iii)）。両辺から ce を引く。

4

逆元での値：cσ⁻¹ = −(cσ)σ⁻¹。

▸ 根拠　0 = ce = cσσ⁻¹ = cσσ⁻¹ + cσ⁻¹（Step 3 とコサイクル条件）。移項するだけ。この式は N3 の共役補題で使う。

5

G の作用が自明（mσ = m）ならば H¹(G, M) = Hom(G, M)（行間②解消）。

▸ 根拠　コサイクル条件は cστ = cστ + cτ = cσ + cτ となり「c が群準同型 G → M」と同値。つまり Z¹ = Hom(G, M)。コバウンダリは cσ = mσ − m = m − m = 0 のみ、つまり B¹ = 0。よって H¹ = Hom(G, M)/0 = Hom(G, M)。Z¹ の群構造（Step 1）が Hom の点ごとの和と一致することも定義から直ちに分かる。

Section 04

射有限群と連続コサイクル（行間③）

位相の規約（離散 G-加群）

G を射有限群（＝有限群の逆極限。コンパクトで、開正規部分群 U が単位元の近傍基をなす）、 M を離散位相のアーベル群とする。作用が連続であるとは、 各 m ∈ M の固定化群 { σ : mσ = m } が G の開部分群を含むこと。 同値な言い換え：M = ⋃U MU（U は開正規部分群を走る）。 コサイクルには写像 c : G → M としての連続性を要求する。 GK/K と E[m], E(K), K× はすべてこの枠に入る （各点の座標が有限次拡大に入るため。検証は N1・N2 で行う）。

コバウンダリは自動的に連続です：σ ↦ mσ は、U を m の固定化群に含まれる開部分群とすると 左剰余類 Uσ の上で定数（mησ = (mη)σ = mσ、η ∈ U）、 つまり局所定数だからです。問題はコサイクルの側で、次が本節の主定理です。

定理（連続コサイクルは有限段階から来る） AEC App. B §2 の暗黙の規約の中身

c ∈ Z¹(G, M) を連続コサイクルとすると、ある開正規部分群 U が存在して： c は各剰余類 σU 上で定数、cη = 0（∀η ∈ U）、全ての値 cσ は MU に入り、 c は有限群 G/U のコサイクル c̄ ∈ Z¹(G/U, MU) の引き戻し（inflation）である。したがって

H¹cont(G, M) = ⋃U inf( H¹(G/U, MU) )　（U は開正規部分群を走る増大和集合）
6

共通の開正規部分群 U が取れて、c は各剰余類 σU 上で定数になる。

▸ 根拠　M は離散なので一点 {cσ} は開集合。連続性より c⁻¹({cσ}) は σ を含む開集合で、射有限群の位相の基本近傍系から、ある開正規部分群 Vσ について σVσ ⊆ c⁻¹({cσ})。{σVσ}σ∈G は G の開被覆、G はコンパクトなので有限部分被覆 σ₁V₁, …, σkVk が取れる。U := V₁ ∩ ⋯ ∩ Vk（開正規部分群の有限交叉は開正規）。任意の σ はある σiVi に入り、σU ⊆ σiViVi = σiVi（Vi は群）。c は σiVi 上で値 cσᵢ の定数なので σU 上でも定数。U は正規なので σU = Uσ（両側剰余類が一致）。

7

cη = 0（∀η ∈ U）。

▸ 根拠　η ∈ U = eU で、c は eU 上定数、その値は ce = 0（Step 3）。

8

すべての値が不変部分に入る：cσ ∈ MU（∀σ ∈ G）。

▸ 根拠　η ∈ U に対しコサイクル条件：cση = cση + cη = cση（Step 7）。一方 ση ∈ σU なので cση = cσ（Step 6）。よって cση = cσ。

9

c̄σU := cσ は well-defined な c̄ ∈ Z¹(G/U, MU) を定め、その引き戻しが c に一致する。

▸ 根拠　well-defined 性は Step 6（剰余類上定数）。その前に MU が G/U-加群であること：m ∈ MU, σ ∈ G に対し mσ ∈ MU を検証する──η ∈ U に対し (mσ)η = mση = mη′σ（η′ := σησ⁻¹ ∈ U、U の正規性）= (mη′)σ = mσ。さらに σ を同じ類の ση に取り替えても mση = (mσ)η = mσ なので、作用 mσU := mσ は代表の取り方に依らない。コサイクル条件の降下：c̄(σU)(τU) = cστ = cστ + cτ = (c̄σU)τU + c̄τU（値が MU に入るのは Step 8）。引き戻しの一致：(inf c̄)σ = c̄σU = cσ、定義通り。

∎
? この定理が「暗黙の規約」の全貌

本編・弱MW編を通じて「コサイクルは有限次Galois拡大を経由するものだけ考える」と繰り返してきた一文は、 この定理の主張そのものです。射有限群のコホモロジーは有限群のコホモロジーの増大和にすぎない── だから第2部の「有限群 GL/K での手計算」と第3部の「絶対Galois群での一般論」が矛盾なく往復できます。 なお inf が類のレベルで単射であること（和集合が「重なりなく」増大すること）は N3 の inflation–restriction 完全列の帰結です。

Section 05

関手性 ─ f* の構成（行間④）

10

G-同変準同型 f : M → N は群準同型 f* : H¹(G, M) → H¹(G, N)、[c] ↦ [f∘c] を誘導する。H⁰ でも同様に f(MG) ⊆ NG。

▸ 根拠　f∘c がコサイクルであること：(f∘c)στ = f(cστ + cτ) = f(cσ)τ + f(cτ)（f は加法的かつ G-同変）。コバウンダリを保つこと：f(mσ − m) = f(m)σ − f(m)、つまり m のコバウンダリは f(m) のコバウンダリに移る。ゆえに類の写像として well-defined。準同型性は f の加法性から点ごとに従う。連続性：M が離散なら f∘c は連続写像の合成（離散空間からの写像はすべて連続）。H⁰ 側：mσ = m ⇒ f(m)σ = f(mσ) = f(m)。

Section 06

連結準同型 δ（行間⑤）

0 → A → B →ψ C → 0 を短完全列（R2）とし、c ∈ CG を取ります。 本編が3行で述べた構成を、検証事項に分解します。

11

構成：持ち上げ b ∈ B（ψ(b) = c）を1つ選び、dσ := bσ − b とおくと、dσ ∈ A。

▸ 根拠　持ち上げの存在は ψ の全射性（R2）。ψ(dσ) = ψ(bσ) − ψ(b) = ψ(b)σ − ψ(b) = cσ − c = 0（ψ の G-同変性と c ∈ CG）。よって dσ ∈ ker ψ = A（R2）。

12

d は A に値を持つコサイクル：d ∈ Z¹(G, A)。

▸ 根拠　bστ − b = (bσ − b)τ + (bτ − b)（Step 2 と同じ恒等式、R1(i)(ii)）。値はすべて A に入り（Step 11）、A は G-部分加群なのでこの式は A の中の式として読める。連続性：σ ↦ bσ は局所定数（§04 冒頭のコバウンダリの議論と同じ）なので d は連続。

13

well-defined 性：別の持ち上げ b′ を選ぶと、d は A のコバウンダリの差しか変わらない。したがって δ(c) := [d] ∈ H¹(G, A) は持ち上げに依らない（行間⑤解消）。

▸ 根拠　ψ(b′) = ψ(b) = c より a := b′ − b ∈ ker ψ = A。d′σ − dσ = (b′σ − b′) − (bσ − b) = aσ − a。a ∈ A なのでこれは B¹(G, A) の元。

14

δ : CG → H¹(G, A) は群準同型。

▸ 根拠　c₁, c₂ ∈ CG の持ち上げ b₁, b₂ を選ぶと、b₁ + b₂ は c₁ + c₂ の持ち上げ（ψ は準同型）。この選択で計算すると (b₁+b₂)σ − (b₁+b₂) = d₁σ + d₂σ。Step 13 より δ の値は持ち上げの選択に依らないので δ(c₁+c₂) = [d₁] + [d₂] = δ(c₁) + δ(c₂)。

Section 07 ─ Main

6項完全列 ─ 5箇所の完全性（行間⑥）

定理（低次の長完全列） AEC App. B §2

0 → A → B →ψ C → 0 を G-加群の短完全列とすると、次は完全：

0 → AG →φ BG →ψ CG →δ H¹(G,A) →φ* H¹(G,B) →ψ* H¹(G,C)

（射有限群と離散加群・連続コサイクルの設定でもそのまま成立。各ステップの根拠に連続性の注記を添える。）

図1：6項完全列。完全性の検証点は5箇所（右端 H¹(G,C) では主張しない──そこで「続き」を測るのが H² だが、この教材では不要）。
15

AG で完全（= φ|AG の単射性）。あわせて φ(AG) ⊆ BG, ψ(BG) ⊆ CG の確認。

▸ 根拠　φ は A 全体で単射（R2）なので部分集合 AG 上でも単射。行き先の確認：a ∈ AG なら φ(a)σ = φ(aσ) = φ(a)、つまり φ(a) ∈ BG（φ の G-同変性）。ψ も同様。──この確認を経て初めて「不変部分の間の列」が意味を持つ。

16

BG で完全：ker(ψ|BG) = φ(AG)。

▸ 根拠　（⊇）ψ∘φ = 0 は im φ = ker ψ（R2）の片割れ。（⊆）b ∈ BG, ψ(b) = 0 とすると b ∈ ker ψ = im φ、つまり b = φ(a) なる a ∈ A がある。a が不変であること：φ(aσ) = φ(a)σ = bσ = b = φ(a) で、φ の単射性から aσ = a。よって b ∈ φ(AG)。

17

CG で完全：ker δ = ψ(BG)。

▸ 根拠　（⊇）c = ψ(b), b ∈ BG なら、持ち上げとして b 自身を選べて（Step 13 で選択自由は保証済み）dσ = bσ − b = 0。よって δ(c) = 0。（⊆）δ(c) = 0 とすると、持ち上げ b に対し bσ − b = aσ − a（ある a ∈ A、コバウンダリの定義）。b′ := b − a とおくと b′σ − b′ = (bσ − b) − (aσ − a) = 0、つまり b′ ∈ BG。さらに ψ(b′) = ψ(b) − ψ(a) = c − 0 = c（a ∈ A = ker ψ）。よって c ∈ ψ(BG)。

18

H¹(G, A) で完全：ker φ* = im δ。

▸ 根拠　（⊇）φ*δ(c) は「σ ↦ bσ − b を B の中で読んだ類」で、これは b ∈ B のコバウンダリそのもの。よって 0。（⊆）[c] ∈ H¹(G, A) が φ*[c] = 0 を満たすとする。B の中でコバウンダリ、つまりある b ∈ B で cσ = bσ − b（∀σ）。y := ψ(b) ∈ C とおくと yσ − y = ψ(bσ − b) = ψ(cσ) = 0（cσ ∈ A = ker ψ）なので y ∈ CG。この y の δ を持ち上げ b で計算すると δ(y) = [σ ↦ bσ − b] = [c]。よって [c] ∈ im δ。

19

H¹(G, B) で完全：ker ψ* = im φ*。

▸ 根拠　（⊇）ψ*φ*[c] = [(ψ∘φ)∘c] = [0]（ψ∘φ = 0）。（⊆）[d] ∈ H¹(G, B) が ψ*[d] = 0 を満たすとする。C でコバウンダリ、つまりある y ∈ C で ψ(dσ) = yσ − y（∀σ）。ψ の全射性で y の持ち上げ b₀ ∈ B を選び、d′σ := dσ − (b₀σ − b₀) とおく。d′ は d とコホモロガス（b₀ のコバウンダリの差）。ψ(d′σ) = (yσ − y) − (ψ(b₀)σ − ψ(b₀)) = (yσ − y) − (yσ − y) = 0 なので d′ の値はすべて A = ker ψ に入る。d′ は B のコサイクルで値が A に入るから A のコサイクル（Step 12 と同じ論法）。連続性：σ ↦ b₀σ は局所定数なので d′ も連続。よって [d] = [d′] = φ*[d′] ∈ im φ*。

∎（5箇所すべて検証済み）
? δ が「両側から」完全性に絡む理由

検証を並べると、δ は Step 17 で「左の核」、Step 18 で「右の像」として現れます。 つまり δ は「BG から来ない不変元」と「B で消えるコホモロジー類」を同一視する橋です。 本編の標語「δ は割り算の障害を測る」の正確な内容は、この2つの完全性の合わせ技に他なりません。
