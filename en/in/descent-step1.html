Between-the-lines notes ─ Descent and heights N1/N3

Foundations of height ─ the shape of coordinates and finiteness
Denominators are perfect squares & cubes

"In lowest terms we can write P = (a/d², b/d³)", which Main Part IV glossed over in one line ── is in fact the foundation of the whole theory of heights. In this note we nail down a complete proof via p-adic valuations, the basic properties of the height H, and an exact count for property (c), "there are finitely many points of bounded height".

TEXT: Silverman, AEC 2nd ed. ─ VIII §4, VIII.4.2(c) (fully expanded)

Main IV Descent N0 Descent theorem N1 Foundations of height N2 Property (a) addition N3 Property (b) doubling
Section 01

The gaps this note fills

Section 03 of the main part went straight from the definition of height to the proof of property (a), and along the way the following five points sank between the lines.

  • ① Proof of the basic properties of H(t) and hx (H ≥ 1, hx ≥ 0, hx(P) = hx(−P))
  • ② "We can write x = a/d², y = b/d³" ── a complete proof that the denominators automatically come as a pair of a square and a cube
  • ③ The gcd conditions (a ⊥ d, b ⊥ d) and the uniqueness of the representation
  • ④ An exact count for property (c), "{ P : hx(P) ≤ C₃ } is finite" (the reasons for (2C+1)² and "at most 2 values of y for each x")
  • ⑤ Checking with an example ── how the denominators 16 = 4², 64 = 4³, 7744 = 88² appear in the doubling sequence of P = (1,2)

② is the foundation all the estimates in N2 and N3 depend on. Plan: fix the premises as V1–V3, and prove ② with a "local" argument that looks at one prime p at a time.

Section 02

Fixing the premises (V1–V3)

Premise V1 ─ p-adic valuations a restatement of unique prime factorization

For each prime p a function vp : ℚ× → ℤ is defined (the k when we write t = pk·(u/w) with p ∤ uw), satisfying:

(V1-1) vp(st) = vp(s) + vp(t)
(V1-2) vp(s + t) ≥ min{ vp(s), vp(t) }, with equality guaranteed when vp(s) ≠ vp(t)
(V1-3) t ∈ ℤ ⟺ vp(t) ≥ 0 for every p (t ∈ ℚ×)
Convention: vp(0) = +∞ (0 is "divisible infinitely many times" by every p). (V1-2) holds even including 0.
Open the proof of the equality case in (V1-2)

Suppose vp(s) < vp(t). If vp(s+t) > vp(s), then writing s = (s+t) − t, (V1-2) gives vp(s) ≥ min{ vp(s+t), vp(−t) } > vp(s) (both terms are strictly larger than vp(s)), a contradiction. So vp(s+t) = vp(s) = min. "The least divisible term governs how the sum divides" ── the standard consequence of the ultrametric inequality.

Premise V2 ─ lowest terms and the height H AEC VIII §4

t ∈ ℚ can be written as t = p/q (p, q ∈ ℤ, q ≥ 1, gcd(p,q) = 1) in exactly one way, and we define H(t) := max{ |p|, |q| }. Relation to valuations: q = Πℓ ℓmax{0, −vℓ(t)} (the denominator is the collection of "negative valuations").

Premise V3 ─ setting up the curve Main IV, Section 03

Fix E : y² = x³ + Ax + B (A, B ∈ ℤ, Δ ≠ 0). P = (x, y) ∈ E(ℚ) means x, y ∈ ℚ satisfy this equation. hx(P) = log H(x(P)) (P ≠ O), hx(O) = 0.

Section 03

Basic properties of H and hx (gap ①)

1

H(t) ≥ 1 for all t ∈ ℚ. Hence hx(P) = log H(x(P)) ≥ 0 (∀P).

▸ Reason In the representation of V2, q ≥ 1, so max{|p|, |q|} ≥ 1. log is ≥ 0 on [1, ∞). At O, hx(O) = 0 ≥ 0 by convention. The descent theorem didn't need h ≥ 0 (N0), but having it simplifies the estimates everywhere.

2

hx(−P) = hx(P).

▸ Reason −(x, y) = (x, −y)AEC III.2.3(a): the inverse doesn't change the x-coordinate. hx only looks at the x-coordinate, so the values agree. −O = O is consistent with the convention. Thanks to this symmetry, computing C₁′ = max C₁(−Qi) in the descent theorem is essentially the same as computing C₁(Qi) (a by-product of N2).

3

There are finitely many rational numbers t with H(t) ≤ C, at most (2⌊C⌋ + 1)² of them.

▸ Reason t ↦ (p, q) (the reduced representation of V2) is injective. If H(t) ≤ C then |p| ≤ C and |q| ≤ C, i.e. (p, q) lies in the square [−⌊C⌋, ⌊C⌋]² of the integer lattice. That square has (2⌊C⌋+1)² lattice points. With an injection, the count is at most the number of candidates for the image (set theory).

Section 04

The coordinate lemma ─ the denominators are d² and d³ (gaps ②③)

Lemma (shape of coordinates) used implicitly in AEC VIII §4

Let P = (x, y) ∈ E(ℚ), P ≠ O. Then there is exactly one triple of integers a, b and d ≥ 1 with

x = a/d², y = b/d³, gcd(a, d) = gcd(b, d) = 1

In particular H(x(P)) = max{ |a|, d² }, and b² = a³ + Aad⁴ + Bd⁶ (an equation of integers).

The proof is just "fix one prime p and compare the p-parts of the denominators of x and y". The crux is that the curve's equation ties the valuations in a 2 : 3 ratio.

1

Fix a prime p and suppose v := vp(x) < 0. Then vp(x³) = 3v, and vp(Ax + B) ≥ v > 3v.

▸ Reason vp(x³) = 3v is (V1-1). vp(Ax) = vp(A) + v ≥ v (A ∈ ℤ gives vp(A) ≥ 0, (V1-3)), and vp(B) ≥ 0 > v. So by (V1-2), vp(Ax+B) ≥ min{v, 0} = v. The last v > 3v holds because v < 0 (add 2v < 0 to both sides). Even if a term vanishes because A = 0 or B = 0, vp(0) = +∞ ≥ v, so the argument goes through unchanged.

2

Therefore vp(y²) = vp(x³ + (Ax+B)) = 3v. That is, 2·vp(y) = 3v.

▸ Reason In Step 1 the two terms have different valuations (3v < v ≤ vp(Ax+B)), so the equality case of (V1-2) kicks in and the valuation of the sum equals the smaller one, 3v. vp(y²) = 2vp(y) is (V1-1). Note that if y = 0 the left side is +∞, contradicting 3v < ∞, so v < 0 automatically gives y ≠ 0.

3

The left side of 2vp(y) = 3v is even, so v is even too. So v = −2e (e ≥ 1 an integer), and vp(y) = −3e.

▸ Reason 3v is even ⟺ v is even (3 is odd). Since v < 0, e = −v/2 ≥ 1. vp(y) = 3v/2 = −3e. This is where it's settled that the exponents of the denominators come as a pair (2e, 3e).

4

Conversely, at primes with vp(x) ≥ 0, vp(y) ≥ 0.

▸ Reason 2vp(y) = vp(x³+Ax+B) ≥ min{3vp(x), vp(A)+vp(x), vp(B)} ≥ 0 ((V1-2), each term ≥ 0). If y = 0, vp(0) = +∞ ≥ 0, no problem.

5

Set ep := max{ 0, −vp(x)/2 }. Each ep is a nonnegative integer, and it is 0 except for the finitely many primes p appearing in the denominator of x. Define d := Πp pep ≥ 1.

▸ Reason Integrality is Step 3 (if vp(x) < 0, then −vp(x)/2 = e ∈ ℤ). vp(x) ≥ 0 for all but finitely many p because the denominator of x in lowest terms has finitely many prime factors (V2). So d is defined as a finite product.

6

a := x·d² and b := y·d³ are integers, and x = a/d², y = b/d³.

▸ Reason Check with (V1-3). vp(a) = vp(x) + 2ep is −2ep + 2ep = 0 if vp(x) < 0, and vp(x) + 0 ≥ 0 if vp(x) ≥ 0. vp(b) = vp(y) + 3ep is −3ep + 3ep = 0 if vp(x) < 0 (Step 3), and vp(y) ≥ 0 if vp(x) ≥ 0 (Step 4). The valuation is ≥ 0 at every prime, so they are integers.

7

gcd(a, d) = gcd(b, d) = 1.

▸ Reason At a prime p | d we have ep ≥ 1, i.e. vp(x) = −2ep < 0, and by the computation in Step 6, vp(a) = 0 and vp(b) = 0. That is, the prime factors of d divide neither a nor b. This is the first half of gap ③.

8

Uniqueness and the remaining claims: the representation is unique, H(x(P)) = max{|a|, d²}, and moreover b² = a³ + Aad⁴ + Bd⁶.

▸ Reason gcd(a, d) = 1 ⇒ gcd(a, d²) = 1, so a/d² (d² ≥ 1) is itself the reduced representation. Uniqueness of the reduced representation (V2) determines a and d², d ≥ 1 makes d unique too, and b = y·d³ is unique as well. At the same time H(x(P)) = max{|a|, d²} follows immediately from the definition. The last equation is just substituting x = a/d², y = b/d³ into y² = x³+Ax+B and multiplying by d⁶: b²/d⁶ = a³/d⁶ + Aa/d² + B.

∎
Bonus: if y = 0 the denominator disappears (a seed of Lutz–Nagell)

If y = 0 (a 2-torsion point), the contradiction in Step 2 forces vp(x) ≥ 0 at every prime, that is, x ∈ ℤ and d = 1. The first step of the Lutz–Nagell theorem, "the coordinates of torsion points are integers" AEC VIII.7.1–7.2 (main part, Section 06), is already inside this lemma.

? Why 2 and 3 ─ the weights of the Weierstrass equation

The equation y² = x³ + ⋯ becomes homogeneous if you give "x weight 2 and y weight 3" (2·3 = 3·2 = 6). The coordinate lemma says these weights are stamped directly onto the exponents of the denominators. In fact, the same phenomenon seen from inside the p-adics is the filtration of AEC Chapter VII, E₁(ℚp) ⊃ E₂(ℚp) ⊃ ⋯ (the points with vp(x) = −2n, vp(y) = −3n) around AEC VII.2. The global theory of heights and the local theory first shake hands over this "2 : 3".

Section 05

A complete proof of property (c) (gap ④)

Lemma (height property (c)) AEC VIII.4.2(c)

For any constant C₃, { P ∈ E(ℚ) : hx(P) ≤ C₃ } is a finite set.

1

Set C := eC₃. If hx(P) ≤ C₃ and P ≠ O, then H(x(P)) ≤ C.

▸ Reason log H(x(P)) ≤ C₃, and exp is increasing. If C₃ < 0, there is no P ≠ O satisfying the condition (Step 1 of Section 03: hx ≥ 0), so only the case C ≥ 1 matters below.

2

There are finitely many candidates for the x-coordinate: #{ t ∈ ℚ : H(t) ≤ C } ≤ (2⌊C⌋+1)².

▸ Reason Step 3 of Section 03.

3

Fix one x-coordinate; there are at most 2 points P ∈ E(ℚ) with that x-coordinate.

▸ Reason P = (x, y) satisfies y² = x³+Ax+B. In the field ℚ there are at most two elements "whose square is c" (y₁² = y₂² ⇒ (y₁−y₂)(y₁+y₂) = 0 ⇒ y₂ = ±y₁: an integral domain has no zero divisors). So there are at most two candidates for y, ±y₀.

4

Summary: #{ P : hx(P) ≤ C₃ } ≤ 2(2⌊C⌋+1)² + 1 < ∞.

▸ Reason P ≠ O number at most "candidates for x (Step 2) × points per candidate (Step 3)" = 2(2⌊C⌋+1)², and finally we add the one point O. Finite × finite = finite.

∎
For general number fields ─ Northcott's finiteness

Over ℚ, as shown, it's "just counting lattice points", but over a general number field K the candidates for coordinates become "algebraic numbers of bounded height", and you need to control all the conjugates. Even so, "there are finitely many algebraic numbers of bounded height and degree" holds ── this is Northcott's theorem AEC VIII.5.11, the general version of property (iii) that appeared on the map in Section 06 of the main part. The skeleton of the proof is the same "count the coefficients" argument.

Section 06

Checking with an example ─ E : y² = x³ + 3, P = (1, 2) (gap ⑤)

We look again at what's behind the table in Section 05 of the main part, through the eyes of the coordinate lemma. First compute 2P completely:

λ = (3x² + A)/(2y) = 3/4
x(2P) = λ² − 2x = 9/16 − 2 = −23/16,
y(2P) = λ(x(P) − x(2P)) − y(P) = (3/4)(1 + 23/16) − 2 = 117/64 − 128/64 = −11/64
PointCoordinatesdChecking the denominators
P(1, 2)11 = 1², 1 = 1³
2P(−23/16, −11/64)416 = 4², 64 = 4³ ✓
4Px = 2540833/7744887744 = 88² ✓ (the denominator of y is 88³ = 681472)
✓

Reading 2P with the valuation at p = 2: v₂(x(2P)) = v₂(−23/16) = −4 = −2·2, v₂(y(2P)) = v₂(−11/64) = −6 = −3·2.

▸ Reason The pair (−2e, −3e) = (−4, −6) with e₂ = 2 appears exactly ── the real thing behind Step 3's "2 : 3 tie". You can also check gcd(−23, 4) = gcd(−11, 4) = 1 (the gcd condition of the lemma).

Notice too that we can predict the denominator 7744 of 4P is a perfect square before computing it. Whatever integer the denominator G(−23, 16) of the duplication formula turns out to be, the coordinate lemma guarantees "once reduced, it's always the square of (some d)". Indeed 7744 = 88², 88 = 2³·11. d goes from 4 to 88, about 22 times larger ── this explosion of denominators is what the growth hx(2ⁿP) ≈ 4ⁿ (property (b), N3) really is.
