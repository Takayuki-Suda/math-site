Section 02

前提の固定（W1–W4）

前提 W1 ─ 乗法的記法と μm

K は標数 0 の体（数体を想定）、K、G := GK/K は N1 の D1 と同じ。 このノートの主役 K× は乗法群なので、N0 の加法的記法を次の辞書で読み替える：

加法的（N0・N1）乗法的（このノート）
0,　m + n,　−m1,　m·n,　m−1
m 倍　[m]m 乗　z ↦ zm
コサイクル条件　cστ = cστ + cτcστ = cστ · cτ
コバウンダリ　σ ↦ mσ − mσ ↦ βσ/β

μm := { z ∈ K× : zm = 1 }。char 0 では Xm − 1 は分離的 （導関数 mXm−1 との共通根なし）なので #μm = m、しかも μm は位数 m の巡回群 （体の乗法群の有限部分群は巡回群──1の冪根の標準事実）。

前提 W2 ─ 無限 Galois 理論の対応 ANT IV.1.2

G の開正規部分群 U と K 内の有限次 Galois 拡大 L/K は U = GK/L で1対1に対応し（Krull 位相の主定理）、 制限写像により G/U ≅ GL/Kweakmw N1 前提Q4。 固定体は KU = L であり、したがって (K×)U = L×（0 を除くだけ）。

前提 W3 ─ Weil 対 AEC III.8.1

E/K 楕円曲線、m ≥ 2、char 0 とする。次の性質を持つ対（Weil pairing）が存在する：

em : E[m] × E[m] → μm

(a) 双線形：em(S₁+S₂, T) = em(S₁,T)·em(S₂,T)、第2変数も同様。 (b) 交代：em(T, T) = 1（したがって em(S,T) = em(T,S)−1）。 (c) 非退化：em(S, T) = 1 が全ての T ∈ E[m] で成り立てば S = O。 (d) Galois 同変：em(S, T)σ = em(Sσ, Tσ)。 構成は因子と関数の理論による（AEC III §8）。このノートでは性質だけを使う。

前提 W4 ─ N0・N1 の機械

6項完全列と5箇所の完全性（N0 §07）、連続コサイクルの有限段階への降下（N0 §04）、 切り出しの手続きと「誘導写像 = m 倍（乗法版：m 乗）」（N1 Step 9–12）。 乗法群への適用は W1 の辞書を通す。

Section 03

乗法群も機械の枠に入る（行間①②）

1

K× と μm は離散 G-加群である。

▸ 根拠　σ は体の自己同型なので (ab)σ = aσbσ、1σ = 1、つまり各 σ は K× の群自己同型（W1 の辞書で R1(i)）。合成規約 (ii)・恒等 (iii) は体の作用そのもの。離散性：a ∈ K× は K 上代数的だから固定化群は開部分群 GK/K(a) を含む（N1 Step 2 と同じ議論）。μm が G-安定であること：(zσ)m = (zm)σ = 1σ = 1。有限（#μm = m、W1）なので離散。

次は離散 G-加群の短完全列である：

1 → μm → K× →m乗 K× → 1

▸ 根拠　z ↦ zm は準同型（乗法群はアーベル）。G-同変：(zm)σ = (zσ)m（体準同型）。核は μm（定義）。全射：a ∈ K× に対し Xm − a は代数閉体 K に根 α を持ち、a ≠ 0 なので α ≠ 0、つまり α ∈ K×。包含 μm ⊆ K× は G-同変単射（Step 1 の G-安定性）。

1 → μm(K) → K× →m乗 K× →δ H¹(G, μm) → H¹(G, K×) →(m乗)* H¹(G, K×)

1 → K×/(K×)m →δ H¹(G, μm) → H¹(G, K×)[m] → 1,　δ(a) = [ σ ↦ ασ/α ]（αm = a）

▸ 根拠　(K×)G = K× は KG = K（N1 D1）から 0 を除くだけ。μm(K) := μm ∩ K×。δ の表示は N0 Step 11 の構成で持ち上げとして「m 乗根 α」を選んだもの（乗法版の bσ − b が ασ/α）AEC VIII.2.2。誘導写像 (m乗)* が「H¹ の類の m 乗」に一致すること・切り出しの3箇所の完全性は、N1 Step 9–12 の証明が文字の読み替えだけでそのまま通る（使った性質は「Z¹ の演算が点ごと」「完全性5箇所」のみで、加法性は使っていない）。

Section 04

Dedekind の独立性補題（行間③の鍵）

補題（指標の一次独立性：Dedekind–Artin） Lang, Algebra VI §4

H を群、L を体、χ₁, …, χn : H → L× を相異なる群準同型（指標）とする。 χ₁, …, χn は L 上一次独立：a₁χ₁(h) + ⋯ + anχn(h) = 0 が すべての h ∈ H で成り立てば a₁ = ⋯ = an = 0。

4

最短の非自明な関係式を仮定して矛盾を導く（n についての最小反例法）。

▸ 根拠　非自明な関係式（係数が全部は 0 でない）のうち、0 でない係数の個数が最小のものを取る。0 の係数の項を落とし、番号を付け替えて a₁, …, an ≠ 0 としてよい。n = 1 なら h = e を代入して a₁χ₁(e) = a₁·1 = 0、矛盾。よって n ≥ 2。χ₁ ≠ χn なので χ₁(h₀) ≠ χn(h₀) となる h₀ ∈ H が取れる。

5

h₀ を使って関係式を1つ短くする──これで矛盾。

▸ 根拠　任意の h で、関係式に h₀h を代入：Σ aiχi(h₀)χi(h) = Σ aiχi(h₀h) = 0。一方、元の関係式を χn(h₀) 倍：Σ aiχn(h₀)χi(h) = 0。差を取ると i = n の項が消えて Σi≤n−1 ai(χi(h₀) − χn(h₀))χi(h) = 0（∀h）。第1項の係数 a₁(χ₁(h₀) − χn(h₀)) ≠ 0 なので、これは 0 でない係数の個数が n より少ない非自明な関係式。最小性に矛盾。∎

応用の形：L/K を有限次 Galois 拡大とすると、相異なる τ ∈ GL/K は L× → L× の相異なる指標（乗法を保つ）なので、L 上一次独立です。 すなわち係数 cτ ∈ L× がすべて 0 でない限り、関数 z ↦ Στ cτ·zτ は恒等的に 0 ではありません。

Section 05

有限次版 Hilbert 90（行間③）

定理（Hilbert の定理 90・有限次版） ANT IV.3.5

L/K を有限次 Galois 拡大、G := GL/K とすると：

H¹( GL/K, L× ) = 1　（すべての1-コサイクルはコバウンダリ σ ↦ βσ/β）
6

平均化の準備：c ∈ Z¹(GL/K, L×) を取る。ある a ∈ L× で

b := Στ ∈ GL/K cτ · aτ ≠ 0

▸ 根拠　係数 cτ は L× の元、つまりすべて 0 でない。§04 の補題（応用の形）より z ↦ Σ cτzτ は L× 上恒等的に 0 でないので、b ≠ 0 となる a ∈ L× が存在する。和は有限（GL/K は有限群）なので b ∈ L。

7

コサイクル条件で b の Galois 軌道を計算：bσ = cσ−1 · b（∀σ）。

▸ 根拠　bσ = Στ cτσ · aτσ（作用は体準同型、(aτ)σ = aτσ は右作用規約）。コサイクル条件（W1 の辞書）を組 (τ, σ) で読むと cτσ = cτσ · cσ、つまり cτσ = cτσ · cσ−1。代入して bσ = cσ−1 Στ cτσ aτσ。τ ↦ τσ は GL/K の全単射（群の右移動）なので和は b に一致：bσ = cσ−1 b。

8

結論：β := b−1 とおくと cσ = βσ/β。つまり c はコバウンダリで、H¹ = 1。

▸ 根拠　βσ/β = (bσ)−1/b−1 = b/bσ = b/(cσ−1b) = cσ（Step 7）。b ∈ L× なので β ∈ L×。任意のコサイクルがコバウンダリになったので H¹(GL/K, L×) = 1。∎

? 古典形（巡回拡大のノルム定理）との関係

GL/K = ⟨σ⟩ が巡回群のとき、コサイクルは1つの値 cσ で決まり、 コサイクル条件は「NL/K(cσ) = 1」に化けます。すると定理は 『ノルム 1 の元は βσ/β の形』──ant.html 棚4 に「古典形」として並べた主張です。 Hilbert の原論文（数論報文 Satz 90）はこの形でした。上の証明の b は「Poincaré 級数」と 呼ばれる平均化で、体の加法を借りて乗法群の問題を解くのがミソです。

Section 06

射有限版への持ち上げと同型 δ（行間④）

定理（Hilbert 90・射有限版） AEC B.2.5
H¹( GK/K, K× ) = 0（乗法的に書けば = 1）
9

証明：連続コサイクルを有限段階に降ろして §05 を適用する。

▸ 根拠　c を連続コサイクルとする。K× は離散 G-加群（Step 1）なので N0 §04 の定理が使え、開正規部分群 U があって c は c̄ ∈ Z¹(G/U, (K×)U) の inflation。W2 より U = GK/L（L/K 有限次 Galois）、G/U ≅ GL/K、(K×)U = L×。つまり c̄ ∈ Z¹(GL/K, L×)。§05 の定理より c̄σ̄ = βσ̄/β なる β ∈ L× が存在。inflation はコバウンダリをコバウンダリに移す：cσ = c̄σU = βσ|L/β = βσ/β（β ∈ L なので σ の作用は制限 σ|L で決まる）。よって [c] = 0。∎

帰結（連結準同型が同型になる） AEC VIII.2.2
δ : K×/(K×)m ≅ H¹(G, μm),　δ(a) = [ σ ↦ ασ/α ]　（αm = a）

Step 3 の切り出した完全列の右端 H¹(G, K×)[m] が 0 になったので、 単射 δ は全射でもある。乗法群の「m 乗根の理論」は K×/(K×)m で完結する ──本編 §04 の対比表の左列がすべて検証済みになった。

? 同じ証明が楕円曲線で走らない場所はどこか

§05 の証明の心臓部は b = Σ cτaτ という平均化で、 「乗法群の元 cτ を係数、体の加法で和を取る」という操作でした。 E(K) には「係数を掛ける」も「体の加法」もありません──点の加法しかない。 だから同じ平均化が定義できず、実際 H¹(G, E) は一般に消えません（本編 §04 の表の右下）。 あの「≠ 0」の一マスは、平均化できないという構造的な理由の現れです。

Section 07

Weil 対で E[m] を μm に接続する（行間⑤⑥）

以後この節では E[m] ⊂ E(K) を仮定します（本編 §07 と同じ設定。 m = 2 なら「ei が全部 K にある」ことと同値）。

10

系：E[m] ⊂ E(K) ならば μm ⊂ K×。AEC III.8.1.1

▸ 根拠　基底 T₁, T₂ ∈ E[m] を取る（E[m] ≅ (ℤ/mℤ)²、N1 D3）。ζ := em(T₁, T₂) とおき、ζ の位数を d（d | m）とする。任意の S = [a]T₁ + [b]T₂ に対し、双線形性(a)と交代性(b)より em([d]T₁, S) = em(T₁, T₁)da · em(T₁, T₂)db = 1 · (ζd)b = 1。非退化性(c)より [d]T₁ = O。T₁ の位数はちょうど m（基底）なので m | d、よって d = m。つまり ζ は原始 m 乗根で μm = ⟨ζ⟩（W1：μm は位数 m の巡回群）。Galois 同変性(d)と Ti ∈ E(K) より ζσ = em(T₁σ, T₂σ) = em(T₁, T₂) = ζ（∀σ）、つまり ζ ∈ KG = K。よって μm = ⟨ζ⟩ ⊂ K×。

11

写像 w : E[m] → μm × μm,　S ↦ ( em(S, T₁), em(S, T₂) ) は G-加群の同型である。

▸ 根拠　準同型：第1変数の双線形性(a)。単射：w(S) = (1,1) なら、任意の T = [a]T₁+[b]T₂ に対し em(S,T) = em(S,T₁)aem(S,T₂)b = 1、非退化性(c)より S = O。全単射：単射＋両辺の位数が m² で等しい（#E[m] = m²、#(μm×μm) = m²）。G-同変：w(Sσ) = (em(Sσ, T₁), …) = (em(Sσ, T₁σ), …) = (em(S, T₁)σ, …) = w(S)σ（Ti は K-有理で不動＋同変性(d)）。なお今の仮定下では両辺とも G の作用は自明（E[m] ⊂ E(K)、μm ⊂ K：Step 10）なので、同変性は「自明作用同士」としても成立している──本編 §07 の「G-加群として。μ₂ = {±1} は作用自明なので単に (ℤ/2)²」という括弧書きの中身。

12

同型は H¹ の同型を誘導し、直積は成分ごとに分解する。結論：

H¹(G, E[m]) ≅w* H¹(G, μm × μm) ≅ H¹(G, μm)² ≅ ( K×/(K×)m )²

▸ 根拠　第1の同型：f* の構成（N0 Step 10）は合成と恒等を保つ──(g∘f)*[c] = [(g∘f)∘c] = g*f*[c]、(id)* = id は定義から点ごとに明らか。よって (w−1)*∘w* = (w−1∘w)* = id、逆向きも同様で w* は同型。第2の同型：直積加群のコサイクルは成分の組 c = (c′, c″) で、コサイクル条件・コバウンダリ・連続性がすべて成分ごとに読めるから、射影が誘導する写像 [c] ↦ ([c′], [c″]) は同型（逆写像は組み立て）。第3の同型：§06 の帰結の2連装。

帰結（本編 §07 の同一視）

E[m] ⊂ E(K) のとき、N1 の Kummer 完全列の δ は単射準同型

E(K)/mE(K) ↪ ( K×/(K×)m )²

を与える。m = 2 では μ₂ = {±1} ⊂ K が常に成り立つので、 仮定は「e₁, e₂, e₃ ∈ K」だけ。これが本編 §07 の H¹(G, E[2]) ≅ K×/(K×)² × K×/(K×)² の完全な根拠である。

Section 08

m = 2 の具体化 ─「x − ei」の準同型性（行間⑦）

E : y² = f(x) = (x − e₁)(x − e₂)(x − e₃)、ei ∈ K、Ti = (ei, 0) とします。 本編 §07 の写像 φ = (φ₁, φ₂)、φi(P) = x(P) − ei（一般点。特殊値は §07 の規則）が なぜ準同型なのか──全てを支えるのは、次の初等的な恒等式です。

補題（直線の恒等式・sympy 検証済み）

P₁, P₂ ∈ E（どちらも O でない）を通る直線（P₁ = P₂ のときは接線）を y = λx + ν とし、 P₃ := −(P₁ + P₂) ≠ O とする。xj := x(Pj) と書くと、任意の e に対し：

(x₁ − e)(x₂ − e)(x₃ − e) = (λe + ν)² − f(e)
特に e = ei（f の根）では　(x₁ − ei)(x₂ − ei)(x₃ − ei) = (λei + ν)²　＝ 平方
13

恒等式の証明。

▸ 根拠　g(x) := f(x) − (λx + ν)² はモニック3次式。弦の場合（x₁ ≠ x₂）：P₁, P₂ は直線上の E の点なので yj = λxj + ν かつ yj² = f(xj)、ゆえに g(x₁) = g(x₂) = 0。第3の根は根と係数の関係（x² の係数の比較）で λ² + (e₁+e₂+e₃) − x₁ − x₂ となり、これは加法公式の x(P₁+P₂) に一致AEC III.2.3。x(−P) = x(P) なので x₃ = x(P₁+P₂) はこの第3根。接線の場合（P₁ = P₂、y₁ ≠ 0、λ = f′(x₁)/(2y₁)）：g(x₁) = 0 に加え g′(x₁) = f′(x₁) − 2λ(λx₁+ν) = f′(x₁) − 2λy₁ = 0 なので x₁ は二重根、第3根が x₃ = x([2]P₁)。どちらの場合も g(x) = (x − x₁)(x − x₂)(x − x₃)。あとは x = e を代入：g(e) = (e−x₁)(e−x₂)(e−x₃) = −(x₁−e)(x₂−e)(x₃−e)。整理して主張の式。e = ei では f(ei) = 0。

sympy による厳密検証（方針と結果）

弦：x₁, x₂, y₁, y₂, e₁, e₂, e₃, e を不定元とし、λ = (y₂−y₁)/(x₂−x₁)、ν = y₁ − λx₁、 x₃ = λ² + (e₁+e₂+e₃) − x₁ − x₂ とおく。差 (x₁−e)(x₂−e)(x₃−e) − {(λe+ν)² − f(e)} の分母を払った多項式を、 関係式 y₁² − f(x₁)、y₂² − f(x₂) で剰余を取ると恒等的に 0。 e = e₁, e₂, e₃ を代入した掲載形も同様に 0。

接線：λ = f′(x₁)/(2y₁)、x₃ = λ² + (e₁+e₂+e₃) − 2x₁ として (x₁−e)²(x₃−e) − {(λe+ν)² − f(e)} を y₁² − f(x₁) で簡約 → 恒等的に 0。 あわせて特殊値規則の整合 (e₁−e₂)(e₁−e₃) ÷ {(e₁−e₃)/(e₁−e₂)} = (e₁−e₂)²（完全平方）も確認済み。

14

φi の準同型性（一般位置）。P₁, P₂, P₁+P₂ がどれも O でも 2-分点でもないとき：

φi(P₁) · φi(P₂) · φi(P₁+P₂) = (x₁−ei)(x₂−ei)(x₃−ei) = (λei+ν)² ≡ 1

▸ 根拠　x(P₁+P₂) = x(−(P₁+P₂)) = x₃ なので左の等号は定義。中央は Step 13（P₁, P₂ ∈ E(K) なら λ, ν ∈ K：弦なら座標の有理式、接線なら f′(x₁)/(2y₁)。x₁ = x₂ かつ P₁ ≠ P₂ なら P₂ = −P₁ で P₁+P₂ = O となりこの場合には入らない）。λei+ν ≠ 0 は「P₁+P₂ が 2-分点でない」ことから（= 0 なら x₃ = ei の二重・三重交点になる）。K×/(K×)² では各類が自分自身の逆元（t² ≡ 1）なので、積 ≡ 1 は φi(P₁+P₂) = φi(P₁)φi(P₂) と同値。O が絡む場合：φi(O) = 1 と P + O = P で自明。P₂ = −P₁ の場合：φi(P₁)φi(−P₁) = (x₁−ei)² ≡ 1 ✓。

15

2E(K) は核に入る──しかも「平方根」が明示的に書ける：

x([2]P) − ei = ( (λei+ν)/(x(P)−ei) )²　（接線 y = λx+ν、x(P) ≠ ei）

▸ 根拠　接線の場合の Step 13：(x₁−ei)²(x₃−ei) = (λei+ν)²、x₃ = x([2]P)。両辺を (x₁−ei)² で割るだけ。形式的には準同型性（Step 14）だけからも φi([2]P) = φi(P)² ≡ 1 が出る（行き先は指数2の群）が、この明示式が「2-降下の計算可能性」の源泉──第2部で L = ℚ(√−1, √2) が手計算できたのはこの式のおかげである。

? 特殊値規則の出どころ

y ≠ 0 の点では (x−e₁)(x−e₂)(x−e₃) = y² ≡ 1、つまり3成分の平方類の積は常に 1です。 T₁ = (e₁, 0) では第1成分 x−e₁ が 0 になって使えませんが、積 ≡ 1 の関係から 「残り2成分の積」で代用できます：φ₁(T₁) = (e₁−e₂)(e₁−e₃)。 本編 §07 の規則 (e₁−e₃)/(e₁−e₂) はこれと (e₁−e₂)² 倍しか違わず、同じ平方類です （sympy 確認済み）。規則が「気まぐれな約束」ではなく、恒等式の必然だと分かります。
