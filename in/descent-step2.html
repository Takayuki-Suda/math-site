性質(a)の完全証明 ─ 加法と高さ
Translation doubles the height, at most

hx(P + P₀) ≤ 2hx(P) + C₁(P₀)──本編Ⅳ Section 03 で「要点＋行間」とした証明を、 例外ケースの処理から定数 C₁ の完全な明示形まで、飛躍ゼロで書き切ります。 急所は1箇所だけ：y の項 |bd| を曲線の方程式そのもので抑えるところです。

TEXT: Silverman, AEC 2nd ed. ─ VIII.4.2(a)（完全展開）

本編Ⅳ 降下法 N0 降下定理 N1 高さの土台 N2 性質(a) 加法 N3 性質(b) 倍加
Section 01

このノートで埋める行間

  • ① 例外ケース（P₀ = O、P ∈ {O, P₀, −P₀}）で C₁ をどう取るかの明示
  • ② 加法公式を対称形 ((xx₀+A)(x+x₀)+2B−2yy₀)/(x−x₀)² に変形する計算の全行
  • ③ 分母 d⁴d₀⁴ を掛けて整数の分数にする操作の項別チェック
  • ④ 「約分は高さを下げるだけ」の正確な主張と証明
  • ⑤ 邪魔者 |bd| を M² で抑える議論の完全版（曲線の方程式の使用箇所）
  • ⑥ 定数 C₁(P₀, A, B) の完全な明示形

前提は A1–A3 の3つ。特に A1（N1 の座標補題）が全計算の土台です。

Section 02

前提の固定（A1–A3）

前提 A1 ─ 座標の形と高さ N1 で完全証明済み

O でない P ∈ E(ℚ) は P = (a/d², b/d³)（a, b ∈ ℤ, d ≥ 1, gcd(a,d) = gcd(b,d) = 1）と一意に書け、

H(x(P)) = max{ |a|, d² } =: M,　b² = a³ + Aad⁴ + Bd⁶　（整数の等式）

また hx ≥ 0、hx(P) = hx(−P)。

前提 A2 ─ 加法公式 AEC III.2.3(d)

P = (x, y), P₀ = (x₀, y₀)、x ≠ x₀ のとき、λ = (y − y₀)/(x − x₀) として x(P + P₀) = λ² − x − x₀。 なお E 上で x(P) = x(P₀) ⟺ P = ±P₀（同じ x を持つ点は (x, ±y) の2つだけ）。

前提 A3 ─ 絶対値の初等評価と約分 初等整数論

|s + t| ≤ |s| + |t|、|st| = |s||t|。さらに（行間④）：t = N/D（N, D ∈ ℤ, D ≠ 0）ならば H(t) ≤ max{ |N|, |D| }。

H(t) ≤ max{|N|,|D|} の証明を開く

g = gcd(N, D) ≥ 1、p = N/g、q = ±D/g（符号は q ≥ 1 になるよう選ぶ）とすると t = p/q は既約表示。よって H(t) = max{|p|, |q|} = max{|N|, |D|}/g ≤ max{|N|, |D|}。 約分（g で割ること）は高さを下げる方向にしか働かない──上からの評価では 約分を完全に無視してよい理由がこれである。（下からの評価ではそうはいかない。N3 の主題。）

Section 03

主張と例外ケース（行間①）

補題（高さの性質 (a)） AEC VIII.4.2(a)

P₀ ∈ E(ℚ) を固定すると、定数 C₁ = C₁(P₀, A, B) が存在して、 すべての P ∈ E(ℚ) で hx(P + P₀) ≤ 2hx(P) + C₁。

1

P₀ = O の場合：C₁ = 0 でよい。以後 P₀ = (a₀/d₀², b₀/d₀³) ≠ O とする。

▸ 根拠　h(P + O) = h(P) ≤ 2h(P) + 0。h(P) ≥ 0（A1）を使った。P₀ の座標表示は A1。

2

P ∈ { O, P₀, −P₀ } の場合：C₁ ≥ max{ h(P₀), h(2P₀) } と取っておけば不等式は成立。以後この3点を除外する。すると x(P) ≠ x(P₀) で A2 の公式が使え、P + P₀ ≠ O。

▸ 根拠　P = O なら P+P₀ = P₀ で h(P₀) ≤ C₁ ≤ 2h(P)+C₁。P = P₀ なら h(2P₀) ≤ C₁。P = −P₀ なら P+P₀ = O で h(O) = 0 ≤ 2h(P)+C₁（C₁ ≥ 0：h の値は ≥ 0）。取り除いたのは高々3点だが、C₁ はその3点での値を「丸呑み」できる──(i) 型の不等式は定数項に余裕があるから例外は怖くない。これが行間①。x(P) ≠ x(P₀) は A2 の最後の主張の対偶。P+P₀ = O ⟺ P = −P₀ も除外済み。

Section 04

加法公式の対称形（行間②）

3

λ² − x − x₀ を1つの分数にまとめる：

x(P + P₀) = (y − y₀)²/(x − x₀)² − (x + x₀) = [ (y − y₀)² − (x + x₀)(x − x₀)² ] / (x − x₀)²

▸ 根拠　A2 と通分。x ≠ x₀（Step 2）なので分母は 0 でない。

4

分子の2つの塊を展開する：

(y − y₀)² = y² + y₀² − 2yy₀ = x³ + x₀³ + A(x + x₀) + 2B − 2yy₀
(x + x₀)(x − x₀)² = x³ + x₀³ − x²x₀ − xx₀²

▸ 根拠　1行目：y² = x³+Ax+B と y₀² = x₀³+Ax₀+B（両方の点が曲線上にあること）を足した。2行目：(x−x₀)² = x²−2xx₀+x₀² を展開して (x+x₀) を掛け、6項のうち −2x²x₀+x²x₀ = −x²x₀、xx₀²−2xx₀² = −xx₀² とまとめた。

5

差を取ると x³, x₀³ が消えて：

分子 = x²x₀ + xx₀² + A(x + x₀) + 2B − 2yy₀ = (xx₀ + A)(x + x₀) + 2B − 2yy₀
∴ x(P + P₀) = [ (xx₀ + A)(x + x₀) + 2B − 2yy₀ ] / (x − x₀)²

▸ 根拠　x²x₀ + xx₀² = xx₀(x + x₀) の因数分解のみ。3次の項が消えて各変数について次数2以下になった──「高さ2倍」の“2”はこの次数である。これが行間②の完成形（本編の式）。

Section 05

整数化 ─ d⁴d₀⁴ を掛ける（行間③④）

6

x = a/d², y = b/d³, x₀ = a₀/d₀², y₀ = b₀/d₀³ を代入し、分子分母に d⁴d₀⁴ を掛けると x(P+P₀) = N/D、ここで

N = (aa₀ + Ad²d₀²)(ad₀² + a₀d²) + 2Bd⁴d₀⁴ − 2(bd)(b₀d₀)
D = (ad₀² − a₀d²)²　（≠ 0）

▸ 根拠　項別に分母を確認（行間③）：xx₀+A = (aa₀+Ad²d₀²)/(d²d₀²)、x+x₀ = (ad₀²+a₀d²)/(d²d₀²)、積の分母は d⁴d₀⁴。2yy₀ = 2bb₀/(d³d₀³) に d⁴d₀⁴ を掛けると 2bb₀dd₀ = 2(bd)(b₀d₀)──ちょうど1乗ずつ余る。(x−x₀)² = (ad₀²−a₀d²)²/(d⁴d₀⁴)。すべての項が同じ d⁴d₀⁴ で払える。N, D ∈ ℤ。D ≠ 0 は x ≠ x₀。

7

H(x(P + P₀)) ≤ max{ |N|, |D| }。

▸ 根拠　A3（行間④）。N/D は既約とは限らないが、上からの評価には約分を無視してよい。

Section 06

評価 ─ M² で抑える（行間⑤⑥）

M := max{ |a|, d² } = H(x(P)) とおきます。使う関係は |a| ≤ M、d² ≤ M（ゆえに d ≤ M1/2、d⁴ ≤ M²）だけ。

8

y の絡まない3つの塊は素直に M で抑わる：

|ad₀² + a₀d²| ≤ (d₀² + |a₀|)·M,　|aa₀ + Ad²d₀²| ≤ (|a₀| + |A|d₀²)·M
|2Bd⁴d₀⁴| ≤ 2|B|d₀⁴·M²,　|D| = (ad₀² − a₀d²)² ≤ (d₀² + |a₀|)²·M²

▸ 根拠　三角不等式（A3）と |a| ≤ M, d² ≤ M。たとえば |ad₀²+a₀d²| ≤ d₀²|a| + |a₀|d² ≤ d₀²M + |a₀|M。D は1つ目の評価を2乗した。

9

急所（行間⑤）：|b| ≤ (1+|A|+|B|)1/2·M3/2、したがって |bd| ≤ (1+|A|+|B|)1/2·M²。

▸ 根拠　A1 の整数等式 b² = a³ + Aad⁴ + Bd⁶ に三角不等式：|b|² ≤ |a|³ + |A||a|d⁴ + |B|d⁶。3項とも M³ 以下（|a|³ ≤ M³、|a|d⁴ ≤ M·M²、d⁶ = (d²)³ ≤ M³）なので |b|² ≤ (1+|A|+|B|)M³。平方根を取り、d ≤ M1/2 を掛ける。b（≒ y座標）は単独では M と無関係に見えるが、「P が曲線上にある」という等式が |b| ~ M3/2 という上限を強制する──証明全体で曲線の方程式が定量的に効くのはこの1箇所（と Step 4 の1行目）だけである。

10

合併して κ を定義：

|N| ≤ [ (|a₀| + |A|d₀²)(d₀² + |a₀|) + 2|B|d₀⁴ + 2|b₀|d₀·(1+|A|+|B|)1/2 ]·M²
κ := max{ 上の [ ] 内, (d₀² + |a₀|)² }　⇒　max{|N|, |D|} ≤ κ·M²

▸ 根拠　N の3つの塊に Step 8–9 の評価を代入し三角不等式でまとめた。|2(bd)(b₀d₀)| ≤ 2|b₀|d₀·|bd|。κ は P₀ と A, B だけの定数（P に依らない）。

11

対数を取って仕上げ：

H(x(P+P₀)) ≤ κ·M² = κ·H(x(P))²　⇒　h(P + P₀) ≤ 2h(P) + log κ
C₁(P₀, A, B) := max{ log κ, h(P₀), h(2P₀) }

▸ 根拠　Step 7 + Step 10、log の単調性と log(uv) = log u + log v。最後の max は Step 2 の例外ケースを合流させた（行間①⑥）。κ ≥ (d₀²+|a₀|)² ≥ 1 なので log κ ≥ 0 であることにも注意。

∎
副産物：C₁(Q) = C₁(−Q)

−P₀ = (a₀/d₀², −b₀/d₀³) であり、κ の式は b₀ を絶対値でしか見ていない。 さらに h(−P₀) = h(P₀)、h(−2P₀) = h(2P₀)（N1）。よって上の構成では C₁(P₀) = C₁(−P₀) が 自動的に成り立つ。降下定理（N0 Step 1）で必要だった C₁′ = maxi C₁(−Qi) は、 代表元自身の定数 maxi C₁(Qi) と同じ値でよい──符号の心配は最初から不要だったことになる。

? この証明には「下からの評価」が1つもない

分母 D がどれほど小さくなろうと、N/D がどれほど約分されようと、上からの評価には響かない （A3：約分は高さを下げるだけ）。だから (a) の証明は「全部を M² で上から抑える」だけの 一方通行で済みました。(b) では逆に「H(x(2P)) が小さくなりすぎない」ことを言う必要があり、 約分の量そのものを制御しなければなりません。その道具が2本の恒等式です──N3 へ。
