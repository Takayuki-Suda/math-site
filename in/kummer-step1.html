行間ノート ─ Kummer対 N1/N3

楕円曲線の Kummer 完全列
Plugging E into the Six-Term Machine

N0 で組み立てた6項完全列の機械に、A = E[m]、B = C = E(K)、ψ = [m] を差し込みます。 本編が「切り出すと得られます」と一行で述べた Kummer 完全列について、 E(K) が機械の使用条件（離散 G-加群）を満たすことの検証、 記号 [m] の二重の意味の整合、切り出しの手続きそのもの、 そして δ が第2部の Kummer 対 κ と文字通り一致するところまでを、一行も飛ばさずに埋めます。

TEXT: Silverman, AEC 2nd ed. ─ Ch. VIII §2（完全展開）

本編Ⅲ Kummer対 N0 コホモロジーの土台 N1 Kummer完全列 N2 Hilbert 90 N3 inf–resと不分岐
Section 01

このノートで埋める行間

  • ① E(K) と E[m] が N0 §04 の「離散 G-加群」の枠に入ること──N0 が「検証は N1・N2 で行う」と予告した宿題の前半
  • ② 0 → E[m] → E(K) → E(K) → 0 が G-加群の短完全列であること（3箇所の完全性と [m] の G-同変性）
  • ③ 6項完全列の左3項が E(K)[m] → E(K) → E(K) に化けること──E(K)G = E(K) の検証
  • ④ 右端の写像 [m]* が「H¹ という群の m 倍写像」に一致すること。本編の H¹(G, E)[m] という表記はこの一致を暗黙に使っている
  • ⑤ 切り出しの手続き：6項完全列から短完全列 0 → E(K)/mE(K) → H¹(G, E[m]) → H¹(G, E)[m] → 0 を作る各段の検証
  • ⑥ δ = κ の確認と、「mE(K) の元による差」がコバウンダリに落ちるまでもなく最初から消えている仕組み

前提は §02 の D 系列で固定します。N0 の R 系列と成果 （6項完全列・連続コサイクル定理・f*・δ の構成）はそのまま引き継ぎます。 このノートを読み終えると、本編 §03 のすべての行が root まで遡れる状態になります。

Section 02

前提の固定（D1–D4）

前提 D1 ─ 舞台（体と Galois 群）

K を標数 0 の体（数体を想定）、K を固定した代数閉包、 G := GK/K とする。KG = K （char 0 なので K/K は Galois。weakmw N1 前提Q2）。 G は Krull 位相で射有限群であり、有限次拡大 L/K に対し GK/L は開部分群 ANT IV.1.2。

前提 D2 ─ 点集合の群構造と Galois 作用 AEC III.2.2 / III.3.6

E/K を K 係数の Weierstrass 方程式で与えられた楕円曲線とする。E(K) はアーベル群で、 加法と逆元は K 係数の射で与えられる。σ ∈ G は P = (x, y) ↦ Pσ = (xσ, yσ)、Oσ = O で作用し、 加法と可換：(P + Q)σ = Pσ + Qσ （弦と接線の公式が K 係数の有理式であることによるAEC III.2.3、 完全展開はweakmw N0 前提P2）。 合成は右作用の規約で読む：Pστ = (Pσ)τweakmw N1 前提Q3。 これは N0 の R1(i)(ii)(iii) のうち (i)(ii) の実体で、(iii)（恒等写像は動かさない）は座標ごとに自明。

前提 D3 ─ [m] と E[m] AEC III.6.2 / III.6.4

m ≥ 2 とする。[m] : E → E は次数 m² の同種写像AEC III.6.2(a)で、 加法の m 回反復だから G 作用と可換：([m]P)σ = [m](Pσ)（D2 の可換性の反復）。 E[m] := ker [m] ⊂ E(K)。char 0 では E[m] ≅ (ℤ/mℤ)²、特に #E[m] = m²AEC III.6.4。 [m] : E(K) → E(K) は全射 （非定数射は代数閉体上の点で全射AEC II.2.3。 完全証明はweakmw N1 前提Q1）。

前提 D4 ─ N0 の機械（そのまま使う部品）

N0 で組み立てた次の部品を引用する：6項完全列と5箇所の完全性（N0 §07）、 連続コサイクルの有限段階への降下（N0 §04）、f* の構成（N0 Step 10）、 連結準同型 δ の構成と well-defined 性（N0 Step 11–14）。 E(K) は加法群なので、N0 の加法的記法がそのまま適用できる。

Section 03

E(K) と E[m] は離散 G-加群（行間①）

N0 §04 の機械は「射有限群 G ＋ 離散 G-加群」という使用条件付きでした。 E(K) がこの条件を満たすことは、本編では一度も検証されていません。ここで埋めます。

1

E(K) は G-加群である（N0 R1 の (i)(ii)(iii) を満たす）。

▸ 根拠　まず作用が「点を点に移す」こと：P = (x, y) ∈ E(K) が Weierstrass 方程式を満たすなら、方程式の係数は K の元で σ に固定されるから、両辺に σ を通すと (xσ, yσ) も同じ方程式を満たす。(i) 各 σ が群準同型であることは D2 の (P+Q)σ = Pσ + Qσ。(ii) 合成の規約 Pστ = (Pσ)τ は座標への体の作用の合成（weakmw N1 前提Q3）。(iii) Pe = P は恒等写像の定義。

2

各点の固定化群は開部分群を含む。したがって E(K) は離散 G-加群（N0 §04 の枠に入る）。同値な言い換え：

E(K) = ⋃L E(L)　（L は K の有限次拡大を走る）

▸ 根拠　P = (x, y) ∈ E(K) の座標 x, y は K 上代数的だから、LP := K(x, y) は有限次拡大。σ ∈ GK/LP は x, y を固定するので Pσ = P。つまり P の固定化群は開部分群 GK/LP（D1）を含む。逆向きの包含 ⋃ E(L) ⊆ E(K) は自明、⊇ は今の LP の構成。O は全ての σ で不変（D2）。

3

E[m] は E(K) の有限な G-部分加群である（したがってこれも離散 G-加群）。

▸ 根拠　部分群であることは [m] が準同型（D3）の核だから。G-安定性：T ∈ E[m] なら [m](Tσ) = ([m]T)σ = Oσ = O（D3 の可換性）、つまり Tσ ∈ E[m]。有限性は #E[m] = m²（D3）。弱MW本編が「E[m] の各点の座標は K 内の代数的数」AEC III.6.4と述べたことは、Step 2 の議論の特別な場合として回収される。

? 「有限次拡大を経由する」の実像

Step 2 の等式 E(K) = ⋃ E(L) が、N0 §04 の定理と噛み合う場所です。 E[m] に値を取る連続コサイクルは、有限次 Galois 拡大 L ⊇ K(E[m]) を1つ取れば GL/K のコサイクルの inflation として書けます。第2部が終始「有限群 GL/K の手計算」で 済ませられたのは、この2つの事実の合わせ技だったわけです。

Section 04

短完全列の検証（行間②）

補題（Kummer の短完全列） AEC VIII §2

次は離散 G-加群と G-同変準同型の短完全列である：

0 → E[m] →ι E(K) →[m] E(K) → 0
4

ι（包含）は単射な G-同変準同型。

▸ 根拠　包含写像は単射準同型。G-同変性は E[m] が G-部分加群であること（Step 3）そのもの──部分加群の包含は定義から同変。

5

im ι = ker [m]。すなわち中央で完全。

▸ 根拠　E[m] := ker [m]（D3 の定義）なので、包含の像がちょうど核。検証すべきことは定義の照合だけだが、N0 R2 の「A ⊆ B と同一視し、ψ の核がちょうど A」という約束がここで文字通り満たされていることの確認が行間②の前半。

6

[m] : E(K) → E(K) は全射な G-同変準同型。以上で短完全列が成立。

▸ 根拠　準同型：[m] は加法の反復（D3）。全射：AEC II.2.3 + III.6.2(a)（D3、完全証明は weakmw N1 前提Q1）。G-同変性：([m]P)σ = [m](Pσ)（D3）。連続性の注記：離散加群の間の写像なので、写像自体の連続性は問題にならない（N0 Step 10 の注記と同じ）。

Section 05

6項完全列を回す（行間③）

Step 1–6 で使用条件がすべて確認できたので、N0 §07 の定理を A = E[m], B = C = E(K), ψ = [m] に適用できます：

0 → E[m]G → E(K)G →[m] E(K)G →δ H¹(G, E[m]) →ι* H¹(G, E(K)) →[m]* H¹(G, E(K))

あとは不変部分を計算するだけです。

7

E(K)G = E(K)、および E[m]G = E(K)[m]。

▸ 根拠　（⊇）P ∈ E(K) なら座標が K の元なので全ての σ で不動。O も不動（D2）。（⊆）P = (x, y) が全ての σ で不動なら、x, y ∈ KG = K（D1）、つまり P ∈ E(K)。後半：E[m]G = E[m] ∩ E(K)G = E[m] ∩ E(K) = { P ∈ E(K) : [m]P = O } = E(K)[m]。

8

したがって6項完全列は本編 §03 の第2式に一致する：

0 → E(K)[m] → E(K) →[m] E(K) →δ H¹(G, E[m]) →ι* H¹(G, E(K)) →[m]* H¹(G, E(K))

▸ 根拠　Step 7 の等式を代入しただけ。左3項の間の写像が「包含」と「[m] の制限」であることは N0 Step 15 の「行き先の確認」（φ(AG) ⊆ BG 等）による。以後、本編の略記にならい H¹(G, E) := H¹(G, E(K)) と書く。

Section 06

[m]* は「H¹ の m 倍写像」（行間④）

補題（誘導写像と m 倍の一致）

H¹(G, E(K)) 上で、同種写像 [m] が誘導する写像は類の m 倍に一致する：

[m]* [c] = m·[c]　（∀[c] ∈ H¹(G, E(K))）
9

証明。

▸ 根拠　[m]* の定義（N0 Step 10）は [c] ↦ [[m]∘c]。各 σ で ([m]∘c)σ = [m](cσ) = cσ + ⋯ + cσ（m 個の和、[m] の定義）。一方、Z¹ の群構造は点ごとの和（N0 Step 1）なので、コサイクル c の m 倍元 mc も (mc)σ = cσ + ⋯ + cσ。つまり [m]∘c = mc がコサイクルとして同一。類を取って [m]*[c] = [mc] = m[c]（商群の m 倍）。

? なぜこれが「行間」なのか

記号 [m] は「E の同種写像」、m 倍は「アーベル群 H¹ の演算の反復」──住んでいる世界が違います。 本編が H¹(G, E)[m]（m-捩れ部分群）と書いた瞬間、この2つの一致が暗黙に使われていました。 検証は上の1ステップで済みますが、検証しない限り「[m]* の核」と「m-捩れ」を 同一視する権利はありません。

Section 07 ─ Main

Kummer 完全列の切り出し（行間⑤）

本編の「真ん中を切り出すと」の中身は、次の3つの検証です。 6項完全列の完全性（N0 Step 17–19）を部品として使います。

10

δ は well-defined な単射準同型 δ̄ : E(K)/mE(K) ↪ H¹(G, E[m]) を誘導する。

▸ 根拠　δ : E(K) → H¹(G, E[m]) は群準同型（N0 Step 14）。その核は、CG での完全性（N0 Step 17）より ker δ = [m](E(K)) = mE(K)。第一同型定理（weakmw N0 前提P5 と同じ標準事実）により δ は単射準同型 δ̄ : E(K)/mE(K) ↪ H¹(G, E[m]) を誘導し、im δ̄ = im δ。

11

im ι* = H¹(G, E)[m]。すなわち ι* は H¹(G, E) の m-捩れ部分群の上への写像。

▸ 根拠　H¹(G, B) での完全性（N0 Step 19）より im ι* = ker [m]*。Step 9 より ker [m]* = { [c] : m[c] = 0 } = H¹(G, E)[m]。2つを繋ぐだけ。

12

以上を組むと、次の列が完全（3箇所すべて検証済み）：

0 → E(K)/mE(K) →δ̄ H¹(G, E[m]) →ι* H¹(G, E)[m] → 0

▸ 根拠　左端（δ̄ の単射性）：Step 10。中央（ker ι* = im δ̄）：H¹(G, A) での完全性（N0 Step 18）が ker ι* = im δ を与え、Step 10 の im δ = im δ̄ を代入。右端（ι* の全射性）：Step 11 で像がちょうど H¹(G, E)[m] だと示した──「行き先の群」をこの像に取り替えたのだから全射は定義通り。

定理（楕円曲線の Kummer 完全列） AEC VIII §2
0 → E(K)/mE(K) →δ H¹(G, E[m]) → H¹(G, E)[m] → 0

これで本編 §03 の主張の box が、一行残らず検証済みになった。

Section 08

δ = κ ─ mE(K) の差が消える仕組み（行間⑥）

13

δ の cocycle 表示は第2部の Kummer 対そのもの：P ∈ E(K) に対し [m]Q = P なる Q を選ぶと

δ(P) = [ σ ↦ Qσ − Q ] = [ σ ↦ κ(P, σ) ]

▸ 根拠　N0 Step 11 の構成で、持ち上げ b として Q（存在は Step 6 の全射性）を選ぶと dσ = Qσ − Q。これは本編 §01・weakmw N1 §03 の κ の定義式と文字が一致するAEC VIII §1。「持ち上げの選択自由」（N0 Step 13）があるから、この特定の選び方をしてよい。

14

2段階の取り替え不変性。(i) Q → Q + T（T ∈ E[m]）ではコサイクルはコバウンダリの差だけ動く。(ii) P → P + [m]R（R ∈ E(K)）では、持ち上げをうまく選ぶとコサイクルは文字通り同一になる。

▸ 根拠　(i) (Q+T)σ − (Q+T) = (Qσ − Q) + (Tσ − T)。第2項は T の定めるコバウンダリ（N0 Step 13 の a = −T の場合の具体化）。よって類は不変。 (ii) P + [m]R の持ち上げとして Q + R が取れる（[m](Q+R) = P + [m]R）。すると (Q+R)σ − (Q+R) = (Qσ − Q) + (Rσ − R) = Qσ − Q。最後の等号は R ∈ E(K) = E(K)G（Step 7）で Rσ = R だから。コバウンダリすら現れない。

? 「打ち消しの2段構え」──これが直観の正体

E[m] 分の自由度（割り算の答えの選び方）は、コホモロジーの商 B¹ が吸収します。 mE(K) 分の差（割られる点の m 倍のズレ）は、商に頼るまでもなく持ち上げの選択で完全に消えます。 この2段構えこそが「δ̄ が E(K)/mE(K) 上 well-defined な単射になる」の中身であり、 本編の標語『割り算のねじれだけが情報として残る』の正確な形です。

本編 §03 が「コホモロジーの一般論から自動的に出ます」と述べた第2部・命題 VIII.1.2 の3項目は、次の部品に対応します：

VIII.1.2 の主張対応する部品
(a) κ の well-defined 性Step 13–14（N0 Step 13 の具体化）
(b) 双線形性（P 側・σ 側）P 側：δ が準同型（N0 Step 14）。σ 側：コサイクル条件（N0 Step 12）
(c) 左核 = mE(K)Step 10（N0 Step 17）
Section 09

3つの項は何を分類しているか（直観の整理）

項分類しているもの行き先
E(K)/mE(K) 有理点の「m で割った余り」。生成元を知りたい対象そのもの 降下法（本編Ⅳ）の入力
H¹(G, E[m]) 「P を m で割ろうとしたときの Galois 的ねじれ」の型の全体。E[m] ⊂ E(K) なら Hom(G, E[m])（N0 Step 5）＝体拡大の情報に退化する 第2部の L = K([m]−1E(K)) はこの群の言葉の言い換え
H¹(G, E)[m] 割り算の大域的な障害。後に Weil–Châtelet 群（E の主等質空間の類の群）の m-捩れと同定されるAEC X §3 / X.3.6 第5部の主役（Selmer 群・Ш）の住処

切り出した完全列が言っているのは：知りたい群 E(K)/mE(K) は、 「ねじれの型の空間」の中に単射で埋まり、余りは「障害の群」で正確に測られる──ということです。 乗法群 K× で同じ手続きを踏むと右端が消えて理論が完結する（Hilbert 90）のに対し、 楕円曲線では消えない。この非対称が第5部の全部の出発点になります（N2 で証明します）。

? なぜ完全列だけでは有限性が出ないのか

H¹(G, E[m]) は巨大な群です（E[m] ⊂ E(K) の場合ですら Hom(G, (ℤ/m)²) であり、 K のあらゆる次数 m 巡回拡大が1本ずつコサイクルを寄こします）。 単射 δ̄ の行き先が大きすぎて、このままでは E(K)/mE(K) の有限性は何も言えません。 像を「不分岐条件」で切って有限の箱に押し込むのが本編 §06 の仕事 ──その完全展開は N3（inflation–restriction と不分岐）で行う予定です。
